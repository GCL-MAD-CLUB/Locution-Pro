# 浏览和选择待导入文件

导入工作区用于先浏览磁盘文件，再决定加入项目的素材。文件区的勾选、底部待导入栏和项目媒体箱分别对应准备、核对和已经登记的内容。

## 浏览并选择素材

1. 打开顶部**导入**工作区，从左侧选择磁盘、收藏位置或常用位置。
2. 双击文件夹进入，使用面包屑返回上级。
3. 按文件类型筛选，按名称或创建日期排序，并选择升序或降序。
4. 搜索当前文件夹，选择列表或缩略图视图。
5. 勾选文件，或选择文件夹并等待其子文件夹扫描完成。
6. 在底部待导入栏核对本次选择和数量。

眼睛按钮切换**显示隐藏文件**。单击星形按钮可收藏当前位置，再次单击可从收藏夹移除；之后可从左侧收藏位置返回。列表字段包括名称、持续时间、创建日期、帧大小、帧速率和视频编码，“—”表示该项信息尚未取得或不适用。

### 调整待导入选择

- **Shift + 单击**选择连续项。
- 文件区中的 **Ctrl + A** 选择当前可见项。
- 在待导入栏中使用 **Ctrl** 或 **Shift** 多选，再按 **Delete** 移除。
- 使用**取消当前选择**清空本次待导入选择，不影响已经导入的媒体。
- 右键菜单可清除全部待导入项或查看所在文件夹。

移除待导入项不会删除磁盘文件。已导入的同一路径会显示**已导入**，可到媒体箱查找，无需重复导入。

扫描中的文件夹暂不能导入；无法读取时可右键选择**重新扫描文件夹**，或移除后选择可访问的子文件夹。

### 导入最近使用的文件

**文件 → 导入最近使用的文件**列出近期导入的媒体路径。选择条目可再次把该文件加入当前项目；如果文件已移动或不可用，请改用导入工作区选择新位置。

此命令与**文件 → 打开最近使用的内容**不同：前者导入媒体，后者打开项目。

## 区分文件选择的三个位置

| 位置       | 内容                         | 移除的影响                   |
| ---------- | ---------------------------- | ---------------------------- |
| 文件浏览区 | 当前磁盘目录中的文件和文件夹 | 取消勾选影响本次待导入选择   |
| 待导入栏   | 本次准备加入项目的内容       | 移除不删除磁盘文件           |
| 项目媒体箱 | 已成功登记的媒体             | 删除移除项目条目，原文件保留 |

## 按目录导入拍摄素材

1. 浏览到拍摄日期或场次文件夹。
2. 先检查类型筛选，确认视频、音频或字幕是否可见。
3. 需要整批加入时选择文件夹，等待子目录扫描完成。
4. 在待导入栏核对数量，移除测试片和无关文件。
5. 设置复制与媒体箱组织，再提交导入。

当前文件夹搜索和类型过滤影响浏览结果；找不到文件时，先恢复较宽的过滤范围，不要立即判定文件损坏。

## 收藏和隐藏文件

对经常使用的素材目录，可用星形按钮收藏。收藏只提供访问入口，不复制目录；移动原目录后需重新定位。

显示隐藏文件适合寻找平时被隐藏的内容。开启后仍应只选择实际需要的素材，不把目录中的辅助文件全部当作媒体。

## 文件夹扫描不能结束时

检查磁盘连接和目录可读性，使用重新扫描文件夹，或改选可访问的子文件夹。扫描中的目录暂不能导入。

一次选择过多不相关目录时，可清空待导入选择后按场次逐批加入。已经成功导入的同一路径会显示已导入，去媒体箱查找即可。
