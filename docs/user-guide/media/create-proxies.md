# 创建、连接和管理代理

代理是用于轻量预览的视频副本。原始文件和代理分别保管，通过项目关联起来；代理不能代替原始媒体归档。

## 创建代理

1. 选择一个在线视频，右键进入**代理 → 创建代理…**。此命令一次处理一个视频，不能对多选视频批量创建。
2. 选择完整、二分之一、四分之一或自定义帧大小。
3. 自定义宽度和高度时以 2 像素为步进调整，并保持所需宽高比。
4. 选择代理预设，如无损重封装 MOV、H.264 MP4、H.264 MP4 All-Intra、H.264 QuickTime、VP8 WebM 或 VP9 WebM。
5. 选择原始媒体旁的代理文件夹、指定文件夹或首选项缓存位置。
6. 确认空间充足并提交创建。
7. 等待完成，在播放器预览来源菜单切换到**代理**。

代理需要额外空间。选择尺寸时兼顾流畅度与审看细节；正式交付通常仍使用原始素材。水印当前仅提供“无”。

## 无损重封装 MKV

macOS 预览无法读取 MKV 容器。视频为 H.264、HEVC、ProRes 或 MJPEG 时，**无损重封装 MOV** 是默认推荐预设：它只复制视频流，不重新编码，画质和分辨率与原文件相同，通常几秒即可完成。帧大小设置对此预设无效。

- AAC、MP3、ALAC、AC-3 和 E-AC-3 音频原样复制；Opus、Vorbis、FLAC、DTS、PCM 等音频转为 AAC。
- 文件保存为 `原文件名_Remux.mov`，不会覆盖已有的 H.264 代理。
- AV1、VP9 等编码不提供此预设，请使用 H.264 代理。
- 在 macOS 上，MKV 无法直接预览时会自动重封装。可在**首选项 → 常规 → 预览**中关闭**自动无损重封装 MKV**。
- 重封装文件仍无法播放时（例如 10 位 H.264），应用会提示改用 H.264 代理。

## 连接、分离和定位已有代理

### 使用应用内媒体浏览器

在代理或链接对话框中启用**使用媒体浏览器附加文件**后，可直接在应用内查找文件：

- 使用后退、前进按钮和文件夹树导航。
- 按扩展名过滤，或切换**显示隐藏项目**。
- 搜索当前文件夹，并在列表与缩略图视图之间切换。
- 缩略图视图提供小、中、大三档尺寸。

浏览器只用于定位文件。附加后仍应核对内容、时长和帧率，不要只按名称判断对应关系。

### 连接代理

1. 确认已有代理与目标视频对应。
2. 使用**代理**子菜单中的连接命令选择代理文件。
3. 检查内容、时长和帧率是否对应。
4. 在源监视器切换代理预览并抽查。

### 分离代理

通过**分离代理**取消关联，不会删除代理文件。之后仍可重新连接，不必立即重新生成。

原始视频脱机时，使用**代理 → 重新连接完整分辨率媒体…**重新选择原视频。连接成功后，可切回**完整**预览。

### 在资源管理器中显示代理

选择已连接代理的视频，使用**代理 → 在资源管理器中显示**打开代理所在位置。该命令用于检查或管理磁盘文件，不会分离代理，也不会删除文件。

## 使用代理导出

导出设置中的**使用代理**适合快速审核。正式画面交付前通常应关闭，并确认原始素材在线。代理不会自动生成，缺失时请先创建或重新连接。

| 输出目的     | 建议                           |
| ------------ | ------------------------------ |
| 内部快速审核 | 可使用代理，并明确审核用途     |
| 正式画面交付 | 通常使用完整原始媒体           |
| 检查代理本身 | 使用代理输出，并核对尺寸和画质 |

如果画面模糊或范围不一致，检查当前使用的完整媒体与代理是否正确。

## 选择尺寸和位置

| 条件                   | 选择时考虑                            |
| ---------------------- | ------------------------------------- |
| 需要检查细小文字或物体 | 不要过度缩小尺寸，必要时切回完整媒体  |
| 以连续审看为主         | 用少量素材比较流畅度和文件大小        |
| 经常按帧定位           | 可比较 All-Intra 与常规预设的实际响应 |
| 需要随项目移交         | 固定代理目录并一同复制                |
| 仅本机临时使用         | 可使用首选项缓存位置，注意清理策略    |

完整帧大小仍可更换压缩方式，不表示一定最轻量。自定义尺寸应保持所需宽高比。

## 生成后验证对应关系

1. 切换代理预览，检查开头、中间和结尾。
2. 核对人物、场景、时长、声音和定位。
3. 切回完整媒体比较细节。
4. 确认连接正确后保存项目。

错连代理可能使你按错误画面挑选镜头。发现内容不同先分离并连接正确文件，不要继续据此修改切点。

## 代理在线但原视频脱机

可继续代理审看，但镜头检测、画面检索准备和原始分辨率静帧导出仍需原文件。正式输出前恢复完整媒体，并检查导出中的使用代理开关。

## 取消或更换代理

取消生成后查看项目关联与输出目录，确认是否留下文件。需要更换已有代理时，保留仍有用途的旧文件，再附加新代理并检查。分离命令不清理磁盘。
