# 使用关键字集和喷涂工具

关键字集把常用分类放进九宫格，喷涂工具将同一批分类应用到经过的镜头。两者适合在分类已经确定后，加快重复标注。

## 重复使用常用关键字

### 建议关键字和最近使用过的关键字

**建议关键字**根据所选镜头推荐可能适用的已有分类，**最近使用过的关键字**记录你刚用过的分类。选择镜头后单击其中任何一项即可赋值，完成后请核对赋值结果是否符合预期。

这两处适合添加少量分类；要连续标注大量镜头时，请改用关键字集或喷涂工具。

### 使用关键字集

关键字集把九个位置的关键字放进九宫格，单击即可赋予选定镜头，不必逐个输入路径。**关键字集**下拉菜单包含最近使用的关键字和全部预设，内置以下六组预设：

| 预设     | 关键字                                                     |
| -------- | ---------------------------------------------------------- |
| 画面主体 | 人物、物件、动物、交通工具、建筑、自然景观、文字屏幕       |
| 景别取景 | 人物远景、人物全身、人物半身、人物特写、物件全貌、物件特写 |
| 拍摄视角 | 平拍、俯拍、仰拍、顶拍、倾斜拍                             |
| 主体运动 | 静止、原地动作、空间移动、混合运动                         |
| 镜头运动 | 固定、推、拉、水平摇、垂直摇、移、跟、升降、环绕           |
| 人物数量 | 无人、单人、双人、多人                                     |

使用方式如下：

1. 选择要标注的镜头。
2. 打开**关键字集**下拉菜单，选择一组预设或最近使用的关键字。
3. 单击九宫格中的关键字赋予选定镜头；按住 **Alt** 可查看每个位置对应的数字快捷键。
4. 组内关键字不足九个的位置留空，留空位置单击无效。

### 管理关键字集

- **编辑集...** 打开当前关键字集，可编辑九个位置的内容，也支持填入层级路径。单击**更改**保存，**取消**放弃本次内容编辑。内置预设同样允许编辑。
- **将当前设置存储为新预设...** 把当前九宫格内容复制为命名预设。最近使用的关键字和编辑框中尚未提交的内容也可以先装入九宫格再存储。预设名称不可为空，也不能与现有预设重复。
- 自定义预设可以重命名或删除。删除当前预设后，九宫格暂时保留为**自定**；选择其他关键字集后，这份临时内容随即清除。
- **还原默认预设**恢复所有内置预设的原始内容，自定义预设不受影响。

预设和已保存的编辑会在下次打开软件时保留；**自定**仅在本次使用中保留。

## 使用喷涂工具批量标注

需要为大量连续镜头赋予同一分类时，使用底部喷涂工具比逐个选择更高效。先将常用分类设为快捷关键字：

1. 右键单击树中的节点，选择**设为快捷关键字**。
2. 开启底部喷瓶，将模式设为**关键字**。
3. 在输入框中键入路径，或按住 **Shift** 打开关键字九宫格，从最近关键字或任意预设中选择。此处只提供选择功能：可用**全选**装入当前关键字集，或用**清除**清空喷瓶。
4. 在镜头缩略图上单击或按住拖动，为经过的每个镜头赋值。
5. 完成后单击空喷瓶退出喷涂模式。

其他注意事项：

- 按住 **Alt** 单击或拖动可擦除镜头上的该关键字，适合修正误喷。
- 一次连续拖动视为一个整体操作，可一次撤销。
- 对折叠的堆叠赋值后，应展开确认各成员是否符合本次分类。
- 喷涂结束后记得退出喷涂模式，再恢复普通选择和其他操作。

## 为一次整理建立关键字集

1. 先确定本轮需要的类别，例如主讲人、嘉宾、观众、室内和室外。
2. 打开编辑集，为九个位置填写关键字或完整路径。
3. 按需要将当前设置存为新的命名预设。
4. 用少量镜头试用，确认路径创建在正确父级下。
5. 再推广到整个来源范围。

关键字集是输入分类的快捷入口，不会限制一个镜头只能拥有其中一个关键字，也不会自动清除其他分类。

## 九宫格快捷键

关键字面板的对应区域展开时，可按住 Alt 查看或使用位置数字：上排 7、8、9，中排 4、5、6，下排 1、2、3。输入文字时按键优先用于编辑。

留空位置无作用。修改预设后先核对位置，避免按旧习惯为镜头添加错误类别。

## 喷涂与普通选择

喷涂用于对经过的镜头应用当前值，普通选择用于建立随后批量处理的集合。喷涂状态下单击画面前，先确认喷瓶中装入的是哪组关键字。

Shift 打开的喷涂九宫格用于装入关键字，不提供预设编辑。需要改名、改路径或调整九个位置时，返回关键字集管理。

## 修正误喷与保存

按住 Alt 擦除当前关键字，或用 Ctrl + Z 撤销一次连续拖动。对折叠堆叠喷涂前先展开检查。完成后退出喷涂，并保存项目。

关键字集预设会在当前电脑继续使用；镜头赋值随项目保存。移交项目时，应以镜头上的分类为准，不把本机预设当成交付记录。
