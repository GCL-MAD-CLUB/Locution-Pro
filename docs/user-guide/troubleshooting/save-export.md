# 解决保存、恢复和导出问题

保存问题关系到可继续编辑的项目，导出问题关系到生成的媒体文件。先保住当前项目，再分别检查来源、输出设置和磁盘条件。

## 保存失败或需要找回工作

检查项目位置是否可写、磁盘是否在线且空间充足。可尝试另存到可写位置，避免继续覆盖唯一副本。

需要恢复时：

1. 在首选项确认自动保存位置。
2. 打开所需的自动保存文件。
3. 核对媒体、分镜、字幕标记和关键字。
4. 确认内容后另存为正式项目副本。

**还原**只返回最近一次成功保存，可能已包含自动写回的内容。详见[自动保存与恢复](/projects/projects#自动保存与恢复)。

## 导出失败或结果异常

1. 检查已勾选有效片段，输出目录可写且有足够空间。
2. 确认原始素材在线；使用代理输出时，核对代理连接。
3. 检查至少启用了有效的视频或音频输出。
4. 确认同名文件提示已处理。
5. 硬件加速失败时，改用**仅限软件**重试。
6. 文件无法播放时，确认接收设备支持格式，必要时改用 H.264 / MP4。
7. 查看完成提示中的成功与失败数量，部分失败时定位对应片段。

无声时检查来源音频、绑定和音频开关。模糊时检查代理、分辨率和质量。范围错误时，重新核对导出列表与蓝色括号。取消后应检查已完成的文件。

完整设置见[导出媒体](/export/exporting)。

## 根据导出现象检查

| 现象           | 优先检查                                     |
| -------------- | -------------------------------------------- |
| 无法提交       | 是否选中有效片段，至少启用一种有效音视频输出 |
| 提交后没有文件 | 任务是否仍排队，是否等待同名处理或已经失败   |
| 部分文件没更新 | 是否被跳过、失败，或输出到了其他目录         |
| 画面模糊       | 使用代理开关、输出尺寸与质量                 |
| 有画面无声音   | 来源音频、绑定和启用状态、导出音频开关       |
| 片头片尾不准确 | 导出列表中的当前片段和蓝色括号               |
| 合并后顺序错误 | 实际导出列表顺序，是否沿用了匹配度排序       |

## 覆盖、取消与撤销

导出范围撤销不能恢复被覆盖的磁盘文件。取消也可能保留已经完成的结果。先检查输出目录，再决定重试、使用唯一名称或改用新的批次目录。

## 提供足够的排查信息

记录失败时间、应用提示、来源格式、逐项或合并、代理开关、输出格式和成功失败数量。问题只发生在一个片段时，指出来源与时间范围，比反复重跑整批更有助于定位。
