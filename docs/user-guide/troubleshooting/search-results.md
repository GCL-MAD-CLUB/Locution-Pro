# 解决分镜和字幕检索问题

检索结果取决于来源、数据准备、查询和独立筛选。先判断没有内容、没有模式、准备失败或结果不理想，再处理对应环节。

## 分镜没有出现或切点不准确

- 检查来源菜单是否选中视频、原始文件是否在线。
- 等待识别任务结束，并查看是否出现失败提示。
- 检索准备尚未完成时，先处理索引进度或错误。
- 已有分镜时可主动重新切分，但覆盖前应保存副本。
- 淡入淡出、特殊转场或快速动作可能需要人工修正。

使用源监视器[添加、移动或清除切点](/source/source-monitor#调整分镜切点)。分镜数量不符合预期时，检查来源、搜索和筛选条件。

## 没有语义搜索或检索结果不理想

- 搜索模式没有**语义**：重新运行安装程序，确认语义检索组件已安装。
- 显示初始化或构建提示：等待完成；素材较多时准备时间较长。
- 分镜准备失败：确认原始视频在线、缓存盘可写且有足够空间。
- 结果过少：降低阈值，清除其他筛选条件，简化查询。
- 结果不相关：用具体画面描述搜索分镜，用对白主题搜索字幕，并播放核对。
- 无字幕内容：确认字幕来源和绑定；语义搜索不会生成字幕。
- 使用高级语义搜索时：检查正向与反向描述是否重复，以及反向描述是否过度降低得分。

字幕结果还应检查星级比较方式、旗标、标签、编辑状态和时长条件。高亮模式会保留非匹配项，不要把它误认为过滤结果。

使用方法见[按画面查找镜头](/workflows/find-visuals)和[使用字幕](/subtitles/subtitles)。

## 按顺序检查结果为空

1. 取消查询，确认未筛选的列表确实有分镜或字幕。
2. 确认视频、字幕轨与语言正确，来源没有被锁定在另一套范围。
3. 查看顶部识别或检索准备任务是否完成。
4. 清除星级、旗标、标签、编辑状态、时长和仅展示选中。
5. 分镜还要检查关键字快捷过滤，多个节点需同时满足。
6. 再使用简单查询，逐项加回条件。

## 不同结果问题的处理

| 问题                         | 处理                               |
| ---------------------------- | ---------------------------------- |
| 语义模式根本不存在           | 调整安装组件，不用反复改查询       |
| 一直提示准备或构建           | 查看任务和错误，检查原文件及缓存   |
| 文字存在却查不到             | 检查规则、大小写、字段与排除条件   |
| 只有相近含义，没有原词       | 这是语义匹配；精确原话改用文字搜索 |
| 高亮后仍有无关行             | 高亮保留上下文，批量处理前切到过滤 |
| 图标命中画面合适但片段不合适 | 检查完整镜头，命中帧不代表全段     |
| 字幕行数少于文件条数         | 检查连续相同字幕合并与筛选         |

## 语义查询的调整方法

先只使用一条明确正向描述，降低阈值检查能否找到目标类型。再补充替代表达或反向条件，避免一开始同时设置过多限制。

画面需求在分镜中检索，对白含义在字幕中检索。字幕没有文字时，语义搜索不会听写补齐。

## 核对修改是否有效

恢复预期结果后，重新应用需要的标记筛选，并把选用判断保存到项目。不要仅凭一次查询数量增加就认为问题已经解决。
