# 提交导出、查看结果和复用设置

完成片段和参数检查后，导出会在后台处理。提交成功、返回编辑工作区与文件全部完成是不同阶段，应等待完成提示再核对交付。

## 开始导出并查看结果

1. 确认片段、范围、顺序、输出文件夹和名称。
2. 核对视频与音频规格，正式交付时检查代理选项。
3. 需要把成品加入项目时，开启**常规 → 导入项目**。
4. 单击**导出**，按提示处理同名文件。
5. 提交成功后应用返回编辑工作区，导出在后台继续。
6. 等待顶部任务完成，并查看完成提示中的实际成功和失败数量。
7. 在输出位置检查成品；勾选**导入项目**时，同时核对媒体箱。

任务可能先排队。提交后继续编辑不会改变本次导出的已提交设置；需调整时取消并重新准备。取消可能保留已完成的文件，应检查输出目录。不要仅凭“已开始导出”判断全部片段都已成功。

## 使用上次设置快速导出

**文件 → 使用上次设置导出**可复用当前项目上次成功导出的设置，快捷键 **Ctrl + Alt + Shift + E**。

快速导出适合来源和交付要求均未改变的重复任务。切换素材、范围或交付要求后，先打开完整导出工作区确认参数，避免沿用旧的输出位置、命名或代理选项。

## 检查交付结果

用目标播放器核对清晰度、声画同步、开头结尾和合并接缝。分批导出时，同时核对文件数量、文件名和输出目录；部分失败时，根据完成提示和日志定位失败片段后重试。

遇到无声、打不开或失败提示，请参阅[故障排查](/troubleshooting/troubleshooting#导出失败或结果异常)。

## 提交前的检查顺序

1. 看勾选数量和总时长，确认只包含本轮片段。
2. 看逐项或合并设置以及列表顺序。
3. 看预览范围和输出规格。
4. 看完整输出路径、命名示例和同名策略。
5. 看是否使用代理、是否导入项目。
6. 提交并等待完成。

## 任务处理中继续编辑

提交后的任务使用本次已提交设置，后续编辑不会自动更新它。需要改变输出时取消任务，再重新准备与提交。

处理期间保持来源、代理和输出磁盘连接。多个任务汇总时不能逐项取消，具体取消条件见后台任务说明。

## 取消和部分失败

取消可能保留已完成的文件。部分失败也不代表整批都未输出：先查看完成提示，再核对目录，只重试确实需要重做的片段。

重试前检查同名策略，避免把成功文件意外覆盖或将旧文件误认为重试结果。

## 将成品导入项目

开启导入项目后，完成的媒体会加入项目，便于后续查看。导入结果仍引用磁盘成品，不会把文件装入项目；成品移走后也需要恢复连接。

项目内容发生变化时仍应保存项目。导出不替代保存操作。
