# Locution Pro 官网设计约束

## 内容与入口

- 面向视频创作者，介绍素材管理、画面检索、镜头整理和片段交付。不展示虚构性能、评分或客户证明。
- 素材处理在本机完成；语义检索需要可选组件。
- 官网为 `https://locution.dpdns.org/`，用户指南为 `https://helpx.locution.dpdns.org/`，GitHub 为 `GCL-MAD-CLUB/Locution-Pro`。
- 下载统一使用同源 `/api/download`，版本由发布清单更新；回退规则见 [README](README.md)。保留 `#workspace`、`#features`、`#workflow`、`#local` 和 `#download` 入口。

## 页面与视觉

- 网站视觉以 [DESIGN.md](DESIGN.md) 为准：暖纸白与亚麻色背景、轻字重标题、4px 圆角、黑色主按钮、少量蓝色链接，不用装饰阴影与渐变。
- 使用本地 Locution UI 字体，页面最大宽度 1200px。手机单列阅读，下载与正文保持可用。
- 参考 [Dela](https://dela.changyo.me/) 的疏朗编排：产品首屏、交替排列的三段演示、本地处理说明、FAQ 和下载。减少重复功能卡片、章节编号和装饰性元数据。
- 原生滚动驱动界面的轻微缩放、位移与文字显现。不拦截滚轮、翻页键或触摸手势，不添加滚动吸附。
- 三段功能区块使用相同布局与间距，从左右交替滑入；区块显现后保持可见。手机减小滑入幅度，减少动态效果时恢复普通文档流。
- 首屏加载时描绘产品名轮廓，依次呈现说明、按钮和软件画面。字形来自本地 Locution UI 的 300 字重，标题保留可访问的文本名称；减少动态效果时直接显示完整内容。
- 三段展示框使用相同宽高比例、内边距和说明区高度，不对第一段额外放大或拉长滚动空间。
- 下载区采用英文标题与 HTML/CSS 信件的双栏排版。参与支持区独占一个视口，三张链接卡片与 Star 入口集中在最大 800px 的区域内，不展示鸣谢或赞助内容。
- 页脚背景按明确要求横向铺满，内部导航保持 1200px 最大宽度；桌面端正文滚动离场后揭开页脚。背景、字体、圆角和控件继续遵守 DESIGN.md。

## 自动演示

- 导入、检索和导出分别循环播放自己的流程。使用三张真实应用截图，按原始 3120 × 1940 坐标对齐 SVG 演示层；保留软件的字体、图标、菜单、面板布局与比例。
- 自动演示素材选择、输入分镜标题、定位镜头、添加人物关键字和输出格式选择。光标移动、点击反馈与局部取景连续播放。
- 软件画面使用 `inert` 与 `aria-hidden`，不提供访客可操作的搜索、标注、上传或导出功能。不运行媒体分析、模型或编码，不虚构导出完成。
- 演示等比缩放，手机保持真实桌面布局。动画不改变网页滚动或焦点。
- 进入视口自动播放，离开视口或切换后台暂停，重新可见后接续。图外仅有暂停/继续控制。
- 减少动态效果或 JavaScript 不可用时，各段显示对应的真实静态界面，隐藏动画光标；下载与正文保持可用。
- 读屏使用流程说明，不逐帧播报。保留跳至正文、可见焦点和原生 FAQ。
