# 故障排查

先保存当前项目，并记录屏幕上的提示、发生时间和刚才执行的操作。按下面对应现象逐项检查；仍无法解决时，使用页面末尾的日志与反馈方法。

不要为了排错删除唯一项目副本、原始素材或已有输出。涉及覆盖、替换素材和批量删除时，先保存项目副本。

## 先按问题选择主题

| 问题发生位置                               | 排查主题                                            |
| ------------------------------------------ | --------------------------------------------------- |
| 找不到文件、导入失败、脱机、卡顿或画面为空 | [导入、连接和预览](/troubleshooting/media-playback) |
| 没有分镜、切点不准、语义不可用或搜索无结果 | [分镜与字幕检索](/troubleshooting/search-results)   |
| 项目无法保存、需要恢复或导出异常           | [保存、恢复和导出](/troubleshooting/save-export)    |
| 安装、启动、更新或界面报错                 | 继续阅读本页对应小节                                |

修复后回到原来失败的步骤确认一次，再继续处理其余素材。已经成功的部分不必默认全部重做。

## 安装或启动失败

1. 确认系统为 64 位 Windows 10 / 11，并关闭仍在运行的应用实例。
2. 重新运行完整安装程序，检查所需组件是否安装成功。
3. 如果安装程序提示文件被占用，关闭应用和相关任务后重试。
4. 启动后先阅读安装错误，再阅读更新或版本说明，不要忽略组件错误。
5. 仍失败时记录安装方式、组件选择和完整错误提示。

安装步骤和组件说明见[安装与卸载](/getting-started/install)。

## 应用界面暂时无法继续运行

出现**应用界面暂时无法继续运行**等界面错误时：

1. 记录错误内容；如界面提供错误编号，一并记下。
2. 关闭错误提示，保存仍能保存的工作。
3. 关闭并重新启动应用。
4. 检查问题是否由某个项目、某条媒体或某项重复操作触发。
5. 若再次发生，提供对应时段的日志和最小重现步骤。

重启不能替代排查。若重新打开同一项目就复发，先不要继续批量修改或覆盖输出。

## 媒体工具不可用

检查首选项中的两个媒体工具路径，或使用完整安装程序修复内置工具。重置路径不会安装工具。

详细操作见[解决导入、连接和预览问题](/troubleshooting/media-playback)。

## 提示运行库或组件不可用

检测或检索提示 **Microsoft Visual C++ 运行库（x64）** 缺失、不兼容或损坏时：

1. 使用错误提示中的**下载 VC++ 运行库**入口，从微软下载安装。
2. 已经安装时可尝试修复。
3. 完成后关闭并重新打开 Locution Pro。
4. 重新提交任务。

若仍提示组件无法加载，或提示应用组件缺失，重新运行完整安装程序修复对应组件。运行组件错误可能带有编号，反馈时请同时提供该编号和日志。

## 无法导入或看不到素材

检查当前目录、类型与隐藏过滤、文件夹扫描、待导入栏和媒体箱位置。复制失败时检查目标空间和权限。

详细操作见[解决导入、连接和预览问题](/troubleshooting/media-playback)。

## 媒体脱机或画面为空

检查原文件、启用和隐藏状态，恢复链接；只有代理在线时切到代理预览。需要检测或静帧时恢复原视频。

详细操作见[解决导入、连接和预览问题](/troubleshooting/media-playback)。

## 分镜没有出现或切点不准确

检查视频来源、原始文件与识别进度；转场附近需要人工校正。重新切分覆盖前先保存副本。

详细操作见[解决分镜和字幕检索问题](/troubleshooting/search-results)。

## 没有语义搜索或检索结果不理想

没有语义模式时检查安装组件；准备失败时检查来源、原视频和缓存；结果过少时逐项检查阈值、高级条件和独立筛选。

详细操作见[解决分镜和字幕检索问题](/troubleshooting/search-results)。

## 预览卡顿或磁盘空间不足

检查磁盘连接和空间，为可读取的大视频创建代理。更改缓存位置不迁移旧文件，清理前保留项目、素材和恢复文件。

详细操作见[解决导入、连接和预览问题](/troubleshooting/media-playback)。

## 保存失败或需要找回工作

检查保存位置与空间，必要时另存到可写目录。恢复时打开自动保存文件，核对后另存为正式项目。

详细操作见[解决保存、恢复和导出问题](/troubleshooting/save-export)。

## 导出失败或结果异常

确认勾选、来源在线、音视频设置、同名处理和输出路径。硬件加速失败时改用仅限软件，部分失败按片段检查。

详细操作见[解决保存、恢复和导出问题](/troubleshooting/save-export)。

## 更新失败或没有收到更新

1. 确认网络可用，并记录下载或安装阶段的提示。
2. 使用**帮助 → 更新…**手动重试。

3. 更新安装失败时，按提示使用回退安装方式，不要删除当前项目。
4. 曾选择忽略某版本时，该版本可能不会再次自动提示。
5. 仍失败时提供当前版本、目标版本和更新时段的日志。

详见[更新与获取帮助](/getting-started/updates)。

## 菜单或快捷键没有生效

单击目标面板，确认当前未在输入文字。检查项目是否只读、条目是否启用、来源是否锁定，以及命令是否适用于当前选择。

- 高亮搜索的左右方向键用于导航匹配项；逐帧操作应先聚焦源监视器。
- 导出工作区的撤销用于待导出范围，不用于撤销已生成的文件。
- 输入框中的 **Enter** 和 **Esc** 可能用于应用或放弃输入，而不是触发面板命令。
- **浮动面板**、**面板组设置**和**脱机编辑**等禁用项目前不可执行。

完整按键见[键盘快捷键](/workspace/shortcuts)。

## 查看与提供日志文件

1. 记下出现问题的时间、操作和报错内容。
2. 选择**帮助 → 显示日志文件**。
3. 找到对应时段的日志，复制一份用于反馈。
4. 检查日志中的路径、项目名称等信息，遮去不希望公开的内容。
5. 在[问题反馈页面](https://github.com/GCL-MAD-CLUB/Locution-Pro/issues)说明应用版本、系统、操作步骤、媒体格式与提示。
6. 如果错误窗口或运行组件提供错误编号，将其与日志一起提交。

不要提交私人素材或完整项目。确需样本时，先制作不含敏感内容且能重现问题的最小样本。反馈安全问题请使用[私密漏洞报告](https://github.com/GCL-MAD-CLUB/Locution-Pro/security/advisories/new)。
