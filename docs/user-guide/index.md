## 欢迎使用

Locution Pro 帮助你从大量视频中发现、筛选和整理可用素材。无需字幕，也可以完成镜头检测、画面检索、标注和导出；已有字幕时，还可按对白文字或含义查找片段。

本指南适用于 Locution Pro 0.4.2，按实际工作任务介绍操作方法。首次使用请从[安装与首次启动](/getting-started/install)和[创建第一个项目](/getting-started/first-project)开始；已经熟悉基本操作时，可直接选择下面的任务。

## 按工作流程学习

### 第一次使用

1. 查看[系统要求](/getting-started/system-requirements)，准备素材和存储空间。
2. 完成[安装与首次启动](/getting-started/install)，确认媒体工具和自动保存设置。
3. 按[创建第一个项目](/getting-started/first-project)完成一次导入、整理和导出。
4. 阅读[认识工作界面](/getting-started/interface)，了解各面板和当前操作对象。

### 建立素材库

1. 在[导入和整理媒体](/media/import-organize)中选择复制方式与媒体箱结构。
2. 有独立录音或字幕时，按[管理音频与字幕轨](/media/tracks-binding)完成绑定。
3. 使用[分镜](/storyboard/storyboards)浏览和筛选镜头，再用[关键字](/storyboard/use-keywords)建立长期分类。
4. 通过[创建和管理项目](/projects/projects)保存、备份和移交整理结果。

### 查找并交付片段

- 只有画面需求时，使用[语义画面检索](/workflows/find-visuals)。
- 已有对白字幕时，使用[字幕检索](/workflows/find-dialogue)。
- 预览不流畅时，先[生成代理](/workflows/create-proxy)。
- 输出前查阅[导出媒体](/export/exporting)，核对范围、格式、音频和文件名。

## 保护和继续你的工作

[保存项目与恢复自动保存文件](/projects/projects)，了解项目与原始素材如何分别保管。需要调整自动保存、存储位置或媒体工具时，请参阅[首选项](/projects/preferences)。

::: tip 项目不是媒体备份
项目文件保存媒体箱组织、分镜和标注，但不包含原始视频、音频、图像或外部字幕。移交项目时，请同时复制项目文件和需要继续使用的媒体。
:::
