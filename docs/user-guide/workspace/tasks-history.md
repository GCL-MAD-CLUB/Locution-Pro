# 使用历史记录和后台任务

历史记录管理已经发生的项目编辑，任务进度显示正在处理的工作。取消任务和撤销操作处理不同阶段，不能互相代替。

## 查看任务进度与取消

导入、分析、分镜识别、检索准备、生成代理和导出时，顶部显示任务与进度。任务可能先排队；某些步骤的百分比会短暂停留，请结合任务名称和文件规模判断。

处理期间可继续浏览或进行允许的操作。不要移动正在使用的源文件，也不要断开素材盘、代理盘或输出盘。

### 取消任务

1. 确认顶部显示的是需要停止的任务。
2. 只有一个可取消任务时，单击取消按钮。
3. 等待**正在取消任务**结束。
4. 核对项目中是否保留了部分导入或分析结果。
5. 检查代理或输出目录，确认是否已生成部分文件。

多个任务的汇总显示不提供逐项取消。取消不等于撤销，已经完成的文件或项目变化可能需要另行处理。

持续没有进展时，记录任务名称和提示，参阅[故障排查](/troubleshooting/troubleshooting)。

## 使用项目历史记录

打开窗口 → 历史记录，单击记录可回到对应状态。Ctrl + Z 撤销，Ctrl + Shift + Z 重做。

- 回到早期状态再继续编辑，会替换原先后续的编辑路径。
- 比较不同方案前先保存项目副本。
- 历史面板的删除按钮删除当前记录及后续历史，不能撤销。
- 关闭项目再打开后，不应把本次会话的历史当作长期备份。

## 选择正确的回退入口

| 想回退什么                   | 使用什么                       |
| ---------------------------- | ------------------------------ |
| 刚才的分镜、关键字或标注操作 | 项目撤销与历史记录             |
| 刚才切换的视频来源           | 来源导航按钮                   |
| 刚才调整的待导出入点或出点   | 导出工作区的范围撤销           |
| 已写入磁盘的成品覆盖         | 需要已有文件备份，撤销不能恢复 |
| 需要停止尚未完成的处理       | 取消任务，再核对部分结果       |

## 判断任务是否完成

提交任务、任务排队、正在处理和完成是不同状态。导出提交后返回编辑工作区并不表示文件已全部生成；应等待完成提示中的实际成功与失败数量。

进度可能在准备步骤短暂停留。结合任务名称、素材规模和错误提示判断，避免连续重复提交同一个批次。

## 取消之后做什么

1. 等待正在取消结束，不要立即断开磁盘。
2. 检查媒体箱和当前面板已完成的项目变化。
3. 查看代理或成品目录中的已有文件。
4. 确认仍需处理的部分，再重新提交。
5. 已完成的整理结果单独保存。

取消通常停止后续处理，不能保证恢复到提交前的全部状态。
