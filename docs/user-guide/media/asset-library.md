# 使用项目素材库

素材库集中保管从分镜和字幕选出的片段。在同一项目内，可以跨视频收集候选，按交付用途分文件夹，并在导出前单独调整每个片段。

## 添加片段

1. 选择**窗口 → 素材库**打开面板。分镜和字幕各有一个根目录。
2. 如需按用途分类，在相应根目录下右键选择**新建文件夹**。
3. 在分镜或字幕面板选中片段，右键选择**添加到素材库**，再选择对应的根目录或目标文件夹。

加入时会保留当时的入点、出点、文本和标注。之后在素材库内修改这些内容只影响库内片段。项目保存后，下次打开可继续使用。

## 整理、预览和导出

- 在素材库中搜索条目，或使用排序、分组选项浏览候选。
- 双击片段可在源监视器中预览。选中片段，在属性窗格的**切点**中调整入点和出点。需要为交付另留片头片尾时，可在导出工作区设置[范围扩展](/export/prepare-clips#批量扩展片头和片尾)。
- 选中所需片段，执行**文件 → 导出…**。在导出工作区核对片段顺序、范围和输出规格，再提交任务。

预览和导出仍需要项目引用的媒体文件。移交项目时，请同时提供原始素材；文件路径变化后，按[重新链接媒体](/media/relink-media)恢复连接。
