# 导出媒体

将所选镜头、媒体或对白片段生成为新的媒体文件。导出工作区分为左侧片段列表、中间范围预览和右侧输出设置；右侧的来源与输出信息用于在提交前比较规格。

导出不会替代项目保存。完成后仍应保存项目，以便继续整理、修改标记或再次导出。

## 选择导出内容

从媒体箱、分镜或字幕选择条目，再执行文件 → 导出。到导出列表核对勾选、数量、顺序和总时长。

详细操作见[选择、预览和调整待导出片段](/export/prepare-clips)。

## 调整导出范围

在预览中拖动蓝色括号左右边界调整入点与出点，拖动中间手柄整体移动。范围调整只影响待导出片段，不随项目保存。

详细操作见[选择、预览和调整待导出片段](/export/prepare-clips)。

## 选择逐项或合并输出

关闭合并为一个文件可逐项输出；开启后按列表顺序拼接。混合来源先明确统一规格，再检查顺序与接缝。

详细操作见[选择、预览和调整待导出片段](/export/prepare-clips)。

## 设置输出位置

选择固定文件夹或常用位置，可存入子文件夹。同名处理可选择询问、唯一名称、覆盖或跳过，覆盖不能通过撤销恢复。

详细操作见[设置导出位置、文件名和同名处理](/export/naming-location)。

## 设置视频

视频输出可选 H.264、HEVC、ProRes 和 VP9；按交付要求设置尺寸、帧率、质量、速度与性能。正式画面通常使用原始媒体。

详细操作见[设置视频格式、尺寸和质量](/export/video-settings)。

## 设置音频

来源有音频时可控制声音输出及编码、采样率、声道和比特率。只需声音可选 MP3 或 AAC；没有音频的来源不能使用纯音频输出。

详细操作见[设置音频和纯音频输出](/export/audio-settings)。

## 设置文件名

命名字段随分镜、字幕、媒体箱与合并方式变化。查看示例，核对自定文本、重复名称编号和扩展名大小写。

详细操作见[设置导出位置、文件名和同名处理](/export/naming-location)。

## 开始导出并查看结果

确认范围、位置、命名、视频和音频后提交。应用返回编辑工作区，任务继续处理；完成后核对成功、失败数量与文件。

详细操作见[提交导出、查看结果和复用设置](/export/run-export)。

## 使用上次设置快速导出

使用上次设置导出可复用当前项目上次成功导出的设置。交付用途或来源改变时，先打开完整导出工作区复核。

详细操作见[提交导出、查看结果和复用设置](/export/run-export)。

## 检查交付结果

核对文件数量、名称、声音、清晰度、片段边界和合并接缝。部分失败时根据提示和日志定位片段再重试。

详细操作见[提交导出、查看结果和复用设置](/export/run-export)。
