# 首选项

展开**编辑 → 首选项**，选择**常规、外观、自动保存、媒体缓存**或**媒体工具**。各入口打开同一个首选项弹窗，并直接进入对应子页；打开后也可在左侧切换分类。

调整后单击**确定**保存；单击**取消**、关闭窗口或按 **Esc** 放弃本次修改。路径可直接输入，也可单击**浏览…**选择。数值不符合允许范围时，请按提示修正后保存。

## 常规

**启动时显示主页**默认开启。关闭后，应用启动时不主动显示项目首页，仍可通过顶部主页按钮打开。

如果需要频繁返回最近项目，可保持开启；如果通常继续当前工作，可关闭启动首页。此设置不会改变最近项目记录或项目文件。

## 外观

在**颜色主题**中选择**最暗、深色**或**浅色**，界面立即预览所选配色。单击**确定**保存，下次启动继续使用；取消、关闭窗口或按 **Esc** 恢复已保存的外观。

| 主题 | 界面表现                                     |
| ---- | -------------------------------------------- |
| 最暗 | 默认配色，项目首页也使用最暗配色             |
| 深色 | 在最暗基础上稍微提亮，项目首页与最暗主题一致 |
| 浅色 | 使用浅色工作区和项目首页                     |

品牌与工作区切换所在的顶部区跟随主题，应用菜单栏和弹出菜单保留原有配色关系。切换主题保持灰度与彩色的类别；标签和切点在三种外观中使用同一套固定配色。

切点使用亮、暗两套颜色区分选择状态：**最暗、深色**下选中项为亮色，其他项为暗色；**浅色**下选中项为暗色，其他项为亮色。没有选中切点时，所有切点均为亮色。

## 自动保存

| 设置                     | 用途                           | 默认值或范围               |
| ------------------------ | ------------------------------ | -------------------------- |
| 自动保存项目             | 开启或关闭定时自动保存         | 默认开启                   |
| 自动保存时间间隔         | 控制检查项目变化的频率         | 1–1440 分钟，默认 5 分钟   |
| 最大项目版本             | 控制每个项目保留的恢复文件数量 | 1–1000 个，默认 20 个      |
| 自动保存也会保存当前项目 | 同时写回已有正式路径的当前项目 | 默认开启                   |
| 自动保存位置             | 指定恢复文件所在目录           | 默认为缓存目录下的独立目录 |

项目内容有变化时才生成新的自动保存文件。达到上限后，删除该项目最旧的自动保存文件。未命名项目也可生成恢复文件，但需手动保存一次后，才能自动写回正式项目路径。

### 选择自动保存位置

默认位置是缓存目录下的 **Locution Pro Auto-Save**。该位置独立设置，随后更改媒体缓存位置不会连带改变它。清空自动保存位置并确认，可重新采用当前缓存目录下的默认位置。

更改位置不会迁移或删除旧文件。请选择稳定、可写且空间充足的目录。需要找回工作时，按[自动保存与恢复](/projects/projects#自动保存与恢复)操作。

::: tip 自动保存不是完整备份
自动保存不复制原始媒体，也不替代重要节点的独立项目副本。大批量调整前仍建议使用**保存副本**。
:::

## 媒体缓存

缓存用于日常浏览和检索准备，应放在空间充足、连接稳定的磁盘上。

1. 选择**媒体缓存**。
2. 输入缓存路径，或单击**浏览…**选择文件夹；留空采用默认位置。
3. 单击**确定**。
4. 后续生成缓存后，检查新位置是否可写、空间是否足够。

新生成的缓存使用新位置，旧文件不会自动迁移。缓存位置与项目、原始素材及自动保存位置分别管理。清理磁盘前，先确认哪些缓存可以重新生成，避免误删项目或素材。

## 媒体工具

通常使用安装程序提供的内置媒体工具即可。如果使用自己的工具，分别填写 **FFmpeg** 与 **ffprobe** 的可执行文件路径，建议来自同一套发行包。

1. 选择**媒体工具**。
2. 分别检查或填写两个程序的路径。
3. 单击**确定**保存。
4. 用一小段素材重新尝试导入、预览或导出，确认工具可用。

单击**重置工具路径**会恢复这两项的默认命令名称，仍需单击**确定**才生效。如果系统中没有对应工具，重置后也可能无法处理媒体；可重新运行安装程序选择内置方案。

工具问题见[媒体工具不可用](/troubleshooting/troubleshooting#媒体工具不可用)。

## 区分设置保存在哪里

| 内容               | 调整位置     | 是否替代项目保存         |
| ------------------ | ------------ | ------------------------ |
| 主题、启动行为     | 首选项       | 否，属于使用环境         |
| 自动保存频率和目录 | 首选项       | 否，正式项目仍应手动保存 |
| 缓存和媒体工具     | 首选项       | 否，不会迁移项目或素材   |
| 镜头、关键字和标注 | 对应项目面板 | 需要保存项目             |
| 临时导出范围       | 导出预览     | 不随项目文件保存         |

更换电脑后，先确认路径和组件，再打开项目恢复媒体连接。不要把旧电脑上的缓存位置直接当作新电脑也可访问的素材位置。

## 使用键盘操作首选项

- 使用 **Tab / Shift + Tab** 在控件之间移动焦点。
- 焦点位于左侧分类时，使用上下方向键切换。
- 按 **Home / End** 跳到首个或末个分类。
- 按 **Esc** 放弃本次未确认的修改。
