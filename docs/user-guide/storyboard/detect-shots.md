# 检测和重新切分镜头

镜头检测根据视频画面变化生成可独立审看的片段。先建立合适的镜头边界，再批量填写标题、关键字和质量标记，可以减少后续返工。

## 生成分镜

1. 在媒体箱选择原始文件在线、已启用的视频。
2. 打开**分镜**面板，在来源菜单选择视频。新增来源尚无分镜时，会自动开始识别。
3. 需要主动识别时，单击标题行最右侧的剪刀按钮**切分**或**重新切分**。
4. 等待顶部进度结束，在标签或图标视图中查看结果。

也可以在媒体箱多选视频，右键选择**分镜识别**。识别需要原始视频在线；仅有代理可预览时，请先重新连接原始媒体。

自动识别后请检查明显的误切和漏切，尤其是淡入淡出、叠化和快速运动画面。需要修正时，在[源监视器](/source/source-monitor#调整分镜切点)中添加、移动或清除切点。

### 重新识别已有分镜

| 选项 | 对已有工作的影响                                               |
| ---- | -------------------------------------------------------------- |
| 合并 | 保留现有划分与整理，补充识别出的新切点；检查新镜头的边界和标记 |
| 覆盖 | 重建分镜，清除旧删除记录、堆叠和镜头标注                       |
| 取消 | 保留现有分镜，不执行本次识别                                   |

准备覆盖前请保存项目副本。如果识别期间继续修改了相关镜头，完成时可能再次要求选择处理方式。

## 检测前确认素材条件

- 原始视频必须在线、可读取并已启用；代理不能代替检测所需的原文件。
- 检查顶部是否仍在导入或分析，避免把尚未完成的准备误判为无结果。
- 只对需要整理的视频开始识别；长视频和大量来源会增加等待时间。
- 已有大量标注时，重新检测前先保存项目副本。

## 检测完成后检查什么

1. 切换到图标视图，检查镜头缩略图能否反映明显场景变化。
2. 选择几个转场，在源监视器逐帧检查边界。
3. 将一个镜头中出现的明显场景变化记为漏切，将同一连续动作中的多余切点记为误切。
4. 检查特别短或特别长的条目，判断是否需要人工修正。
5. 完成主要修正后再批量标注，并保存项目。

淡入淡出、叠化、闪光和快速运动都可能影响自动结果。镜头数量多或少本身不代表检测失败，应结合实际画面判断。

## 合并与覆盖如何选择

| 当前工作                         | 建议处理           | 完成后检查                     |
| -------------------------------- | ------------------ | ------------------------------ |
| 还没有开始整理                   | 可以重新建立切分   | 镜头边界和总览                 |
| 已有人工切点和标注，希望补充检测 | 选择合并           | 新切点附近的标题、关键字和时长 |
| 需要舍弃整套旧划分               | 保存副本后选择覆盖 | 删除记录、堆叠和旧标注已被重建 |
| 尚不清楚影响                     | 取消               | 先查看原有结果再决定           |

合并识别补充切点，与将相邻镜头合并成一个条目是不同操作。覆盖也不会改写视频文件。

## 检测未完成时

先看顶部任务是否仍在排队、处理或取消。取消后检查已完成的结果，再重新提交需要的来源。提示原文件或组件不可用时，先恢复连接或修复安装；反复单击切分不能解决这些问题。

检测后的精确校正见[添加、移动和清除切点](/source/edit-cuts)。
