# 设置音频和纯音频输出

音频选项随输出格式和来源变化。先选择视频或纯音频格式，再核对声音是否启用、声道和采样率是否符合交付要求。

## 设置音频

来源包含音频时，可以开启或关闭音频输出，选择可用格式、采样率、声道和比特率。先确定输出格式，再调整音频参数；切换格式后应再次检查。

- 单声道或立体声按交付要求选择；5.1 仅在来源和格式支持时出现。
- 使用匹配源采样率可减少不必要的规格变化。
- 纯音频输出选择 **MP3** 或 **AAC**，此时不输出视频。
- 没有音频的来源不能选择纯音频格式。
- 至少启用一种有效的视频或音频输出。

绑定独立录音的项目，应先确认使用了正确音频。导出后无声时，检查来源、启用状态和音频开关。

### 音频格式与规格

WebM 提供 Opus，MP3 输出 MPEG 音频，AAC 输出 AAC；视频格式中的音频选项以对应下拉菜单为准。MPEG 音频层可按可用选项选择 MP2 或 MP3，纯 MP3 文件固定使用 MP3。

AAC / Opus 可选择匹配源或 16000、22050、24000、32000、44100、48000 Hz；MPEG 提供匹配源或 32000、44100、48000 Hz。源声道不足时不会提供 5.1，MP2 / MP3 也不提供 5.1。

比特率越高通常文件越大。按交付要求选定后，试听开头、中间与片段连接处，确认声道和同步。

## 从视频中输出声音片段

1. 在字幕、分镜或媒体箱选择需要的范围。
2. 打开导出工作区，试听入点和出点。
3. 选择 MP3 或 AAC 纯音频格式。
4. 核对采样率、声道、比特率及文件名。
5. 导出完成后检查声音、停顿和语句完整性。

纯音频输出不包含画面。来源无音频时，应先确认是否选错媒体或缺少绑定录音。

## 采样率、声道和比特率

| 设置   | 选择依据             | 检查重点                   |
| ------ | -------------------- | -------------------------- |
| 采样率 | 接收方要求，或匹配源 | 切换编码后选项是否变化     |
| 声道   | 实际来源及交付用途   | 单声道、立体声或允许的 5.1 |
| 比特率 | 音质与文件大小要求   | 不以提高数值代替修复原录音 |

来源声道不足时不会提供 5.1，MP2 / MP3 也不提供 5.1。选项以当前格式的下拉菜单为准。

## 有独立录音时

导出前先检查绑定目标、启用状态和同步。绑定表示建立项目关系，不会自动对齐录制时已经错位的音频。

播放开头、中间和结尾，尤其检查长素材尾部与片段接缝。若偏移随时间增加，先修正来源问题，再重新输出。

## 导出后无声或声道异常

1. 检查来源是否实际有声，音频条目是否启用。
2. 确认导出音频开关开启。
3. 检查切换格式后音频设置是否改变。
4. 核对绑定录音及选择范围。
5. 用接收软件支持的格式重新核对结果。
