# 创建和管理媒体箱

媒体箱是项目内部的组织方式。你可以按日期、场次、人物或用途建立分类，而不改变磁盘素材目录。

## 在媒体箱中整理

使用列表或图标视图浏览，按名称搜索和排序。双击视频可在源监视器打开；拖动条目到媒体箱文件夹可移动分类位置。文件夹可多级组织，双击进入，使用路径导航返回上级。

列表视图提供标题、帧速率、媒体开始、媒体结束、媒体持续时间、视频信息、音频信息、启用和隐藏等字段，可据此核对素材规格和状态。

### 常用管理命令

通过右键菜单或工具栏执行以下操作：

| 命令                 | 结果                                       |
| -------------------- | ------------------------------------------ |
| 新建媒体箱、重命名   | 调整项目内分类和显示名称，不改磁盘文件名   |
| 移动到素材箱         | 将所选条目移到项目媒体根目录或指定分类     |
| 通过选择项新建素材箱 | 新建分类并把当前选择移入其中               |
| 复制、粘贴和重复     | 创建项目内条目，不复制磁盘上的原文件       |
| 隐藏 / 查看隐藏内容  | 改变浏览可见性，需要时恢复显示             |
| 禁用 / 启用          | 让所选条目暂不参与或重新参与相应操作       |
| 全部启用             | 在空白处右键，重新启用当前范围内的全部条目 |
| 删除                 | 从项目中移除所选条目，不删除原始媒体       |
| 项目只读             | 允许预览但限制编辑，编辑前需解除           |

列表中的启用与隐藏复选框可直接更改状态。媒体箱顶部的笔 / 锁按钮切换**项目只读**状态。通过窗口菜单可分别打开不同媒体箱视图。

删除媒体前请确认关联的分镜、标注和轨道是否仍需要保留，必要时保存项目副本。完成整理后按 **Ctrl + S** 保存。

## 建立可持续使用的层级

1. 先按稳定维度建立少量媒体箱，例如拍摄日期或场次。
2. 将视频和对应辅助媒体放在便于核对的位置。
3. 为需要单独管理的用途建立次级分类。
4. 检查移动后的条目和绑定关系。
5. 保存项目。

关键字用于镜头内容分类，媒体箱用于项目媒体的组织。一个长视频包含多种场景时，不必为每个场景复制视频条目，可在分镜中按关键字整理。

## 重命名、移动和复制

重命名只改变项目显示名称，不改原文件名；移动到媒体箱只改变项目分类。通过选择项新建素材箱可一次完成新建和移入。

复制、粘贴或重复建立项目内条目，不产生独立素材备份。多个条目可能仍引用同一个磁盘文件，移动或删除该文件会影响相关引用。

## 隐藏、禁用和脱机

| 状态     | 目的                       | 恢复方法               |
| -------- | -------------------------- | ---------------------- |
| 隐藏     | 减少浏览中的干扰           | 查看隐藏内容后恢复显示 |
| 禁用     | 暂停条目参与相应操作       | 启用，或使用全部启用   |
| 脱机     | 原文件不可访问或已主动断开 | 使用链接媒体恢复       |
| 项目只读 | 限制编辑以便审看           | 通过笔 / 锁按钮解除    |

找不到条目时，先检查当前媒体箱、搜索和隐藏内容；看得到却不能操作时，再检查启用、只读和连接。

## 删除项目媒体

删除前检查关联分镜、标记、音频和字幕是否仍需保留。必要时先保存项目副本。删除只从项目移除条目，不删除磁盘原文件。

误删后立即撤销，核对相关整理结果。不要通过重新导入原文件来代替检查已经丢失的项目标注。
