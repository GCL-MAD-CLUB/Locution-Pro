# 维护关键字层级和同义词

关键字分类由整个项目共用。修改名称、父级或删除节点前，先考虑它在其他视频和镜头中的使用情况。

## 创建和编辑分类

### 创建分类

1. 单击**关键字列表**标题栏的加号，或右键选择**创建关键字标记…**。
2. 输入名称，可按需填写同义词。
3. 需要子分类时，确认**置入某关键字中**并选择父级名称。
4. 可勾选**添加到选定的分镜**，在创建的同时完成赋值。
5. 单击**创建**。

同一父级下不能使用重复名称。右键单击父节点可直接在其中创建子分类。启用**将新关键字置入到该关键字中**后，后续创建会默认采用该父级，父级名称旁会出现标记；使用完毕后记得取消，避免新分类放错位置。

### 修改名称与同义词

右键单击节点，选择**编辑关键字标记…**，修改后单击**存储**。同义词可用逗号或换行分隔，搜索关键字时任一叫法都能命中。

重命名会影响项目中使用该分类的所有视频。批量调整结构前，请先保存项目副本。

### 更正父级

不提供直接移动已有节点的命令。创建时父级选错，应按以下步骤更正：

1. 在正确的父级下新建分类。
2. 为所需镜头添加新分类的赋值。
3. 移除旧分类在各镜头上的赋值。
4. 确认无镜头再使用后，删除错误的分类。

## 移除赋值与删除分类

**从镜头移除关键字**只是取消这个镜头与分类的关联，分类本身保留，其他镜头仍可继续使用：

- 取消树节点的勾选。
- 或右键选择**从选定的分镜中移去此关键字**。

**删除分类**会从项目中彻底移除该节点：选择树节点，单击减号或右键选择**删除…**。删除父节点会连同其子分类和相关赋值一起移除；执行前先阅读提示中显示的使用数量，确认没有仍在使用的镜头。

两个操作都可能误伤其他镜头，请注意：

- 误操作后立即撤销。
- 只是当前镜头不需要该分类时，应移除当前赋值，而不是删除整个分类。
- 删除父级前，先展开检查其子分类是否仍有镜头在使用。

## 命名和同义词的选择

| 情况                 | 建议                     | 例子                     |
| -------------------- | ------------------------ | ------------------------ |
| 同一概念有不同叫法   | 保留一个分类，补充同义词 | 主讲人、演讲者           |
| 名字相同但含义不同   | 放入不同父级             | 人物 > 主持、工作 > 主持 |
| 多个维度可能同时成立 | 分别建立类别             | 景别 > 特写、地点 > 室内 |
| 一批镜头暂时待审     | 使用旗标或标签记录状态   | 待核对                   |

同义词用于搜索，不是另一套独立赋值。修改同义词后，用新的叫法搜索少量已标注镜头，确认能按预期找到。

## 安全调整分类结构

1. 保存项目副本。
2. 使用旧节点快捷过滤，确认实际使用的镜头。
3. 在正确位置创建新分类。
4. 将新分类赋予需要迁移的镜头，清除筛选后抽查。
5. 移除旧赋值，确认其他视频中没有遗漏。
6. 最后删除不再需要的旧分类。

一次只迁移一个类别，便于核对。不要先删除旧父级再尝试找回原来的镜头集合。

## 父级为什么仍显示已赋值

子关键字同时属于父级。镜头只有人物 > 嘉宾时，人物分类也能找到它；想让镜头完全离开人物类别，需要检查并移除相关直接赋值和子级赋值。

## 删除前的核对

节点删除提示中的使用数量帮助评估影响，仍需检查父级下的子分类。仅当前镜头不适用时，取消勾选或移除赋值即可；不要删除整个项目分类。

误操作后立即撤销，再检查其他视频的赋值。确认无误后保存项目。
