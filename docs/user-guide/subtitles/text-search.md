# 按文字查找字幕

记得对白原词时，使用文字查找。文字搜索不需要语义检索组件，结果取决于字幕中实际存在的文字。

## 按文字查找对白

1. 在搜索框输入一句对白或若干关键词。
2. 选择**过滤**，只保留匹配结果；或选择**高亮**，在完整上下文中标记匹配项。
3. 选择匹配规则。
4. 必要时叠加星级、旗标、色标或编辑状态筛选。
5. 在源监视器中核对结果，再决定是否选用。

| 规则            | 适用任务               |
| --------------- | ---------------------- |
| 包含            | 查找含任一输入词的字幕 |
| 包含所有        | 要求所有输入词都出现   |
| 包含单词        | 按词匹配所有输入条件   |
| 不含            | 排除含输入词的字幕     |
| 开头为 / 结尾为 | 按完整输入匹配首尾     |
| 为空 / 不为空   | 按是否具有文字筛选     |

高亮模式提供上一个、下一个匹配按钮和序号跳转，到两端后循环。在匹配序号输入框中按 **Enter** 跳转，按 **Esc** 放弃编辑。计数按匹配条目计算。高亮保留非匹配项；如果只想全选匹配字幕，应切换到过滤模式。

高级排除、时长、正则和最近搜索见[设置高级搜索条件](/subtitles/advanced-search)。

## 根据已知线索选择规则

| 线索                     | 建议规则       | 示例与结果                      |
| ------------------------ | -------------- | ------------------------------- |
| 只记得几个词，任一词都可 | 包含           | 输入“预算 成本”，包含任一词即可 |
| 需要同时谈到两个概念     | 包含所有       | 输入“预算 拍摄”，两词都要出现   |
| 只找完整英文单词         | 包含单词       | 输入“cat”不会按词命中“category” |
| 明确知道整条字幕         | 完全相等       | 文字需与一个完整字段一致        |
| 排除某类说法             | 不含           | 输入不希望出现的词              |
| 寻找固定句式             | 开头为、结尾为 | 用完整输入检查字段首尾          |

“包含单词”依赖文字边界，不会自动把连续中文切成词。搜索中文短语时通常先用包含或包含所有，避免因为边界要求漏掉结果。

## 在上下文与结果集合之间切换

- **高亮**适合逐项阅读上下文：保留其他条目，使用匹配导航检查结果。
- **过滤**适合批量标注和导出：隐藏不匹配项，再选择可见结果。
- 切换保留查询。计数按匹配条目计算，同一行出现多次也不是多条对白。

例如先用高亮找到“我们再讨论预算”，听完上下文后切到过滤，再选择本轮要保留的对白。

## 没有结果时依次检查

1. 用一个确定存在的短词替换长句，排除标点和换行差异。
2. 检查是否选中了正确视频和字幕语言。
3. 检查规则，特别是完全相等、包含单词和首尾条件。
4. 打开高级条件，检查大小写、排除内容和时长。
5. 清除旗标、星级、标签、编辑状态和仅展示选中等独立条件。

仍为空时，先返回未筛选列表确认文字是否存在。只记得含义时，改用字幕语义搜索。
