# 重新链接、替换和断开媒体

项目通过文件位置寻找媒体。磁盘断开、目录移动或文件更名后，应恢复连接；明确更换内容版本时，使用替换素材。

## 重新链接媒体

1. 接好素材磁盘，确认文件可访问。
2. 在媒体箱选择脱机条目，右键选择**链接媒体…**。
3. 在链接窗口中选择剪辑，单击**附加**并选择对应文件。
4. 检查成功标记，再处理剩余项。
5. 完成后在源监视器核对画面与声音，并保存项目。

**跳过**略过当前项，**全部跳过**结束整批；取消不会撤回已成功完成的链接。

开启**使用媒体浏览器附加文件**可在应用内浏览；关闭后使用系统文件选择器。

### 自动重新链接其他媒体

开启此选项后，选择一个文件会同时在其所在目录中查找其他素材，不搜索子目录。可按文件名、扩展名、媒体开始或磁带名称限制匹配。

1. 先确认其他待链接文件确实位于同一目录。
2. 根据素材特征选择匹配条件。
3. 执行附加并逐项检查成功状态。
4. 对同名或相似文件，抽查实际内容。

同名文件较多时，关闭自动重新链接并逐条附加。匹配属性缺失时，减少不适用的条件，并以实际画面核对为准。

## 替换或暂时断开素材

### 替换素材

1. 先保存项目副本。
2. 选择一个在线文件，执行**替换素材…**。
3. 选择同类的新文件。
4. 检查既有分镜、切点、标注和轨道关系是否仍适用。

替换适合明确的新版本或修正版本。内容或时长变化后，不要默认旧镜头边界仍然正确。

### 设为脱机

选择**设为脱机…**可暂时断开项目连接，不会删除磁盘文件。恢复时使用链接媒体命令。

## 链接前先定位正确文件

1. 连接素材盘，在系统中确认目标文件确实可访问。
2. 区分原视频、代理、转码副本和修订版本。
3. 查看文件名、时长、起始信息和内容，避免附加同名不同片段。
4. 目录层级变更较大时，先逐项恢复一组，再决定是否自动匹配。

## 自动匹配不成功时

自动链接只在所选文件所在目录寻找其他文件。子目录中的素材应分别定位。匹配属性缺失或不一致时，过多限制可能阻止匹配；同名素材较多时，限制过少又可能引入错误。

选择符合素材实际情况的条件，完成后抽查，不能只看成功标记判断内容正确。

## 替换与重新链接的区别

| 操作     | 目的           | 核对重点                           |
| -------- | -------------- | ---------------------------------- |
| 重新链接 | 找回原来的文件 | 内容、时长、轨道是否对应           |
| 替换素材 | 改用另一个版本 | 旧切点、标注和绑定是否仍准确       |
| 连接代理 | 增加预览副本   | 代理与原始媒体的内容和时间是否一致 |

新版本时长或内容不同，不能默认旧分镜仍准确。先保存副本，再替换并检查。

## 部分链接成功后取消

取消不会撤回已经完成的链接。返回媒体箱检查哪些仍脱机，逐项继续处理；无需把成功项再次断开。最后预览代表性画面和声音，再保存项目。
