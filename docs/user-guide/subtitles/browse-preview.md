# 浏览、排序和预览字幕

字幕列表把对白与视频时间对应起来。用列表找到线索后，在源监视器检查声音和前后画面，再决定是否采用。

## 阅读、排列与预览

字幕列表包含缩略图、字幕、匹配度、媒体开始、媒体结束、媒体持续时间、星级、留用和标签等信息。多来源时还显示来源列。

- 单击列标题排序；再次单击可改变方向。
- 拖动列边界调整宽度，或调整缩略图大小。
- 单击条目在源监视器中跳转并预览对应片段。
- 当前面板包含正在播放的媒体时，列表随播放位置自动定位。

字幕与分镜面板的来源范围可以不同。只要包含正在播放的媒体，两者都会跟随该媒体的播放位置；字幕按该媒体的帧率和当前载入的字幕轨定位。跟随播放不会替换面板来源、改变所选条目或解除作用域锁定。

### 连续相同字幕的显示方式

同一轨道中，文字完全相同且时间相接或重叠的连续字幕，会自动显示为一个完整片段。不同轨道或中间有时间空隙的字幕保持分开。

合并不影响原始字幕文件；预览、选择和导出使用显示片段的完整范围。格式样式和换行可能以便于阅读的文字形式显示。

## 认识列表字段

| 字段               | 核对内容                                   |
| ------------------ | ------------------------------------------ |
| 字幕               | 当前片段的文字，排版可能简化为可读文字     |
| 媒体开始、媒体结束 | 在来源媒体中的位置，用于区分重复出现的对白 |
| 媒体持续时间       | 当前显示片段的长度，也是时长筛选使用的范围 |
| 匹配度             | 语义搜索中与当前描述的相关程度             |
| 星级、留用、标签   | 你保存的整理判断，可用于后续筛选           |
| 来源               | 多视频时显示，帮助识别对白所属视频         |

## 按工作目的排序

1. 按叙述顺序阅读时，按媒体开始排序。
2. 挑选完整长句时，按媒体持续时间排序，再试听。
3. 比较语义结果时，按匹配度排序。
4. 多来源按来源正序或倒序时，先分组再按其他列排列；来源排序设为无，可跨视频统一比较。
5. 再次单击表头改变方向；拖动列边界，为字幕正文留出空间。

排序改变浏览顺序，不会改写字幕时间。按匹配度排好的列表也不代表故事的叙述顺序。

## 选择与跟随播放的区别

单击字幕用于选择或预览；播放跟随用于把当前播放位置带入列表视野。跟随不会把正在播放的行自动变成你的候选集合。

比较相隔较远的对白时，可先暂停播放，再滚动列表核对。恢复播放后，面板继续跟随当前媒体的位置。

## 调整底部显示

打开底部**更多选项**，可以分别显示或隐藏选中、喷涂工具、排序、旗标、星级、色标和缩略图大小。隐藏工具区只改变界面安排，已经应用的标记或筛选条件仍需单独核对。

## 列表与字幕文件条数不一致时

先检查连续相同字幕是否合并显示，再检查搜索、星级、标签和仅展示选中等条件。不要为增加行数而重复导入同一文件。合并行被选中或导出时使用整个显示片段；删除该行也会处理它包含的原始条目。
