# 使用直方图和帧迹图审看分镜

帧数据为审看提供另一组线索：直方图观察当前画面的颜色分布，帧迹图沿镜头范围展示画面变化。图表适合帮助定位，最终判断仍以实际画面为准。

## 查看帧数据

右侧**帧数据**默认显示**直方图**，用于查看源播放器当前画面的颜色分布。标题左侧的下拉选项可切换为**动势、四色、清晰度**帧迹图，同一区域每次显示一种图表。

暂停时将指针移到帧迹图上可预览对应帧，单击可定位。计算失败时，使用状态旁的**重新计算**重试。

单击分组标题可收起图表，再次展开时保留所选类型；重新创建面板后默认显示直方图。帧数据用于辅助审看，最终选择仍应结合实际画面。

## 选择图表

| 图表   | 适合观察               | 接下来怎么核对                 |
| ------ | ---------------------- | ------------------------------ |
| 直方图 | 当前帧颜色分布         | 回看实际画面的亮暗和颜色       |
| 动势   | 镜头内运动变化线索     | 检查动作起止和明显运动位置     |
| 四色   | 镜头内色彩变化线索     | 查看场景、光线或主体颜色的变化 |
| 清晰度 | 镜头内清晰程度变化线索 | 放大画面检查失焦、模糊或细节   |

图表不能单独决定曝光、对焦或内容质量，也不代替正式技术检测。

## 结合帧迹图检查镜头

1. 选择一个分镜，在源监视器打开。
2. 展开右侧帧数据，选择所需图表。
3. 暂停播放，在帧迹图不同位置悬停预览。
4. 单击可疑位置，逐帧检查实际画面。
5. 需要改变切分时，到源监视器调整切点；只记录判断时使用标记。

例如动势变化可以提示动作可能开始，但是否保留该段，还要看动作完整性、构图与声音。

## 收起、切换和重新计算

同一区域每次显示一种图表。单击标题收起后，再展开会保留类型；重新创建面板后默认回到直方图。

计算失败时先检查来源和原始媒体连接，再使用重新计算。大量任务运行时先查看进度，避免把等待当作失败。

## 审看后的处理

帧数据帮助定位，并不会自动替你加星、留用或修改切点。检查完成后把判断写入标题、标签或旗标并保存项目，才能在后续筛选中复用。
