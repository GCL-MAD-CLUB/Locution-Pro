# 通过字幕找到片段

适合查找采访、课程或节目中已经有字幕的对白。知道原话时可按文字搜索，只记得主题时可按含义搜索。找到结果后，应播放前后内容，确认语句完整且声画对应。

本流程不会自动听写音频，也不会把画面中的烧录字幕转换为可搜索文字。没有字幕时，可使用[按画面查找镜头](/workflows/find-visuals)。

## 准备字幕

1. 导入视频，在字幕面板的来源菜单中展开该视频。
2. 使用内嵌文字字幕时，直接选择需要的轨道。
3. 使用外部字幕时，先将 SRT、ASS、SSA、VTT 或 WebVTT 文件导入并绑定到对应视频。
4. 选择字幕轨，试听开头、中间和结尾，确认文字、声音和画面时间相符。
5. 跨视频查找时，继续勾选其他视频的字幕轨；同一视频一次选择一条轨道。

字幕列表为空时，检查媒体是否在线、轨道是否启用以及绑定目标是否正确。位图字幕不能用于文字或语义检索。

## 按原话或关键词查找

1. 在搜索框输入一句对白或若干关键词。
2. 选择**过滤**只保留匹配结果；需要查看前后条目时选择**高亮**。
3. 根据已知信息选择规则：
   - **包含**：命中任一输入词即可。
   - **包含所有**：要求所有输入词都出现。
   - **开头为 / 结尾为**：定位特定句式。
   - **不含**：排除包含指定文字的结果。
4. 使用上一个、下一个匹配按钮逐项核对；高亮模式到两端后会循环。
5. 结果过多时，在**高级**中添加排除内容、时长范围或其他规则。

::: tip 全选搜索结果前
高亮模式仍显示非匹配项。若要全选搜索结果并批量标注或导出，请先切换到**过滤**模式。
:::

## 只知道主题时按含义查找

1. 确认已安装**语义检索**组件。
2. 将搜索模式设为**语义**。
3. 输入想找的主题或表达，例如“讨论如何控制拍摄预算”。
4. 首次使用时，等待字幕检索准备完成。
5. 从匹配度较高的结果开始试听，必要时降低阈值扩大结果，或提高阈值缩小结果。

语义搜索查找已有字幕的含义，不要求结果包含完全相同的原词。含义相近也不代表语境适合，因此必须核对前后对白。

## 核对上下文并留下标记

1. 单击条目预览对应片段，注意句子是否从中间开始或在结尾被截断。
2. 按实际用途选择**留用**或**排除**旗标，并用星级记录优先级。
3. 需要保留分类时，使用色标或自定义标签；两者互斥。
4. 使用**仅展示选中字幕**核对候选集合。
5. 按 **Ctrl + S** 保存项目，将标注保留下来。

文字和时间完全相接或重叠的连续相同字幕可能显示为一个完整片段。预览和导出会使用显示片段的完整范围，不会改写原始字幕文件。

## 选择并导出片段

1. 按住 **Ctrl** 选择不连续片段，或按住 **Shift** 选择连续范围。
2. 选择**文件 → 导出…**，核对左侧列表中的勾选项和顺序。
3. 逐段预览，拖动蓝色括号微调入点和出点，保留完整语句及必要停顿。
4. 要逐段交付时关闭**合并为一个文件**；要按列表顺序拼接时开启。
5. 设置格式、输出位置和命名规则，导出后检查声音、画面和片段边界。

此处调整只影响待导出范围，不改变原字幕时间。导出文件也不会自动保存项目，整理结果仍需单独保存。

## 处理一组访谈的示例

先为每个访谈视频选择同一语言的字幕轨，用包含搜索“预算 成本”收集线索，再用语义搜索补找未出现原词的表达。对符合主题的条目标记留用，清空查询后按标记复核，最后逐句试听并输出。

全文字操作见[按文字查找字幕](/subtitles/text-search)；需要排除词、限制时长或复用整套查询时，见[高级搜索条件](/subtitles/advanced-search)。
