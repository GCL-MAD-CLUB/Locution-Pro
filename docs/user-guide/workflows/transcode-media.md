# 转码媒体文件

转码页面用于把媒体文件转换为其他格式，例如把 MKV 转为 MP4、生成 ProRes 中间文件、提取音频，或把字幕转换为 SRT、ASS、WebVTT。转码与分镜、字幕整理互不影响，结果可以直接交给文件管理器，也可以放入当前项目的 `encoder` 媒体箱以便后续使用。

## 打开转码页面

单击窗口右上角的**转码**。页面分为四个区域：

| 区域       | 用途                                                 |
| ---------- | ---------------------------------------------------- |
| 媒体箱     | 显示当前项目的素材，右键选择**添加到转码队列**       |
| 队列       | 列出待转码的源文件及每个输出的格式、预设、位置和状态 |
| 监视文件夹 | 自动把放入指定文件夹的新媒体加入队列                 |
| 预设浏览器 | 浏览、应用、新建、导入和导出预设                     |
| 编码       | 显示正在进行的转码、已用时间和剩余时间               |

## 添加要转码的文件

- 在队列中单击**添加源**，选择一个或多个文件。
- 在媒体箱中选择素材，右键选择**添加到转码队列**。
- 导入素材时，**导入设置 → 组织媒体**中的**在转码页面打开导入素材**默认开启；导入完成后素材会进入转码队列并自动切换到转码页面。不需要时取消勾选即可回到编辑页面。

新加入的文件沿用上一次使用的预设和输出位置。

## 选择输出位置

每个输出都必须选择输出位置，未选择时状态显示**待设置**，队列不会开始编码。

- **文件夹**：输出写入所选文件夹，可在文件管理器或 Finder 中直接使用。
- **项目媒体箱中的 encoder 文件夹**：输出写入项目文件旁的 `encoder` 文件夹，完成后自动加入项目媒体箱的 `encoder` 媒体箱。项目尚未保存时，文件写在源文件旁的 `encoder` 文件夹。

在队列中选择一个或多个输出后，可在队列上方统一修改输出位置。

## 调整导出设置

单击输出的格式或预设打开**导出设置**。左侧设置格式、预设、注释、输出名称、输出位置和需要导出的视频、音频、字幕，并显示输出与源的摘要；右侧按页签调整细节：

| 页签       | 内容                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------- |
| 效果       | 色调映射、LUT、图像叠加、文本叠加、时间码叠加、时间调谐器、视频限幅器、响度标准化              |
| 视频       | 编码器、尺寸与缩放方式、帧速率、像素格式、去隔行、编码速度、配置文件、级别、比特率与关键帧间隔 |
| 音频       | 编码器、采样速率、通道、比特率和要保留的音轨                                                   |
| 多路复用器 | 封装格式、扩展名和快速启动                                                                     |
| 字幕       | 转换并封装、复制字幕流、录制到视频或导出为独立字幕文件                                         |

格式、编码器和字幕格式的下拉列表包含当前 FFmpeg 支持的全部选项，常用项排在最前，例如格式依次为 MP4、MKV、MOV、WebM 等。切换格式后，不兼容的编码器和字幕方式会自动改为可用选项。选择**流复制**可以不重新编码直接换封装，速度最快且不损失画质，但缩放、效果和录制字幕需要重新编码。

字幕支持 SRT、ASS、SSA、WebVTT、TTML 等文本格式。录制到视频时会保留 ASS 字幕的样式；PGS、DVD 等位图字幕只能录制到视频或复制到 MKV。也可以选择外部字幕文件代替源内嵌字幕。

**源范围**可只转码其中一段。调整后可单击**保存预设…**，以后在预设浏览器中直接使用。

## 使用预设

预设浏览器按 H.264、HEVC、Apple ProRes、DNxHR、AV1、WebM、换封装、仅音频、字幕和 GIF 分组。双击预设，或选中后单击**应用预设**，即可应用到队列中所选输出；也可以把预设拖到队列中的源或输出上。当前 FFmpeg 不支持的预设显示为灰色。

自己保存的预设显示在**用户预设及组**中，可以导出为 `.lcpreset` 文件交给其他设备导入。

## 开始与停止

单击队列右上角的**启动队列**，就绪的输出按顺序编码。单击**停止队列**会取消当前编码并删除未完成的文件，其余输出保持就绪。失败的输出可在选中后单击**重置状态**重新编码。完成的输出不会覆盖已有同名文件，而是自动在文件名后添加序号。

## 监视文件夹

1. 在**监视文件夹**页签单击**添加监视文件夹**。
2. 为文件夹选择预设和输出位置，默认输出到其中的 `Output` 文件夹。
3. 勾选**自动对监视文件夹编码**后，复制完成的新媒体会自动加入队列并开始编码；也可单击**立即扫描**手动加入。

每个文件只会被加入一次。正在复制的文件会等大小稳定后再处理。
