# 生成代理以流畅预览

当高分辨率或高码率视频播放不流畅时，可以为它创建较轻量的代理文件。代理用于减轻预览负担，原始素材仍应妥善保留，用于镜头检测、画面检索准备和通常的正式交付。

## 开始前

- 确认视频原始文件在线，并已在媒体箱中启用。
- 检查代理目标磁盘有足够空间和稳定连接。
- 先用一段素材测试代理尺寸与格式，再逐个处理其他视频。
- 如果素材本身无法读取或编码不受支持，先解决媒体问题；代理不能修复损坏文件。

## 创建代理

1. 在媒体箱选择一个在线视频；当前创建代理一次处理一个视频。
2. 右键选择**代理 → 创建代理…**。
3. 选择帧大小：完整、二分之一、四分之一或自定义尺寸。
4. 选择代理预设，例如 H.264 MP4、H.264 QuickTime、VP8 WebM 或 VP9 WebM。
5. 选择输出位置：原始媒体旁的代理文件夹、自行指定的文件夹，或首选项中的缓存位置。
6. 提交创建，在顶部进度区等待任务完成。

| 设置       | 选择建议                                                                 |
| ---------- | ------------------------------------------------------------------------ |
| 帧大小     | 越小的尺寸通常越轻量，但细节也越少；需要检查细小物体或文字时不要过度缩小 |
| 编码与格式 | 先用常用预设测试播放流畅度；需要频繁定位时可比较 All-Intra 预设          |
| 输出位置   | 批量工作时使用固定代理目录，便于备份和移交；缓存位置适合本机临时使用     |

代理需要额外存储空间。任务取消后，可能已经生成部分文件，应检查输出位置和项目中的代理连接状态。

## 切换并检查代理预览

1. 在媒体箱双击视频，打开源监视器。
2. 在预览来源菜单中选择**代理**。
3. 检查开头、中间和结尾，确认画面内容、时长和声音与原始媒体对应。
4. 逐帧定位几处，确认预览响应是否满足审看需要。
5. 如画面过于模糊，重新评估代理尺寸，或在需要核对细节时切回**完整**。

预览来源只改变当前查看所用的文件，不会替换或删除原始素材。

## 原始文件暂时脱机时

原始媒体脱机而已连接的代理在线时，仍可继续预览和审看。需要恢复完整媒体时：

1. 连接原始素材磁盘。
2. 在媒体箱选择条目，使用**链接媒体…**，或使用**代理 → 重新连接完整分辨率媒体…**。
3. 重新选择对应原视频。
4. 切回**完整**预览，并核对内容与时长。

仅有代理时不能完成镜头检测、画面检索准备或原始分辨率静帧导出。

## 准备正式输出

- 快速审核文件可在导出设置中开启**使用代理**。
- 正式画面交付通常应关闭**使用代理**，并确认原始素材在线。
- 开启使用代理不会自动创建缺失的代理；需先创建或连接。
- 输出后核对清晰度、范围、声音和画面内容，避免把审核文件误作正式成片。

## 代理没有改善预览时

先确认源监视器确实切换到了代理，且连接的是本次生成的文件。若仍响应缓慢，检查代理盘连接，比较更小尺寸或其他预设；不要只重复生成相同设置。

如需更换或附加已有代理，按[创建、连接和管理代理](/media/create-proxies)操作。只有原视频脱机时，先判断当前任务是否允许仅使用代理。
