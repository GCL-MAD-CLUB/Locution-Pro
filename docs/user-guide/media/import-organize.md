# 导入和整理媒体

将视频、音频、图像和可选字幕加入项目后，即可开始预览、整理与导出。导入默认使用原文件位置；需要集中保管时，开启复制媒体。媒体箱用于项目内分类，移动其中的条目不会移动磁盘文件。

## 开始前

- 确认文件类型受支持，原文件可以正常读取。
- 将素材放在稳定目录；使用外接磁盘时，保持连接直至导入和后续处理完成。
- 如需复制导入，检查目标位置和可用空间。
- 如需导入到项目所在目录，先保存项目，使其具有正式路径。

## 浏览并选择素材

从磁盘或收藏位置浏览文件，使用类型筛选、搜索、排序和列表或缩略图视图选择素材。选文件夹时等待扫描完成，再检查待导入栏。

详细操作见[浏览和选择待导入文件](/media/browse-files)。

## 设置组织方式

可添加到新媒体箱、复制并校验素材，以及自动绑定音频或字幕。复制后项目引用新文件；虚拟复制只新增项目条目，不复制磁盘文件。

详细操作见[设置导入组织、复制和自动绑定](/media/copy-media)。

## 完成导入并核对

等待扫描完成后提交导入，到编辑工作区检查条目、画面和轨道。失败项可能留在待导入栏，修正后重试。

详细操作见[设置导入组织、复制和自动绑定](/media/copy-media)。

## 在媒体箱中整理

使用多级媒体箱、搜索、排序和列表字段管理项目媒体。项目条目的重命名、移动、复制和删除不等同于磁盘文件操作。

详细操作见[创建和管理媒体箱](/media/organize-bin)。

## 管理媒体连接

原文件被移动或磁盘未连接时，条目可能显示脱机。请使用**链接媒体…**重新选择文件，或为大文件[创建代理](/media/offline-proxies)。

导入后不要随意重命名或移动原文件。确需调整目录时，记录新位置，并在项目中重新链接和核对内容。
