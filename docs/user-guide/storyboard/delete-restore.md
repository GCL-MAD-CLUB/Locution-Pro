# 删除和恢复分镜

删除用于改变项目中的分镜集合，排除旗标用于保留镜头但记录不采用。两者都不会从原始视频删除画面，应按工作目的选择。

## 删除与恢复

**删除**移除所选分镜并保留原时间位置。源监视器以斜线显示该区间，连续播放时会跳过；仍可手动定位，并从切点菜单恢复。

**波纹删除**让后续镜头起点前移，覆盖被删除区间，不提供相同的独立恢复入口。它不会删除源视频中的画面，也不会改写媒体文件。需要回退时使用撤销。

如果只是暂不采用某个镜头，设置排除旗标即可。恢复步骤见[恢复普通删除的分镜](/source/source-monitor#恢复普通删除的分镜)。

## 选择处理方式

| 需求                           | 操作     | 继续使用时                   |
| ------------------------------ | -------- | ---------------------------- |
| 这轮不采用，后面可能再看       | 排除旗标 | 调整旗标过滤重新显示         |
| 从分镜集合移去，保留可恢复区间 | 删除     | 在源监视器选中已删除切点恢复 |
| 移去并让后续范围覆盖该区间     | 波纹删除 | 回退时使用撤销               |

## 执行删除

1. 保存项目副本，确认当前来源。
2. 展开相关堆叠并检查选择，避免只看代表项就批量处理。
3. 使用删除或 Delete；需要波纹处理时使用 Shift + Delete。
4. 查看源监视器，检查剩余镜头的时间边界。
5. 重新核对用于导出的候选集合。

普通删除区间在源监视器中以斜线显示。连续播放会跳过，手动定位仍可查看原画面。

## 恢复普通删除的区间

1. 在源监视器显示切点。
2. 单击对应删除区间的切点；需要时使用 Ctrl 或 Shift 多选。
3. 右键选择从选中的切点恢复。
4. 返回分镜面板核对条目和标记。
5. 保存项目。

所选切点必须均属于已删除区间，命令才可用。混入普通切点时，先重新选择。

## 波纹删除后检查

波纹删除会改变删除区间之后保留镜头的起点，而不是剪短原视频。检查受影响镜头的开头、时长以及标题和关键字是否仍然准确。

它没有与普通删除相同的独立恢复入口。需要还原时使用撤销；已继续大量编辑时，先保存当前副本，再考虑从早期项目恢复。
