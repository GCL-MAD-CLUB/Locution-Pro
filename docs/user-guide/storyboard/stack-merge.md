# 堆叠和合并镜头

多个相关镜头可以组成堆叠，方便折叠浏览；同一视频中连续相邻的镜头也可以合并为一个分镜条目。两种操作对镜头边界的影响不同。

## 组合和拆开镜头

### 合并镜头与堆叠

合并会移除镜头之间的切点，将范围作为一个镜头处理。堆叠则保留各镜头，以可折叠集合显示，适合将同一段落的画面集中浏览。

选择至少两个可组合镜头，使用右键菜单中的相应命令。合并要求同一视频内的所选镜头在原始时间线上连续相邻，不能跨过未选中镜头、已删除区间或时间空隙；排序、过滤和堆叠不会放宽此限制。

跨多个视频选择时，合并与堆叠分别在各视频内进行；任一视频的选择不满足相邻条件时，整次合并不可用。需要跨视频拼接时，使用合并导出。

### 使用堆叠菜单

| 命令                | 结果                         |
| ------------------- | ---------------------------- |
| 组成堆叠            | 将选择组成可折叠集合         |
| 展开 / 折叠堆叠     | 查看内部镜头或收起为代表项   |
| 展开全部 / 折叠全部 | 统一调整当前来源中的堆叠显示 |
| 从堆叠中移去        | 让所选成员恢复为独立镜头     |
| 拆分堆叠            | 以所选成员为界拆开分组       |
| 取消堆叠            | 解除整个分组                 |

## 先选择合适的操作

| 目的                         | 操作               | 对边界的影响               |
| ---------------------------- | ------------------ | -------------------------- |
| 将同一段落的多个画面收拢浏览 | 组成堆叠           | 保留独立镜头               |
| 撤掉误识别的镜头分界         | 合并镜头或清除切点 | 独立条目合为一个范围       |
| 把多个视频的候选拼成审看片   | 合并导出           | 不改项目镜头，只生成新文件 |

## 建立并核对堆叠

1. 在当前视频中选择相关镜头。
2. 使用组成堆叠命令。
3. 先保持展开，核对成员和各自标记。
4. 折叠后检查代表项，继续浏览其他内容。
5. 批量标记或导出前，展开确认需要处理哪些成员。

堆叠适合管理镜头集合，不代表这些镜头已被拼成一个成片。展开全部和折叠全部调整当前来源的显示。

## 合并为什么不可用

即使两个条目在当前列表中挨在一起，它们在视频原时间线上也可能不相邻。以下情况不能据此合并：

- 中间还有未选择的镜头。
- 搜索或排序隐藏了中间条目。
- 中间是已删除区间或时间空隙。
- 多视频选择中，有任一视频不满足相邻条件。

先按来源和媒体开始检查，再决定补选相邻镜头，或改为堆叠、合并导出。不要为启用命令而删除中间镜头。

## 拆开与恢复

从堆叠中移去让成员独立显示；取消堆叠解除整个分组；拆分堆叠以所选成员为界分开组。合并后的镜头需要重新添加切点才能再成为独立分镜，原标记应重新核对。

需要撤销误合并时立即使用 Ctrl + Z。大批量整理前保存副本，以保留原来的边界和分类方案。
