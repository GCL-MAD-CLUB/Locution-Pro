# 使用分镜

分镜将视频呈现为可预览、检索和标注的镜头条目。即使视频没有字幕，也可以完成本页全部操作。整理结果保存后可继续用于筛选和导出。

## 生成分镜

1. 在媒体箱选择原始文件在线、已启用的视频。
2. 打开**分镜**面板，在来源菜单选择视频。新增来源尚无分镜时，会自动开始识别。
3. 需要主动识别时，单击标题行最右侧的剪刀按钮**切分**或**重新切分**。
4. 等待顶部进度结束，在列表或图标视图中查看结果。

也可以在媒体箱多选视频，右键选择**分镜识别**。识别需要原始视频在线；仅有代理可预览时，请先重新连接原始媒体。

自动识别后请检查明显的误切和漏切，尤其是淡入淡出、叠化和快速运动画面。需要修正时，在[源监视器](/source/source-monitor#调整分镜切点)中添加、移动或清除切点。

### 重新识别已有分镜

| 选项 | 对已有工作的影响                                               |
| ---- | -------------------------------------------------------------- |
| 合并 | 保留现有划分与整理，补充识别出的新切点；检查新镜头的边界和标记 |
| 覆盖 | 重建分镜，清除旧删除记录、堆叠和镜头标注                       |
| 取消 | 保留现有分镜，不执行本次识别                                   |

准备覆盖前请保存项目副本。如果识别期间继续修改了相关镜头，完成时可能再次要求选择处理方式。

## 浏览和选择镜头

使用面板底部控件切换**列表**或**图标**视图，并调整缩略图大小。列表适合比较标题、时间、时长、关键字与星级；图标视图适合快速审看画面。单击表头或使用排序菜单改变顺序。

- 单击行或卡片可选择镜头并定位到开始位置。
- 单击缩略图画面或双击条目，可播放该镜头范围。
- **Ctrl + 单击**增减不连续选择，**Shift + 单击**选择连续范围。
- 在空白区域拖动可框选；方向键可移动选择。
- **编辑 → 全选**选择当前筛选后可见的镜头。
- **仅展示选中分镜**可集中核对候选集合。

图标信息区域的右键菜单可选择显示标题、编号、时间、星级或标签。面板底部**更多选项**用于显示或隐藏常用工具。

### 同时查看多个视频

在来源菜单勾选多个视频，可集中检索和标注。列表会出现**来源**列：按来源正序或倒序排列时，先分组，再按其他列排序；将来源排序设为**无**可跨视频统一排序。

取消最后一个来源后，面板显示**未选择**。重新选择来源即可继续查看。使用标题行的**锁定作用域**固定来源，详见[来源工作区与导航历史](/workspace/workspace#来源工作区与导航历史)。

## 用描述查找画面

搜索栏右侧的**高级**打开高级搜索弹窗。弹窗包含模式、字段范围和规则；单击**应用**生效，**取消**或 Esc 放弃修改。匹配度阈值在搜索栏右侧调整。

在语义模式中，每行输入一条正向描述，匹配其中任意一条即可获得较高得分；反向描述用于降低不希望出现的画面的得分。分别取正向与反向的最高匹配度，按 `max(0, 正向最高分 − 反向最高分)` 计算最终得分，再按阈值筛选。反向描述留空时按 0 计算，分镜预览使用正向最高分对应的帧。

例如，正向填写“海边的日落”和“夕阳下的沙滩”，反向填写“拥挤的人群”。快捷搜索框用 `|` 分隔全部正向描述，例如 `海边的日落|夕阳下的沙滩`；打开高级搜索后每行一条，两处均可编辑完整内容。描述中的空格保留，连续的 `|` 和空行不产生空描述；清空快捷搜索框会清空全部正向描述。切换模式保留搜索内容。

正向、反向描述各限 10 个非空项，每项最多 1000 字符（ASCII 字符计 1，中文等非 ASCII 字符计 2）。同侧相同描述只检索一次。高级搜索弹窗会校验输入，正反向描述重复等错误会在弹窗内提示并标红对应输入框，修正后可应用；搜索栏不显示错误提示或错误样式。清空搜索框会同时清除查询和高级条件（反向描述、排除内容、区分大小写与时长范围）。

文字过滤和高亮支持同时配置搜索内容与排除内容、区分大小写、完全相等及正则表达式。排除内容每行一项，按字面匹配；正则不带两侧 `/` 和标志，按选定的标题或关键字字段匹配。两类搜索均可设置最短、最长时长（秒，包含边界），与已有星级、旗标和标签筛选共同生效。

高级入口只在当前模式使用了快捷栏无法显示的条件时点亮：时长范围、文字模式的区分大小写或排除内容、语义模式的反向描述。**重置**在应用后恢复搜索默认值，不改变来源、选择和其他筛选。条件随当前面板的来源工作区保留，未保存到项目文件。

过滤和高亮模式中，搜索内容的换行与空格等效，应用时连续空白合并为一个空格；再次打开高级搜索时，搜索框里的空白分隔显示为换行。正则中的 `|` 仍按正则语法处理。

安装语义检索组件后，可使用**语义**搜索。它按画面内容查找镜头，无需先填写标题或关键字。

1. 选择需要搜索的视频来源。
2. 将搜索模式设为**语义**，输入具体画面描述，例如“室外行走的人群”。
3. 首次使用时，等待语义检索初始化和分镜索引构建完成。
4. 查看匹配度靠前的结果，并在源监视器中核对。
5. 调整阈值缩小或扩大结果集合。

阈值默认是 0.001，越高越严格。分镜匹配度显示五位小数，阈值可调整到三位小数。匹配度用于比较相关性，不代表识别正确的概率。结果过少时，降低阈值或使用更简洁的描述。

图标视图会显示镜头中最符合查询的画面，并以竖线提示其时间位置。列表缩略图区域会并列显示原画面与命中画面；命中画面用于查看，原缩略图保留预览操作。清空搜索或切换模式后，恢复普通缩略图。

准备过程可取消，之后可重新尝试。视频较长或素材较多时需要等待。相关示例见[按画面查找镜头](/workflows/find-visuals)。

## 图谱视图

单击面板底部的**图谱视图**按钮，按画面语义浏览分镜。每个圆点代表一个分镜。普通筛选、语义检索阈值、仅显示选中和删除等操作改变可见分镜后，图谱会为当前可见节点重新连边，避免隐藏中间节点后出现孤岛。更新期间保留画面，节点、连线和全景图从当前位置平滑过渡到新布局，带有轻微回弹；连续筛选会接续当前运动。

左上角可切换**指针**和**手型**工具。手型用于拖动画布，不能选择节点；悬停时，当前节点和直接相连的邻居仍会显示缩略图，邻居缩略图半透明，越靠近当前节点的越靠上。

指针用于选择，可滚轮缩放或通过右下角全景图移动显示区域，不能直接拖动主图平移。单击选择一个节点；双击选择该节点及直接相连的邻居；按住鼠标左键并拖动可框选，选择框经过的节点会实时更新选中状态。按 **Esc** 可取消框选并恢复开始前的选择。工具旁的四个按钮分别执行**替换选择、添加到选择、从选择中减去、与选择交集**，同时适用于单击、双击和框选。

缩放比例低于 0.8 CSS 像素/画布单位时，节点大小随缩放变化；达到 0.8 后，节点的屏幕半径和边框尺寸保持不变，节点间距仍随画布放大。选中不会改变圆点或其边框的尺寸。悬停时放大到 1.1 倍，移开后还原，放大、还原、节点与连线颜色及淡化、缩略图的淡入淡出均使用同步的 120ms 缓动，进入或离开立即开始响应。淡出的缩略图不再接收鼠标操作。选中节点使用与悬停相同的灰度颜色，外围显示同色圆环，内外圆在缩放和平移时保持同心。节点的屏幕直径不超过 8px 时，圆环间隔为 1px；超过后，间隔随节点大小按比例增加，线宽始终为 1px。选中节点持续显示缩略图。指针悬停未选中节点时，会显示自身的缩略图，并为直接相连、原本未显示缩略图的邻居补充 60% 不透明度的缩略图；已有的选中缩略图不会因此变淡。悬停已选节点不会额外展开邻居。源播放器仅在点击或双击节点时定位到对应分镜，框选、悬停和切换选择模式不会改变播放位置。

悬停节点时，该节点显示在节点的最上层。指针模式下，已选节点和直接悬停节点自身的缩略图可在悬停缩略图时置顶；未选中且未直接悬停节点的 60% 邻居缩略图不会因悬停缩略图而置顶。悬停已选节点或已选缩略图时，其余已显示缩略图的不透明度降为 60%；悬停未选缩略图时，它及直接相连节点的已显示缩略图保持原亮度，其余降为 60%。这只调整透明度，不增加或隐藏缩略图，也不改变选择或播放器位置。手型模式的缩略图始终按与当前节点的距离排列，悬停缩略图不会改变层级，邻居预览规则保持不变。

缩放比例小于等于 0.4 CSS 像素/画布单位时，暂停悬停高亮并隐藏所有缩略图，包括已选节点的缩略图；选择状态保留，放大超过此比例后恢复应显示的缩略图。

图谱支持现有的筛选、旗标、星级、色标和关键字控制，隐藏排序与缩略图大小控制。旗标、星级和关键字图标显示在缩略图内部左上角，仅用于查看；通过底部控件或关键字面板修改。色标同时显示在节点和缩略图上，节点的悬停、选中圆环与变淡规则保持一致。指针移到缩略图上时，会按横向位置预览镜头画面，与标签视图相同。

图谱中可启用底部的**喷涂工具**。单击节点喷涂该分镜，双击喷涂该节点及直接相连的邻居；按住并拖动显示虚线框，松开时喷涂框内节点。也可在已显示的缩略图上单击或双击喷涂。喷涂不会改变选中节点或播放器位置；框选时按 **Esc** 可取消。属性选择、**Alt** 擦除、**Shift** 关键字吸管及撤销沿用原有喷瓶规则。点击左上角指针或手型工具可退出喷涂。

图谱依赖分镜语义检索组件。首次进入时会自动构建缺失的语义索引，可在任务面板查看进度或取消；取消或失败后可单击**重新生成图谱**重试。筛选和删除复用已有向量及两两相似度，只重建可见图的连接和布局，不显示重建进度。单纯删除分镜还会复用语义检索得分，不重复构建索引或执行相同查询；新增或内容改变的分镜才需要补充索引。

图谱自动过滤较弱的连线，最低相似度和每点连线数上限由程序固定设置，不提供输入。每个分镜始终保留得分最高的一条连线，不受阈值限制；仅有一个分镜时不生成连线。其余连线按相似度从高到低保留，最高分保底连线优先于连线数上限。

如果稀疏化后出现互不连通的分组，程序会为每组选择它与外部节点相似度最高的一条连线，并在合并后继续检查，直到完整图谱连通。这些跨组连线不受最低相似度和连线数上限限制。

同一分镜有多个选帧时，图谱会综合这些画面，用连线牵引、圆点间的排斥和碰撞间距排列位置。悬停会突出当前分镜及直接相连的邻居，其他未选中的圆点和连线变淡。连线表示画面内容相近，圆点间的距离仅用于辅助浏览。

画布按完整图谱的边界计算：先求出能容纳所有圆点的最小 16:9 矩形，再将宽、高各扩展 20%。连线数为 1–3 条的圆点大小相同，此后每增加一条连线，半径略微增大；碰撞半径始终大于圆点半径。

两种工具均可滚动鼠标滚轮，以指针位置为中心缩放；手型模式下可拖动主图平移。最大缩放为每画布单位 2 CSS 像素，同尺寸的圆点在不同规模图谱和面板中达到 0.8 比例后，显示大小相同。小图达到缩放上限后不会继续放大填满面板。

右下角始终显示 16:9 全景图，其中的矩形框表示当前显示区域，比例随面板尺寸变化。两种模式下，均可单击全景图定位、拖动矩形框移动显示区域，或在全景图上滚轮缩放。平移受画布边界限制；小图无法填满显示区域时会居中，全景图同步包含周围的空白区域。主图或全景图获得键盘焦点后，可用加减键缩放、数字 0 恢复初始显示；全景图获得焦点时，两种模式均可用方向键平移，主图的方向键平移仅在手型模式下可用。

## 按文字和标记筛选

### 文字搜索

从搜索范围选择**任何可搜索的字段**、**标题**或**关键字**。关键字范围支持完整路径和同义词。

| 模式或规则          | 用途                                               |
| ------------------- | -------------------------------------------------- |
| 过滤                | 只保留匹配项                                       |
| 高亮                | 保留上下文，用上一个、下一个按钮或匹配序号浏览结果 |
| 包含                | 查找包含任一输入词的条目                           |
| 包含所有 / 包含单词 | 要求所有输入词满足对应匹配条件                     |
| 不含                | 排除包含输入词的条目                               |
| 开头为 / 结尾为     | 按输入的完整文字匹配字段首尾                       |
| 为空 / 不为空       | 查找未填写或已填写的字段                           |

高亮模式不会隐藏非匹配项；此时全选可能包含这些镜头。只需匹配结果时，请切换到过滤模式后选择。

搜索框获得焦点时会显示最近搜索，可用上下方向键选择并按 Enter 使用。结果随输入更新；离开搜索框后记录最终的非空查询，应用高级搜索或修改快捷设置会更新对应记录。选择记录会恢复模式、范围、规则、匹配度和全部高级条件。

最近搜索保存在当前电脑，字幕和分镜分别记录；每个面板又分为**语义**和**过滤／高亮**两个空间，各保留最近使用的 6 项。记录文字按搜索栏规则生成，同样的文字只保留一项，重新使用或修改配置会更新并移到最前。含高级条件的记录在文字后显示蓝色 `*`，星号不进入搜索栏。

### 标记过滤

组合旗标、星级、色标和已编辑状态，逐步缩小范围。已编辑包括自定义标题、关键字和其他标记。

在关键字树中启用节点右侧的快捷过滤，可按分类筛选；同时启用多个节点时，结果须全部满足。详见[使用关键字](/storyboard/use-keywords)。

## 标记与批量审核

| 标记             | 用法                             |
| ---------------- | -------------------------------- |
| 标题             | 简短描述镜头，便于搜索与导出命名 |
| 星级             | 用 0–5 星记录质量或优先级        |
| 旗标             | 留用、排除或无旗标               |
| 色标与自定义标签 | 按工作约定分类；两者互斥         |
| 关键字           | 按人物、地点、动作等建立层级分类 |

单击已选镜头的文字单元格并稍候，或双击相应文字，编辑标题、关键字和标签。按 **Enter** 或移开焦点保存，按 **Esc** 取消。标题编辑只针对当前镜头。

选中多个镜头后，使用底部工具或右键菜单批量标注。对折叠堆叠操作时，应展开检查其成员是否都符合本次标记要求。

### 喷涂标记

1. 单击底部喷瓶，选择**关键字、标签、旗标**或**星级**。
2. 设置要应用的值，在镜头缩略图上单击或拖动。
3. 关键字、标签和旗标模式按住 **Alt** 可擦除；星级设为 0 可清除。
4. 关键字模式按住 **Shift** 可选择最近使用的关键字。
5. 单击完成或空喷瓶退出。

一次连续拖动可以整体撤销。退出喷涂后再进行普通选择。

## 组合和拆开镜头

### 合并镜头与堆叠

合并会移除镜头之间的切点，将范围作为一个镜头处理。堆叠则保留各镜头，以可折叠集合显示，适合将同一段落的画面集中浏览。

选择至少两个可组合镜头，使用右键菜单中的相应命令。跨多个视频选择时，合并与堆叠分别在各视频内进行；需要跨视频拼接时，使用合并导出。

### 使用堆叠菜单

| 命令                | 结果                         |
| ------------------- | ---------------------------- |
| 组成堆叠            | 将选择组成可折叠集合         |
| 展开 / 折叠堆叠     | 查看内部镜头或收起为代表项   |
| 展开全部 / 折叠全部 | 统一调整当前来源中的堆叠显示 |
| 从堆叠中移去        | 让所选成员恢复为独立镜头     |
| 拆分堆叠            | 以所选成员为界拆开分组       |
| 取消堆叠            | 解除整个分组                 |

## 删除与恢复

**删除**移除所选分镜并保留原时间位置。源监视器以斜线显示该区间，连续播放时会跳过；仍可手动定位，并从切点菜单恢复。

**波纹删除**让后续镜头起点前移，覆盖被删除区间，不提供相同的独立恢复入口。它不会删除源视频中的画面，也不会改写媒体文件。需要回退时使用撤销。

如果只是暂不采用某个镜头，设置排除旗标即可。恢复步骤见[恢复普通删除的分镜](/source/source-monitor#恢复普通删除的分镜)。

## 查看帧数据

右侧**帧数据**默认显示**直方图**，用于查看源播放器当前画面的颜色分布。标题左侧的下拉选项可切换为**动势、四色、清晰度**帧迹图，同一区域每次显示一种图表。暂停时将指针移到帧迹图上可预览对应帧，单击可定位。

单击分组标题可收起图表，再次展开时保留所选类型；重新创建面板后默认显示直方图。帧数据用于辅助审看，最终选择仍应结合实际画面。

整理完成后，参阅[导出媒体](/export/exporting)。
