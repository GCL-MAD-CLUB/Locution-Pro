# 更新与获取帮助

通过**帮助**菜单可以检查更新、打开本指南、定位日志，以及查看应用版本和法律声明。更新检查需要网络连接；即使暂时无法检查，也可以继续使用当前版本。

## 检查更新

选择**帮助 → 更新…**。应用会检查适用于当前版本的正式版更新，并显示以下状态之一：

| 状态                     | 含义与可执行操作                 |
| ------------------------ | -------------------------------- |
| 有新版本且更新包已准备好 | 阅读版本说明，选择立即更新或稍后 |
| 有新版本但自动更新不可用 | 前往发布页下载完整安装包         |
| 当前已是最新版本         | 关闭提示，继续当前工作           |
| 暂时无法检查更新         | 检查网络后选择重试，或关闭提示   |

手动检查期间不会重复派发另一个检查请求。预发布版本不通过此入口请求正式版更新。

## 安装已准备的更新

1. 阅读新版本号、当前版本和更新说明。
2. 如不希望启动时再次看到同一版本提示，勾选**不再提示此版本**。
3. 单击**立即更新**；有未保存更改时，按钮显示**保存后更新**。
4. 按提示保存项目。若取消保存或项目在保存期间发生变化，更新不会继续启动。
5. 等待正在写入的项目操作结束，以及当前任务允许更新。
6. 更新包关闭应用并开始更新，完成后重新打开软件。

更新包在显示可安装状态前已下载并校验。若当前任务尚未结束，先等待任务完成，不要强制关闭应用。

选择**稍后**只关闭本次提示，不安装已经准备好的更新。

## 阅读更新后的版本说明

更新并重新启动后，应用可能显示本次版本说明。阅读后选择**完成**，已确认的启动说明不会重复显示。

启动时如同时存在上次更新失败、更新完成说明和新版本提示，应用会按顺序展示，先处理较早的安装结果，再查看后续提示。

## 自动更新不可用或安装失败

### 可以检查到版本，但无法准备更新包

选择**前往发布页**，下载对应完整安装包。下载、校验或更新信息不完整时，会保留这一手动更新方式。

### 已准备的更新无法启动或完成

1. 阅读更新失败提示，保留当前应用和项目。
2. 选择**前往发布页下载**。
3. 下载完整安装包。
4. 运行安装程序，选择修复或重新安装。
5. 启动后检查项目、素材连接和设置。

自动更新失败不会要求你删除项目或原始素材。使用完整安装程序维护的方法见[安装与首次启动](/getting-started/install#更新、修复或并行安装)。

## 打开在线帮助

选择**帮助 → Locution Pro 帮助…**，在默认浏览器中打开本指南。需要网络连接。

也可以使用帮助中心顶部的搜索，或从各页面的“继续阅读”进入相关任务。

## 查看版本、鸣谢和法律声明

选择**帮助 → 关于 Locution Pro…**：

- 查看应用名称和当前版本号。
- 阅读开发、设计、测试、贡献与鸣谢信息。
- 单击其中的外部链接，在系统浏览器中打开对应页面。
- 选择**法律声明**，查看许可证和第三方软件声明。
- 选择**返回**回到关于信息，或按 **Esc** 关闭。

反馈问题时，提供这里的版本号有助于确认所用环境。

## 打开日志位置

选择**帮助 → 显示日志文件…**，打开日志所在文件夹。反馈前应选择对应时段的日志，并检查其中是否包含需要遮去的路径或项目名称。完整步骤见[查看与提供日志文件](/troubleshooting/troubleshooting#查看与提供日志文件)。

## 更新后继续项目

1. 在关于窗口确认当前版本。
2. 打开一份重要项目副本，检查原始媒体与代理连接。
3. 查看关键分镜、字幕标记和关键字是否符合预期。
4. 检查首选项中的保存、缓存和工具位置。
5. 下次导出前重新核对格式、命名与输出目录。

更新应用不等于重新导入素材。组件选择变化时，先确认需要的检索能力是否可用，再重新提交任务。
