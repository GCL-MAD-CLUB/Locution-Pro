# 安装与首次启动

安装前请确认电脑满足[系统要求](/getting-started/system-requirements)，并关闭正在处理重要项目的应用窗口。

## 安装应用

1. 从[官方下载页面](https://github.com/GCL-MAD-CLUB/LineCut/releases/latest)取得 Windows 安装程序。
2. 运行安装程序，按提示选择安装位置。
3. 首次使用建议选择**内置 FFmpeg**，以便直接导入、预览、生成代理和导出媒体。
4. 在**语义检索**页保留组件勾选，以便按画面描述和对白含义搜索。该组件需要额外磁盘空间。
5. 在**确认安装**页核对目录、媒体工具和语义检索选项，再开始安装。符合数据迁移条件时，可在此选择是否复制 LineCut 数据。
6. 完成安装，从开始菜单或桌面快捷方式启动 Locution Pro。

未安装语义检索组件时，搜索菜单不会显示**语义**模式，其他整理和导出功能仍可使用。需要添加组件时，可重新运行安装程序调整选择；自动更新会保留原有组件选择。

如需使用自行安装的媒体工具，可在安装时填写 `ffmpeg.exe` 的完整路径，同目录必须有 `ffprobe.exe`；填写 `ffmpeg` 可从 PATH 查找。安装器检查文件位置，不运行这些外部工具。稍后也可在**编辑 → 首选项 → 媒体工具**中分别设置两个工具的路径。

## 首次设置

启动后默认显示项目首页，可新建项目、打开 `.lcp` 文件或选择最近项目。单击右上角主页按钮，可随时返回首页。

开始工作前，打开**编辑 → 首选项**：

- 确认媒体缓存位置有足够可用空间。
- 确认自动保存已开启，并选择稳定的自动保存位置。
- 使用外部媒体工具时，检查两个工具的路径。

完成后单击**确定**，继续[创建第一个项目](/getting-started/first-project)。

## 从 LineCut 继续工作

Locution Pro 可与 LineCut 同时安装，请分别使用各自的安装目录。已有 `.lcp` 项目可以通过**打开项目**选择；首次保存前建议保留原文件副本。

当前用户首次安装且电脑上没有既有 Locution Pro 数据时，安装程序可能显示**迁移旧数据**页，将可用的 LineCut 设置和用户数据复制到 Locution Pro。迁移前关闭 LineCut，并预留额外存储空间。原数据会保留，两款软件后续的设置和数据各自维护。为所有用户安装时，不自动迁移个人数据。

等待复制和校验完成即可。失败时可选择**重试**；不需要继续时，选择**跳过迁移并完成安装**并阅读确认提示。跳过后，后续安装不会自动继续复制剩余数据。中断的首次安装可重新运行安装程序尝试继续。

已正常使用 Locution Pro、保留其数据后重新安装或覆盖安装时，不会再次自动导入 LineCut 数据。不要为了重新迁移而删除已有工作；需要使用的项目可直接打开。

## 更新或更换电脑

更新前保存项目并保留重要项目副本。更新后核对素材连接、代理和输出设置。更换电脑时，同时复制项目文件和原始素材；具体步骤见[移交项目](/projects/projects#移交项目)。

检测到已安装版本时，**已安装**页面按版本显示维护选项。选择**更新现有安装**或**修复或调整已安装组件**后，先选择安装位置与组件，再确认安装。依赖检查完成后才替换旧应用文件，无需运行旧版卸载程序；设置、缓存和项目会保留。同版本安装包也可选择只卸载应用。

更新时会校验并复用匹配的内置组件，仍会显示组件选择页，方便调整选择。需要替换的组件会重新安装，已经移除的旧组件会清理。选择**保留旧程序，另选目录安装**时，旧版文件保留，新副本接管应用注册、快捷方式和打开方式；两份 Locution Pro 使用相同的用户数据，并非互相隔离的工作环境。

替换旧文件前，安装器会保留恢复备份；安装失败时尝试恢复旧文件。若提示自动恢复未完成，请保留安装目录中的 `.locution-pro-rollback-*` 文件夹及其中的 `transaction.json`，不要手动删除。这些文件也可能在断电或强制结束安装器后留下，应先恢复旧文件，再继续替换或卸载此副本。

若提示操作已完成、部分旧备份暂未清理，可以继续使用、更新或卸载应用。这类备份已标记为 `committed`，不属于待恢复的安装；详情记录在安装目录的 `.locution-pro-cleanup-*.txt` 中。

安装包内的卸载始终保留应用设置、缓存及用户数据。单独运行当前副本的卸载程序时，可选择**删除应用程序数据**；不勾选则保留数据。保留的旧副本不能删除当前副本的注册信息或共享用户数据。若提示组件被占用，请关闭相关程序后重试；安装器不会把可能被重装复用的文件路径加入重启删除队列。
