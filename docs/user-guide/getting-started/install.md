# 安装与首次启动

安装前请确认电脑满足[系统要求](/getting-started/system-requirements)，保存正在处理的项目，并关闭仍在使用相关文件的应用窗口。首次安装建议同时准备足够的组件、缓存和素材存储空间。

## 安装应用

1. 从[官方下载页面](https://locution.dpdns.org/#download)取得 Windows 安装程序。
2. 运行安装程序，按提示选择安装位置。
3. 在组件页选择所需的媒体工具和语义检索能力。
4. 在**确认安装**页核对目录、组件和可用选项，再开始安装。
5. 符合数据迁移条件时，按需要选择是否复制 LineCut 数据。
6. 等待安装完成，从开始菜单或桌面快捷方式启动 Locution Pro。

### 选择媒体工具

首次使用建议选择**内置 FFmpeg**，以便直接导入、预览、生成代理和导出媒体。

如需使用自行安装的媒体工具：

- 可填写 `ffmpeg.exe` 的完整路径，同目录必须有 `ffprobe.exe`。
- 填写 `ffmpeg` 可从 PATH 查找。
- 安装器检查文件位置，不运行这些外部工具。
- 稍后可在**编辑 → 首选项 → 媒体工具**中分别设置两个工具的路径。

### 选择语义检索组件

在**语义检索**页保留组件勾选，即可按画面描述和对白含义搜索。该组件需要额外磁盘空间。

未安装时，搜索菜单不会显示**语义**模式，其他整理和导出功能仍可使用。需要添加组件时，可重新运行安装程序调整选择；自动更新会保留原有组件选择。

## 根据用途选择安装内容

| 计划完成的工作             | 安装时检查                         | 安装后去哪里                                                                    |
| -------------------------- | ---------------------------------- | ------------------------------------------------------------------------------- |
| 导入、预览、创建代理和导出 | 内置媒体工具，或已准备好的外部工具 | [首选项](/projects/preferences#媒体工具)                                        |
| 人工审看与关键字分类       | 基础应用与媒体工具                 | [检测和整理分镜](/storyboard/storyboards)                                       |
| 按画面或对白含义查找       | 语义检索组件                       | [画面检索](/storyboard/semantic-search)、[字幕检索](/subtitles/semantic-search) |
| 继续旧项目                 | 原项目副本及原始素材可访问         | [保存与恢复项目](/projects/save-recover)                                        |

组件选择决定可用能力，不会自动准备你的项目素材。安装完成后，先用一个项目核对导入和预览，再开展大量工作。

## 完成首次设置

启动后默认显示项目首页，可新建项目、打开 `.lcp` 文件或选择最近项目。单击右上角主页按钮，可随时返回首页。

开始导入前，打开**编辑 → 首选项**：

1. 在**媒体缓存**中确认缓存位置有足够可用空间。
2. 在**自动保存**中确认功能已开启，并选择稳定的保存位置。
3. 使用外部媒体工具时，在**媒体工具**中检查两个程序的路径。
4. 单击**确定**保存设置。
5. 将原始素材放在稳定目录，再继续[创建第一个项目](/getting-started/first-project)。

项目文件与原始素材分别保管。首次设置完成后，不需要为每个项目重复安装组件。

## 从 LineCut 继续工作

Locution Pro 可与 LineCut 同时安装，请分别使用各自的安装目录。已有 `.lcp` 项目可以通过**打开项目**选择；首次保存前建议保留原文件副本。

### 迁移旧数据

当前用户首次安装且电脑上没有既有 Locution Pro 数据时，安装程序可能显示**迁移旧数据**页，将可用的 LineCut 设置和用户数据复制到 Locution Pro。

1. 关闭 LineCut，并预留额外存储空间。
2. 阅读迁移内容，选择是否复制。
3. 等待复制和校验完成。
4. 启动应用后，检查项目、设置和素材连接。

原数据会保留，两款软件后续的设置和数据各自维护。为所有用户安装时，不自动迁移个人数据。

迁移失败时可选择**重试**；不需要继续时，选择**跳过迁移并完成安装**并阅读确认提示。跳过后，后续安装不会自动继续复制剩余数据。中断的首次安装可重新运行安装程序尝试继续。

已正常使用 Locution Pro 并保留其数据后，重新安装或覆盖安装不会再次自动导入 LineCut 数据。不要为了重新迁移而删除已有工作；需要使用的项目可直接打开。

## 更新、修复或并行安装

更新前保存项目并保留重要项目副本。更新后核对素材连接、代理和输出设置。更换电脑时，同时复制项目文件和原始素材；具体步骤见[移交项目](/projects/projects#移交项目)。

检测到已安装版本时，**已安装**页面按版本显示维护选项：

| 选项                     | 用途与结果                                   |
| ------------------------ | -------------------------------------------- |
| 更新现有安装             | 替换所选副本的应用文件，保留设置、缓存和项目 |
| 修复或调整已安装组件     | 重新选择位置与组件，修复缺失内容或调整安装   |
| 保留旧程序，另选目录安装 | 保留旧版文件，并安装一个新副本               |
| 卸载                     | 移除应用；是否删除用户数据取决于卸载时的选择 |

选择更新或修复后，先选择安装位置与组件，再确认安装。依赖检查完成后才替换旧应用文件，无需运行旧版卸载程序。同版本安装包也可选择只卸载应用。

更新时会校验并复用匹配的内置组件，仍会显示组件选择页。需要替换的组件会重新安装，已经移除的旧组件会清理。

选择并行安装时，新副本接管应用注册、快捷方式和打开方式；两份 Locution Pro 使用相同的用户数据，并非互相隔离的工作环境。

### 安装中断或恢复提示

替换旧文件前，安装器会保留恢复备份；安装失败时尝试恢复旧文件。若提示自动恢复未完成，请保留安装目录中的 `.locution-pro-rollback-*` 文件夹及其中的 `transaction.json`，不要手动删除。这些文件也可能在断电或强制结束安装器后留下，应先恢复旧文件，再继续替换或卸载此副本。

若提示操作已完成、部分旧备份暂未清理，可以继续使用、更新或卸载应用。这类备份已标记为 `committed`，不属于待恢复的安装；详情记录在安装目录的 `.locution-pro-cleanup-*.txt` 中。

## 卸载应用

安装包内的卸载始终保留应用设置、缓存及用户数据。单独运行当前副本的卸载程序时，可选择**删除应用程序数据**；不勾选则保留数据。

保留的旧副本不能删除当前副本的注册信息或共享用户数据。若提示组件被占用，请关闭相关程序后重试；安装器不会把可能被重装复用的文件路径加入重启删除队列。

::: warning 删除数据前
卸载应用不等于备份项目。选择删除应用程序数据前，确认正式项目、原始素材和需要保留的自动保存文件已有独立副本。
:::
