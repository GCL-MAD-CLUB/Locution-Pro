# 创建第一个项目

使用一段容易辨认内容的视频，完成从素材导入到片段交付的基本流程。视频无需包含字幕；先选择较短的素材，可以更快了解完整操作。

本示例依次完成四件事：建立项目、导入视频、整理镜头、导出片段。

## 开始前

- 完成[安装与首次启动](/getting-started/install)。
- 准备一段可以正常播放的视频，并保留原文件备份。
- 确认项目、缓存和输出位置有足够空间。
- 如需按画面描述搜索，确认已安装语义检索组件。

## 创建并保存项目

1. 在项目首页选择**新建项目**，或选择**文件 → 新建项目**。
2. 按 **Ctrl + S**，为项目命名并选择 `.lcp` 文件的保存位置。
3. 将原始素材放在稳定的文件夹中；项目文件需要与素材一起妥善保管。

先保存项目可以在导入时选择“与项目相同”的复制位置，也能让后续保存路径更明确。

## 导入视频

1. 切换到顶部**导入**工作区。
2. 浏览素材所在文件夹，勾选视频。也可选择文件夹，等待子文件夹扫描结束。
3. 如需把素材集中放入一个项目分类，开启**添加到新媒体箱**并输入名称。
4. 如需集中保管素材，开启**复制媒体**并选择目标位置；继续使用原位置时保持关闭。
5. 单击**导入**，等待登记完成。
6. 切换到**编辑**工作区，在项目媒体箱中确认视频条目和预览。

复制导入后，项目使用复制后的文件。请在确认副本可正常预览后，再决定如何处理原文件。更多选项见[导入和整理媒体](/media/import-organize)。

## 浏览和寻找镜头

1. 在媒体箱双击视频，并打开**窗口 → 分镜**。
2. 在分镜来源菜单中选择视频；尚无分镜时会开始识别。
3. 等待顶部任务完成，切换到图标视图浏览画面。
4. 单击缩略图预览完整镜头，确认自动切分是否合适。
5. 若已安装语义检索组件，将搜索模式设为**语义**，输入“室外行走的人群”等具体画面描述。
6. 首次搜索需要等待准备完成；从匹配度较高的结果开始审看。

没有语义检索组件时，仍可浏览分镜、编辑标题、添加关键字并按文字筛选。完整示例见[按画面查找镜头](/workflows/find-visuals)。

## 整理并选择候选镜头

1. 选中所需镜头，按 **P** 设置留用旗标，或按 **0–5** 设置星级。
2. 为镜头添加容易复用的关键字，例如“人物 > 嘉宾”或“地点 > 室外”。
3. 按住 **Ctrl** 选择多个镜头；按住 **Shift** 选择连续范围。
4. 清空搜索后，按留用旗标或关键字筛选，检查候选集合。
5. 按 **Ctrl + S** 保存整理结果。

关键字描述画面内容，星级和旗标记录采用价值。保存项目不会复制原始素材。

## 导出片段

1. 保持镜头选中，选择**文件 → 导出…**。
2. 在导出列表中核对勾选项、顺序和总时长，逐段预览。
3. 需要调整片头片尾时，拖动蓝色括号微调入点和出点。
4. 选择输出文件夹、格式和命名规则；常规视频交付可先使用 **H.264 / MP4**。
5. 要生成一个文件，开启**合并为一个文件**；要逐镜头交付，关闭此选项。
6. 正式输出通常关闭**使用代理**，并确认原始素材在线。
7. 单击**导出**，完成后在输出文件夹检查画面、声音和片段边界。

导出会生成新媒体文件，项目仍需单独保存。完整设置见[导出媒体](/export/exporting)。

## 检查本次练习是否完成

完成这次练习后，应能确认以下结果：

- 媒体箱中能找到原视频，并能正常预览。
- 分镜列表有可检查的镜头边界，所选片段与实际画面对应。
- 清空查询后，仍能用留用、星级或关键字找到候选。
- 项目保存为正式文件，原始素材也在稳定位置。
- 输出目录中有预期数量的文件，内容、声音和边界符合本次选择。

某一步不符合预期时，返回对应主题处理即可，无需重新建立整个项目。后续可以从[分镜概览](/storyboard/storyboards)或[字幕概览](/subtitles/subtitles)按具体任务继续学习。

## 完成后可以做什么

- 校正误切或漏切：[使用源监视器](/source/source-monitor#调整分镜切点)。
- 建立更完整的素材分类：[整理分镜并建立关键字](/workflows/organize-storyboard)。
- 已有对白字幕时：[通过字幕找到片段](/workflows/find-dialogue)。
- 大文件预览不流畅时：[生成代理以流畅预览](/workflows/create-proxy)。
- 保存副本、恢复自动保存或移交项目：[创建和管理项目](/projects/projects)。
