# 添加、移动和清除切点

自动检测完成后，可在源监视器修正误切与漏切。切点操作改变项目的分镜集合，开始前先确认当前为编辑工作区的分镜模式。

## 调整分镜切点

切点表示一个镜头的开始位置。编辑前确认当前为**编辑**工作区的分镜模式。大批量修改前建议保存项目副本。

### 显示和添加切点

1. 右键时间标尺，开启**显示切点**；需要时显示时间标尺数字。
2. 单击已有切点可定位，右键菜单可转到上一个或下一个切点。
3. 将播放头定位到镜头内部。
4. 单击播放按钮左侧的添加切点图标，或右键选择**添加切点**。
5. 回到分镜面板，确认一个镜头已分为两段。

媒体首尾和已有切点处不能重复添加。

### 移动与精确编辑

直接拖动切点修正位置。按住 **Ctrl** 或 **Shift** 多选后，拖动其中一个可整体移动；切点不能越过相邻边界。

需要精确输入时：

1. 右键选择**编辑切点…**。
2. 填写允许范围内的时间码。
3. 使用**上一个 / 下一个**继续检查相邻切点。
4. 确认修改，并在分镜面板核对结果。

### 清除切点

- 右键选择**清除所选的切点**，合并相邻镜头。
- **清除切点**处理当前范围内的切点。
- 编辑切点对话框也可删除当前切点。

合并后独立镜头数量和标记会变化。执行批量清除前保存副本，完成后检查标题、关键字和星级。

## 恢复普通删除的分镜

普通删除的分镜区间以斜线显示，连续播放时会跳过，但可手动查看原画面。

1. 单击已删除区间的切点，可用修饰键多选。
2. 右键选择**从选中的切点恢复**。
3. 回到分镜面板检查镜头和标记，并保存项目。

只有所选切点均属于已删除区间时，该命令才可用。波纹删除不提供此恢复方式，应使用撤销。

## 按问题选择操作

| 发现的问题                   | 操作               | 检查结果                 |
| ---------------------------- | ------------------ | ------------------------ |
| 一个条目包含两次明显场景变化 | 在漏切位置添加切点 | 新分镜范围和两侧内容     |
| 切换画面早于或晚于边界       | 移动或精确编辑切点 | 相邻两段是否完整         |
| 同一连续镜头被多次拆开       | 清除多余切点       | 合并后标题和标记是否适用 |
| 多个切点整体偏移             | 多选后整体拖动     | 是否接近其他相邻边界     |

## 精确校正的工作顺序

1. 定位到疑似转场，逐帧核对变化。
2. 选中切点，使用编辑切点输入时间码。
3. 在允许范围内确认，避免越过相邻切点。
4. 播放前后两个镜头，检查动作和声音。
5. 返回分镜面板核对标题、关键字和星级。
6. 保存项目。

多选整体移动适合统一的小幅修正。边界受相邻镜头限制，无法拖动到期望位置时先检查邻近切点，不要连续清除不相关边界。

## 编辑范围与导出范围

拖动编辑工作区中的分镜边界，会改变项目切点并影响相邻镜头。只想本次输出多留片头片尾时，改到导出工作区拖动蓝色括号。

字幕原始范围只供查看，不能借分镜切点工具修改字幕时间。导出范围支持独立调整。

## 撤销与保存

误修改后立即撤销，或在历史记录中返回先前状态。清除切点合并镜头后，需要重新核对分类与标注；保存项目副本便于保留原来的切分方案。
