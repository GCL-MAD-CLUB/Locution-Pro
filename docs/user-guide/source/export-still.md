# 从视频导出静帧

需要把视频中的一帧作为图片保存时，使用源监视器的导出帧。它从原始视频读取当前画面，适合保留构图参考或可继续使用的静态素材。

## 导出当前帧

在编辑工作区的分镜模式中，播放按钮右侧的摄像机图标用于**导出帧**。

1. 定位到所需画面，单击摄像机图标；播放暂停。
2. 确认名称，默认包含媒体名称、时间码和 Still 编号。
3. 选择 BMP、DPX、GIF、JPEG、OpenEXR、PNG、Targa 或 TIFF，默认 PNG。
4. 单击**浏览…**选择输出文件夹。
5. 需要继续在项目中使用时，勾选**导入到项目中**。
6. 单击**确定**，并在输出位置检查图片。

静帧读取原视频并使用原始分辨率，即使正在查看代理。原始媒体脱机时请先重新链接；同名图片不会被覆盖。

## 导出前准备

- 确认当前打开正确视频并位于所需时间。
- 先逐帧检查，避免把转场中间帧或运动模糊帧误作目标。
- 确认原始文件在线；当前查看代理也不改变这一要求。
- 选择可写且便于查找的输出目录。

## 选择格式与名称

PNG 是默认选项；需要其他交付格式时，先确认接收软件支持，再选择 JPEG、TIFF 或相应专业格式。选择格式不会增加原视频中不存在的画面细节。

默认名称包含媒体名、时间码和 Still 编号，便于追溯位置。需要手动命名时保留足够的来源线索。同名图片不会覆盖已有文件。

## 将静帧加入项目

勾选导入到项目中后，导出的图片也会加入项目。它仍是独立磁盘文件，移动项目文件不会一起带走图片；移交项目时应同时复制需要的静帧。

导入图像不意味着图像具有视频的自动分镜或播放能力。

## 结果与预期不一致时

1. 检查视频与时间位置是否正确。
2. 检查是否只是预览缩放造成显示大小不同。
3. 确认输出使用原始视频分辨率。
4. 打不开专业格式时，更换接收软件支持的格式。
5. 没有生成文件时，检查来源连接、输出位置和任务提示。
