# 标记和筛选分镜

分镜标记记录内容与采用价值。你可以给一个镜头写标题，给多个镜头统一设置星级或旗标，再用筛选找到适合当前交付的候选。

## 组合旗标、星级和标签筛选

过滤器区域可组合以下条件：

- **旗标**：留用、无旗标或排除。
- **编辑**：已编辑或未编辑；已编辑包括自定义标题、关键字和其他标记。
- **星级**：选择 1–5 星，并将比较方式设为**大于等于、小于等于**或**等于**。
- **颜色**：按色标或自定义标签筛选。

在关键字树中启用节点右侧的快捷过滤，可按分类筛选；同时启用多个节点时，结果须全部满足。详见[使用关键字](/storyboard/use-keywords)。

## 标记与批量审核

| 标记             | 用法                             |
| ---------------- | -------------------------------- |
| 标题             | 简短描述镜头，便于搜索与导出命名 |
| 星级             | 用 0–5 星记录质量或优先级        |
| 旗标             | 留用、排除或无旗标               |
| 色标与自定义标签 | 按工作约定分类；两者互斥         |
| 关键字           | 按人物、地点、动作等建立层级分类 |

单击已选镜头的文字单元格并稍候，或双击相应文字，编辑标题、关键字和标签。按 **Enter** 或移开焦点保存，按 **Esc** 取消。标题编辑只针对当前镜头。

选中多个镜头后，使用底部工具或右键菜单批量标注。右键菜单还可直接添加快捷关键字、调整星级或进入导出。对折叠堆叠操作时，应展开检查其成员是否都符合本次标记要求。

### 喷涂标记

1. 单击底部喷瓶，选择**关键字、标签、旗标**或**星级**。
2. 设置要应用的值，在镜头缩略图上单击或拖动。
3. 关键字、标签和旗标模式按住 **Alt** 可擦除；星级设为 0 可清除。
4. 关键字模式按住 **Shift** 可选择最近使用的关键字。
5. 单击**完成**或空喷瓶退出。

一次连续拖动可以整体撤销。退出喷涂后再进行普通选择。

## 为项目制定标注约定

| 信息             | 适合记录           | 例子                       |
| ---------------- | ------------------ | -------------------------- |
| 标题             | 当前镜头的具体内容 | 嘉宾拿起产品并向观众展示   |
| 关键字           | 可跨镜头复用的类别 | 人物 > 嘉宾、动作 > 展示   |
| 旗标             | 本轮采用判断       | 留用、排除、尚未决定       |
| 星级             | 优先级或质量等级   | 5 星为首选，3 星为可用备用 |
| 色标或自定义标签 | 工作状态           | 待核对、待补录、备选       |

以上为示例约定，应用不会自动判断质量。色标与自定义标签互斥，需要同时记录其他维度时可使用关键字。

## 批量审核前检查

1. 明确当前视频来源和搜索条件。
2. 退出喷涂模式后再建立普通选择。
3. 在过滤模式选择本轮条目，高亮模式全选仍包含非匹配项。
4. 堆叠处于折叠状态时，先展开确认成员。
5. 应用标记后清除部分筛选，检查是否影响了额外条目。

标题编辑针对当前镜头，不会因为多选而给每个镜头填写相同标题。需要批量分类时优先使用关键字、旗标和标签。

## 连续审核与自动前进

用 P、X、U 设置留用、排除或无旗标，用 0–5 设置星级，用 6–9 设置红、黄、绿、蓝色标。按住 Shift 标注，或开启 Caps Lock 后标注，可前进到下一项。

先在当前排序下确认前进方向。输入框获得焦点时，字母和数字用于文字输入，不触发标记。

## 从标记建立候选集合

例如寻找“嘉宾出镜、已留用且至少 4 星”的镜头：启用嘉宾关键字快捷过滤，选择留用，把星级比较设为大于等于并选择 4 星。

结果数量小于预期时，检查文字查询、语义阈值、时长、标签、编辑状态和仅展示选中。清空查询不会自动撤掉所有独立过滤器。

## 保存审核进度

一轮审核结束后保存项目。下次打开时重新选择来源，再按标注继续。临时选择和最近查询只方便浏览，长期采用判断应写入项目标记。
