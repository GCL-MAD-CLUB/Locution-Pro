# 浏览、排序和选择分镜

分镜面板既可逐镜头审看，也可集中比较多个视频。先选择适合任务的视图和排列方式，再决定批量标记或导出的范围。

## 选择浏览视图

使用面板底部的视图按钮切换：

| 视图     | 适合的任务                                                       |
| -------- | ---------------------------------------------------------------- |
| 标签视图 | 以表格比较标题、匹配度、时间、时长、关键字、星级、旗标和标签     |
| 图标视图 | 以缩略图快速审看画面，并预览命中帧                               |
| 图谱视图 | 按画面关系比较镜头，通过聚类和框选批量整理；需要分镜语义检索组件 |

标签和图标视图可调整缩略图大小。表格视图可单击表头排序，也可拖动列分隔线调整宽度。

图谱的准备、画布导航和选择模式见[使用分镜图谱](/storyboard/graph)。

### 设置图标信息

图标信息区域的右键菜单可选择：**无、星级和标签、索引编号、标题、媒体开始、媒体结束、媒体时长、星级**或**标签**。这只改变卡片显示的信息，不改变镜头内容或标记。

### 调整底部工具

面板底部**更多选项**可分别显示或隐藏**视图模式、选中、喷涂工具、排序、旗标、星级、色标**和**缩略图大小**。

## 浏览和选择镜头

- 单击行或卡片可选择镜头并定位到开始位置。
- 单击缩略图画面或双击条目，可播放该镜头范围。
- **Ctrl + 单击**增减不连续选择，**Shift + 单击**选择连续范围。
- 在空白区域拖动可框选；方向键可移动选择。
- **编辑 → 全选**选择当前筛选后可见的镜头。
- **仅展示选中分镜**可集中核对候选集合。

图标和列表中的缩略图支持按指针横向位置预览镜头画面。高亮搜索会保留非匹配项，全选前请确认是否需要改用过滤模式。

### 同时查看多个视频

在来源菜单勾选多个视频，可集中检索和标注。列表会出现**来源**列：按来源正序或倒序排列时，先分组，再按其他列排序；将来源排序设为**无**可跨视频统一排序。

取消最后一个来源后，面板显示**未选择**。重新选择来源即可继续查看。使用标题行的**锁定作用域**固定来源，详见[来源工作区与导航历史](/workspace/source-workspaces)。

## 用视图完成不同的审看任务

| 任务                     | 视图与排列建议                       |
| ------------------------ | ------------------------------------ |
| 快速找出明显可用画面     | 图标视图，适当放大缩略图             |
| 按叙述顺序检查切分       | 标签视图，按来源和媒体开始排列       |
| 找出太短的镜头           | 按媒体时长排列，结合源监视器核对     |
| 比较多个视频中的相近候选 | 来源排序设为无，再按星级或匹配度排列 |
| 核对长期分类             | 标签视图查看关键字，再使用关键字过滤 |

缩略图是审看片段的入口。快速运动、遮挡或镜头中途出现的主体，可能无法只从默认缩略图判断，应使用悬停预览和完整播放。

## 理解选择与播放范围

单击行或卡片会选择并定位；在缩略图画面上单击或双击条目用于预览范围。拖动框选只建立选择集合，执行标注或导出前仍应核对来源和数量。

**仅展示选中分镜**适合检查临时候选。要让候选能在关闭或重新打开项目后继续查找，应应用旗标、星级或关键字并保存。

## 多来源连续审核

1. 在来源菜单勾选本轮视频，必要时锁定作用域。
2. 先按来源分组，检查每个视频的切分和画面。
3. 为可用镜头添加统一标记。
4. 将来源排序设为无，按质量或内容条件跨视频比较。
5. 进入导出前再次核对列表顺序，尤其是合并输出。

排序和过滤不会改变视频原始时间，也不会使原本不相邻的镜头变成可合并镜头。

## 找不到刚才的镜头时

依次检查来源是否变化、是否仍有搜索、是否开启仅展示选中、是否折叠在堆叠中，以及星级、旗标和关键字快捷过滤是否仍启用。关闭一个底部工具区不会自动清除已经应用的条件。
