# 标注和筛选字幕

用标注记录一次审听后的判断，再按标注建立候选集合。标注随项目保存，适合跨多次搜索继续整理。

## 筛选字幕条目

搜索之外，还可以独立组合以下条件：

- 按 1–5 星筛选，并选择**星级大于等于**、**星级小于等于**或**星级等于**。
- 按留用旗标、无旗标或排除旗标筛选。
- 按色标或自定义标签筛选。
- 按已编辑或未编辑状态筛选。
- 使用**仅展示选中字幕**核对当前候选集合。

这些条件与文字、语义和时长条件共同生效。结果过少时，应同时检查所有筛选器，而不只是清空搜索框。

## 选择与标注

### 选择条目

- 单击选择一项，**Ctrl + 单击**增减不连续项，**Shift + 单击**选择连续范围。
- 在空白区域拖动框选，或使用**编辑 → 全选**选择当前可见条目。
- 需要核对选择结果时，开启**仅展示选中字幕**。

### 应用标记

- 设置 0–5 星。
- 设置留用、排除或无旗标。
- 设置色标或自定义标签；两者互斥。
- 使用底部喷涂工具连续应用标签、旗标或星级。字幕喷涂不提供关键字。
- 喷涂时按住 **Alt** 可切换到擦除；完成后退出喷涂，再恢复普通选择。

快捷标记：**P / X / U** 设置留用、排除或清除旗标，**0–5** 设置星级，**6–9** 设置红、黄、绿、蓝色标。按住 **Shift** 或开启 **Caps Lock** 标注，可自动前进到下一项。

标注应保存到项目。临时勾选和搜索条件不适合作为长期整理记录。

## 为审听约定标记含义

例如将留用表示“内容适合主题”，用 4–5 星表示“优先采用”，色标或自定义标签记录“待核实”“补充上下文”等状态。约定由你决定，应用不会根据星级自动推断采用与否。

旗标与星级可以同时使用。色标与自定义标签共用同一类位置，设置其中一种会替换另一种；保留旧分类前先检查选择。

## 批量标注并核对

1. 切到过滤模式，缩小到本轮目标对白。
2. 核对当前来源、可见项和选择数量。
3. 多选条目，应用旗标、星级或标签。
4. 清除查询，使用相应标记筛选检查结果。
5. 保存项目。

高亮模式的全选仍包含可见的非匹配项。仅展示选中字幕便于核对临时选择，不会自动保存为分类。

## 组合条件的例子

查找“已留用、至少 4 星且 3–12 秒的预算对白”，可先搜索预算，开启留用筛选，把星级比较设为大于等于并选择 4 星，再在高级搜索填写时长。

这些条件共同生效。结果突然变少时，逐一关闭条件观察，而不是重复给字幕加标记。

## 连续喷涂后恢复选择

先在少量条目确认喷涂值。一次拖动后检查结果，需要回退时使用撤销；标注完成应退出喷涂，再执行普通选择或导出。字幕喷涂没有关键字模式，分镜关键字不会自动成为字幕分类。
