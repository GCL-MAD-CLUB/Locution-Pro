# 按含义查找字幕

只记得主题或说话意图时，用一句描述寻找含义接近的对白。例如输入“解释为什么需要增加拍摄预算”，查找表达这一意思的字幕。

## 按含义查找对白

1. 安装语义检索组件，并将搜索模式设为**语义**。
2. 输入想找的主题或表达，例如“讨论如何控制拍摄预算”。
3. 首次使用时等待字幕检索准备完成。
4. 按匹配度查看结果，调整搜索栏右侧的阈值。
5. 播放完整上下文，确认结果符合需要。

默认阈值为 0.01，提高后结果更严格。在阈值输入框中按 **Enter** 应用，按 **Esc** 放弃编辑。含义相近不代表原文完全一致，正式选用前应试听上下文。

### 正向与反向语义描述

高级语义搜索支持每行一条正向描述和反向描述。分别取最高匹配度，最终得分为 `max(0, 正向最高分 − 反向最高分)`；没有反向描述时按 0 计算，再按阈值筛选。

正向、反向描述各限 10 个非空项，每项最多 1000 字符（ASCII 字符计 1，中文等非 ASCII 字符计 2）。同侧相同描述只检索一次。正反向描述重复等错误会在弹窗内提示并标红对应输入框，修正后可应用。

在快捷搜索框中，多条正向描述用 `|` 分隔，例如 `海边的日落|夕阳下的沙滩`；打开高级搜索后每行一条，两处均可编辑完整内容。

## 写出适合对白的描述

| 想找的内容 | 可尝试的描述                   |
| ---------- | ------------------------------ |
| 原因解释   | 解释为什么延后拍摄             |
| 经验分享   | 分享第一次公开演讲的经历       |
| 观点比较   | 比较现场录音和后期配音的优缺点 |
| 操作建议   | 建议如何降低拍摄成本           |

先围绕一个主题检索，再用不同说法补查。画面外观应在分镜中搜索；字幕语义搜索依据文字，不会补出没有写在字幕里的信息。

## 如何理解匹配度

提高阈值缩小结果，降低阈值扩大结果。不同查询和不同面板的分数不适合直接比较，也不代表对白事实的可信程度。

反向描述可能明显降低总分。先去掉反向描述确认正向结果，再逐条添加，有助于判断是哪项条件排除了候选片段。

## 从相关对白中选出可用片段

1. 播放命中的完整显示片段。
2. 检查前后语句，确认指代和观点没有被截断。
3. 用留用旗标记录候选，用星级区分优先级。
4. 清空查询，再按标记复核候选集合。
5. 导出时按实际语句调整开头和结尾。

含义相近的两句可能表达相反态度，尤其涉及否定、转述或假设时，应以原对白为准。

## 准备失败或没有语义模式

没有语义模式时检查可选组件。已有模式但准备失败时，检查字幕来源、文件连接、缓存空间和任务提示。反复改写查询不能解决组件或文件不可用的问题。
