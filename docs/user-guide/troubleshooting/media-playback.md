# 解决导入、连接和预览问题

遇到素材看不到、导入失败或播放器为空时，先确定问题发生在哪一步，再检查文件、工具和项目状态。不要反复导入同一路径代替定位问题。

## 媒体工具不可用

导入、分析、生成代理或导出立即失败时：

1. 打开**编辑 → 首选项 → 媒体工具**。
2. 检查 FFmpeg 和 ffprobe 路径是否对应实际可用文件。
3. 自行安装工具时，建议使用同一发行包中的两个程序。
4. 没有可用工具时，重新运行安装程序选择内置 FFmpeg。
5. 确定设置后，重新提交任务。

重置工具路径只恢复默认命令名称，不会安装缺失程序。仅设置 ffprobe 或仅设置 FFmpeg 可能不足以完成所有任务。

## 无法导入或看不到素材

1. 确认当前已创建项目，文件类型受支持，文件可读取且未被其他程序独占。
2. 在导入工作区检查文件类型过滤、隐藏文件开关、当前目录和排序方式。
3. 选择文件夹时等待扫描结束；无法读取的目录可重新扫描，或改为选择可访问子目录。
4. 检查待导入栏是否仍包含文件，以及是否因失败而保留。
5. 同一路径显示**已导入**时，到媒体箱查找，不必重复导入。
6. 导入后等待分析，部分缩略图和轨道信息可能稍后出现。

复制导入失败时，检查目标盘空间和权限，修正后重试待导入栏中的剩余项。若媒体箱中找不到条目，还应检查当前素材箱、搜索、隐藏状态和启用状态。

完整流程见[导入和整理媒体](/media/import-organize)。

## 媒体脱机或画面为空

1. 连接素材盘，确认原文件位置。
2. 在媒体箱检查条目是否启用、是否被隐藏。
3. 对脱机项执行**链接媒体…**。
4. 如只连接了代理，在播放器中选择**代理**预览。
5. 需要检测、检索准备或导出静帧时，先恢复原始文件。
6. 替换过素材时，核对新文件的内容、时长和既有切点是否仍匹配。

不要只按文件名批量链接相似素材；链接后抽查实际画面和声音。完整步骤见[管理离线媒体与代理](/media/offline-proxies)。

## 预览卡顿或磁盘空间不足

为高分辨率或高码率视频创建代理，并在源监视器切换到代理预览。检查素材盘、代理盘和缓存盘连接稳定，避免在处理期间移动文件。

在首选项中更换缓存位置只影响后续生成的缓存，不会迁移旧文件。自动保存位置独立设置，清理磁盘前请先保留原始素材、项目和需要的恢复文件。

创建代理本身也需要空间和媒体工具。代理生成失败时，先检查原始媒体、输出位置和 FFmpeg 设置。

## 根据现象缩小检查范围

| 现象                         | 优先检查                       |
| ---------------------------- | ------------------------------ |
| 磁盘中有文件，浏览器中看不到 | 目录、扩展名过滤、隐藏文件开关 |
| 选了文件夹却不能导入         | 扫描是否完成、目录是否可读     |
| 复制阶段失败                 | 源盘连接、目标空间与权限       |
| 多种处理任务都立即失败       | 媒体工具路径或安装组件         |
| 项目中有条目但播放为空       | 脱机、禁用、完整媒体与代理选择 |
| 只有个别文件异常             | 编码、损坏和该文件本身的可读性 |

## 修复后怎么确认

先回到原来失败的步骤，用同一条代表性素材重试；核对画面和声音后，再继续剩余内容。已成功导入或生成的部分不必全部重做。

如果问题仍在，记录文件类型、发生步骤、提示和时间，再提供对应日志。
