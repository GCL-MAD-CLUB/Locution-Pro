# 管理来源工作区和导航历史

来源工作区保存一组正在浏览的视频或字幕轨以及浏览位置。它帮助在不同素材集合之间来回工作，与顶部导入、编辑、导出工作区分别使用。

## 管理来源工作区与导航历史

分镜和字幕面板中的“来源工作区”，是一组视频、字幕轨和最近浏览位置，用于在不同素材集合之间切换。它与顶部三个工作区分别使用。

### 选择与返回来源

1. 打开面板来源菜单，按媒体箱层级选择视频；字幕可展开视频选择轨道。
2. 勾选多个来源集中浏览，取消最后一项可清空当前视图。
3. 在面板菜单中选择已有来源工作区，返回先前集合和浏览位置。
4. 使用标题行的上一个、下一个来源选择按钮，回退或前进来源变化。

来源导航保留最多十步回退，到两端时按钮变灰。回退后重新修改来源，将替换原来的前进记录。

面板菜单中的**关闭**和**关闭全部**移除来源工作区，不删除项目媒体。它们与**关闭面板**是不同命令。

### 锁定作用域

单击两个来源历史按钮之间的锁图标，固定该面板的来源和字幕轨。

锁定后：

- 来源菜单与历史按钮禁用。
- 双击其他媒体不会改变此面板来源。
- 仍可在当前范围内搜索、标注和预览。
- 可从面板菜单切换已有来源工作区，或关闭它们。

再次单击锁图标解除。字幕和分镜各自独立锁定。

来源浏览记录在当前电脑恢复。将项目交给另一台电脑时，请重新选择所需范围；导出前也应重新检查搜索、过滤和勾选项。

## 建立两套审看范围

例如分镜中查看活动全体视频，字幕中只查看访谈：

1. 在分镜来源菜单勾选活动视频。
2. 在字幕来源菜单为访谈视频选择需要的字幕轨。
3. 分别锁定作用域，避免打开其他媒体时意外改变范围。
4. 在其中任一面板选择条目，使用源监视器核对。
5. 需要改变范围时，只解锁对应面板。

两个面板的范围可以不同，单击结果仍会打开对应媒体。播放跟随不会自动改写锁定的来源。

## 区分几种历史与关闭

| 入口                       | 管理什么             | 不会改变什么   |
| -------------------------- | -------------------- | -------------- |
| 来源上一个、下一个         | 当前面板浏览过的范围 | 项目标注与切点 |
| 面板菜单的来源工作区列表   | 已有来源集合         | 磁盘文件       |
| 来源菜单中的关闭、关闭全部 | 来源工作区           | 项目媒体       |
| 关闭面板                   | 面板布局             | 项目内容       |
| 历史记录撤销               | 项目操作             | 来源导航顺序   |

## 锁定后按钮不可用

来源菜单和历史按钮锁定时变灰是正常状态。解锁后才能修改当前来源；仍可从面板菜单切换已有来源工作区或关闭它们。

## 返回范围后重新核对

搜索条件和浏览位置便于继续工作，但导出前仍要确认来源、筛选和选择。换电脑后重新建立来源，长期候选用已保存的标记查找。
