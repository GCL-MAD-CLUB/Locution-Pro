# 系统要求

Locution Pro 在本机完成媒体处理。素材长度、分辨率、编码和电脑性能会影响预览与处理速度。安装前请先核对基础条件，正式处理大量素材前再用少量代表文件测试。

## 安装和使用条件

| 项目     | 要求或建议                                                        |
| -------- | ----------------------------------------------------------------- |
| 操作系统 | Windows 10 或 Windows 11，64 位                                   |
| 运行环境 | WebView2；检测与检索所需的 Microsoft Visual C++ 运行库（x64）     |
| 显示器   | 可用窗口至少 1080 × 700，建议 1920 × 1080 或更高                  |
| 媒体工具 | 使用安装程序提供的内置 FFmpeg，或在首选项中指定 FFmpeg 与 ffprobe |
| 存储     | 为素材、媒体缓存、可选组件、代理和输出文件分别预留空间            |
| 网络     | 下载、更新和在线帮助需要网络；日常本地素材处理无需联网            |

如果应用提示运行库缺失或组件无法加载，不要立即重新导入全部素材；先按[故障排查](/troubleshooting/troubleshooting#提示运行库或组件不可用)修复环境，再重新提交任务。

## 显示器与工作区

较小的窗口可能需要频繁调整面板大小。进行以下工作时，建议使用更大的显示区域：

- 同时查看媒体箱、源监视器和分镜。
- 比较列表中的标题、时间、关键字和标记。
- 在导出预览中微调入点和出点。

面板可以重新停靠和调整大小。界面拥挤时，先关闭暂时不用的面板，或拖动分隔线为当前任务留出空间。

## 安排存储位置

项目文件不包含原始媒体。请分别安排以下内容的位置：

| 内容     | 保管建议                                                 |
| -------- | -------------------------------------------------------- |
| 原始素材 | 放在稳定、可访问的磁盘上，并保留独立备份                 |
| 项目文件 | 放在固定的工作目录中，重要节点另存副本                   |
| 自动保存 | 使用稳定、可写且空间充足的目录，不要只依赖它备份         |
| 媒体缓存 | 选择本机可用空间充足的位置，更改位置后旧文件不会自动移动 |
| 代理     | 批量工作时使用固定目录，便于连接、移交和检查空间         |
| 导出成品 | 与原始素材区分，正式交付前避免覆盖唯一旧版本             |

使用外接存储时，在导入、检测、检索准备、代理生成和导出完成前保持连接。不要将唯一副本放在会被自动清理的临时目录中。

在[首选项](/projects/preferences)中检查缓存与自动保存位置。更改位置只影响后续写入，不会替你迁移旧文件。

## 评估大型素材的处理需求

高分辨率、长时长或高码率视频可能需要较长的准备时间。开始大批量工作前，建议选取几段有代表性的素材，依次确认：

1. 能否正常导入、预览和定位。
2. 镜头识别耗时与结果是否符合需要。
3. 首次画面检索准备是否可以完成。
4. 缓存、代理和输出是否占用过多空间。
5. 导出文件能否在接收方的软件或设备上播放。

预览不流畅时可[创建代理](/workflows/create-proxy)。代理能改善审看体验，但镜头检测和首次画面检索准备仍需要原始视频在线。

## 了解可选组件与网络

- **内置 FFmpeg**提供导入、预览、代理和导出所需的媒体工具。
- **语义检索组件**提供按画面描述和对白含义搜索的能力，需要额外存储空间。
- 未安装语义检索组件时，仍可导入、人工浏览分镜、添加标记与关键字并导出。
- 下载安装包、更新应用和打开在线帮助需要网络；已经准备好的本地素材处理不需要持续联网。

## 根据工作负载检查环境

| 工作负载               | 主要检查                             | 出现问题时                             |
| ---------------------- | ------------------------------------ | -------------------------------------- |
| 浏览和人工标注         | 窗口可读、文件可访问                 | 调整面板或检查媒体连接                 |
| 镜头检测与首次画面检索 | 原始视频在线、组件可用、缓存空间足够 | 先看任务和组件提示                     |
| 高频定位高码率素材     | 磁盘响应与代理效果                   | [创建代理](/media/create-proxies)      |
| 合并长片段或高质量输出 | 输出空间、目标格式与性能设置         | [检查输出设置](/export/video-settings) |

同一台电脑处理不同编码和分辨率的素材，表现可能不同。代表性素材验证用于确认你的工作条件，不需要先处理完整素材库。

## 安装前检查清单

- 系统为受支持的 64 位 Windows。
- 可用窗口大小满足工作需要。
- 原始素材已经妥善备份。
- 缓存、代理、自动保存和输出有足够空间。
- 外接素材盘连接稳定。
- 已决定使用内置媒体工具还是自行提供的工具。

确认后继续阅读[安装与首次启动](/getting-started/install)。
