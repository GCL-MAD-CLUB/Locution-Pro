# 测试约定

`npm test` 执行确定性逻辑测试和测试代码的类型检查。浏览器流程通过
`npm run test:e2e` 按需运行；提交涉及用户交互的修改前运行 `npm run test:all`。

```powershell
npm ci
npx playwright install chromium
npm run test:all
```

浏览器运行器独立启动并关闭端口 1430 的 Vite 服务，不复用已有服务，不占用开发端口
1420。每个用例使用独立的浏览器上下文、存储和应用模块状态；可以独立执行，也可以并行执行。

```powershell
npx playwright test tests/browser/import-workflow.test.ts
npm run test:e2e:headed
npm run test:e2e:report
```

默认不重试失败，不允许 `test.only`。失败保留首轮 trace、截图、浏览器错误和原生命令记录，
结果位于被 Git 忽略的 `test-results/` 和 `playwright-report/`。不录制视频。
GitHub Actions 的 **Browser regression tests** 工作流每周定时运行，并在修改浏览器测试、
测试配置或依赖清单时随 PR 运行；也支持手动触发并下载报告。

## 测试边界

| 层级             | 位置                                           | 执行内容                                                                  |
| ---------------- | ---------------------------------------------- | ------------------------------------------------------------------------- |
| 确定性逻辑       | `tests/unit/`                                  | 实际模块的输入、输出、历史、调度和异步状态；普通 CI 执行                  |
| 应用界面流程     | `tests/browser/*.test.ts`                      | 从应用入口点击、键盘输入、切换工作区，验证界面结果和原生命令              |
| 组件与 Hook 集成 | `tests/browser/*.harness.js`、`components.tsx` | 真实 React 组件、任务与项目系统，补充跨面板及竞态验证，由浏览器运行器调用 |
| 外部工具集成     | `tests/integration/`                           | Windows NSIS 等真实工具，仅在具备条件的环境显式运行                       |
| Rust             | 对应实现文件的内联 `mod tests`                 | 原生实现行为，通过 Cargo 执行                                             |

浏览器流程在 Tauri IPC 边界替换本地文件系统、原生对话框和媒体工具，浏览器媒体解码也使用
确定性替身。它们验证实际前端链路，**不能替代完整桌面端到端验证**：真实 WebView2、项目文件
加密与落盘、FFmpeg、模型/GPU、安装升级仍由相应原生测试与外部工具测试验证。不得将模拟命令的
成功结果描述为真实编码、推理或磁盘持久化通过，也不得生成视频再做复杂测试。

原生命令夹具位于 `browser/support/native.ts`，未知命令必须失败。没有显式注入的应用错误也必须
失败，包括应用自行捕获的错误。`native.fail()` 注入错误，`hold()` / `release()` 控制异步顺序；
断言等待可观察的状态，避免用固定休眠掩盖竞态。公共替身和装载工具放在各测试层的 `support/`。

## 新增回归用例

修复用户流程时，重现用户的入口、操作及最终结果；需要验证派发或文件参数时，同时断言命令。
保留已有有意义的逻辑断言，并添加至少一个相关的失败、取消或边界场景。异步流程应验证较晚返回的
旧结果不会覆盖当前状态，失败后可重试，已成功的操作不会重复执行，项目切换后不会污染其他项目。

文件格式等独立契约使用明确列出的输入与预期值，不从实现复制支持列表来生成预期结果。
原生或重型验证不塞进 `npm test`；真实外部工具测试需要说明运行条件，不能用空占位二进制冒充成功。
