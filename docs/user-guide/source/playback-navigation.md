# 播放和精确定位媒体

源监视器用于确认素材内容和精确位置。先打开目标媒体，再使用时间码、逐帧和概览条定位；画面缩放与时间线缩放分别控制查看方式。

## 切换播放历史

源监视器的面板菜单保留本次会话中载入过的视频历史：

- 从历史列表选择视频，可重新载入对应内容。
- **关闭**关闭当前播放项，并回到最近一个仍在历史中的视频。
- **关闭全部**清空源监视器的播放历史。

这些命令只管理源监视器中的播放项，不会从媒体箱删除素材，也不会关闭分镜或字幕的来源工作区。

## 播放与定位

| 控件或按键                  | 操作                             |
| --------------------------- | -------------------------------- |
| 播放按钮 / Space            | 播放或暂停                       |
| 上一帧、下一帧 / 左右方向键 | 逐帧检查                         |
| J / L                       | 反向或正向播放，连续按可提高速度 |
| K                           | 停止变速播放                     |
| 按住 K 再按住 J / L         | 低速向后或向前查看               |

先单击源监视器，确保快捷键作用于播放器。反向和高速播放适合定位，音画同步应以正常速度检查。

### 使用时间码和概览条

- 单击时间线跳转，拖动播放头连续定位。
- 单击时间码可输入目标位置，按 **Enter** 或移开焦点确认，按 **Esc** 取消。
- 越界或无效时间码不会改变位置。
- 按住时间码稍候再左右拖动，可逐帧擦洗。
- 时间线下方概览条的中部用于平移，两端用于改变可见跨度。

在播放控制行或概览条滚动可缩放，按住 **Alt** 滚动可平移。在时间标尺上滚动用于移动播放头。

## 调整画面显示

播放器工具栏提供**适合**及固定缩放比例。**Ctrl + 滚轮**以指针位置缩放，**Alt + 滚轮**以画面中心缩放。

这些操作只改变查看大小，不改变原始视频、代理文件或导出分辨率。需要检查细节时，可放大画面；需要确认整体构图时，返回适合视图。

## 切换完整媒体与代理

通过预览来源菜单选择**完整**或**代理**。没有代理时，请先在媒体箱创建或连接；原始媒体脱机时，可使用已连接的代理继续预览。

- **完整**用于核对原始画面和通常的正式输出准备。
- **代理**用于更流畅地审看高分辨率或高码率素材。
- 导出静帧读取原始视频，即使当前正在查看代理。

完整操作见[管理离线媒体与代理](/media/offline-proxies)。

## 逐帧检查一个边界

1. 暂停播放，单击源监视器使其获得焦点。
2. 用时间线定位到切点附近。
3. 按左右方向键逐帧检查前后画面。
4. 需要判断声音时恢复正常速度播放。
5. 决定修改项目切点，还是仅在导出中调整范围。

高亮搜索所在面板的左右键可能用于匹配导航，因此逐帧前要先确认焦点。

## 时间位置与画面大小分别调整

| 想解决的问题         | 使用控件                     |
| -------------------- | ---------------------------- |
| 看不清画面细节       | 画面缩放比例或 Ctrl + 滚轮   |
| 时间线上无法精确拖动 | 缩小可见时间跨度，放大时间线 |
| 时间线看不到目标区间 | 拖动概览条中部平移           |
| 明确知道目标时刻     | 输入时间码                   |

缩放预览不会提高媒体本身的清晰度。当前使用代理时，需要细节核对可切回完整媒体。
