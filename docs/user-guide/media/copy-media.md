# 设置导入组织、复制和自动绑定

导入设置决定素材在项目中如何分类、是否生成磁盘副本，以及辅助文件如何归到视频。设置前先决定继续引用现有目录，还是集中保管本次素材。

## 设置组织方式

### 添加到新媒体箱

1. 在**组织媒体**中开启**添加到新媒体箱**。
2. 输入能反映拍摄日期、场次或用途的名称。
3. 完成导入后，在媒体箱中检查分类位置。

本次素材将集中放入新媒体箱；同名时会自动区分名称。媒体箱与磁盘上的文件夹分别管理，之后移动项目条目不会移动原文件。

### 复制媒体

开启**复制媒体**后，选择复制方式和目标位置。

| 选项                | 结果                           | 适用情况                         |
| ------------------- | ------------------------------ | -------------------------------- |
| 复制并进行 MD5 校验 | 复制后检查完整性，耗时可能较长 | 重要素材或需要确认副本完整时     |
| 复制且不校验        | 生成副本，不执行额外完整性检查 | 已有其他校验或备份流程时         |
| 与项目相同          | 复制到项目文件所在文件夹       | 项目与素材集中保管，需先保存项目 |
| 选择文件夹          | 复制到自行指定的位置           | 使用固定素材库或专用素材盘       |

项目会使用复制后的文件。同名文件保留，新副本自动区分名称。复制完成并不替代独立备份；请在确认副本可用后，再决定如何保管原素材。

### 自动绑定音频和字幕

有独立录音或字幕时，可开启**自动绑定**，选择全部、仅音频或仅字幕，并选择智能推断或按名称匹配。

| 绑定方式       | 项目中的结果                                     |
| -------------- | ------------------------------------------------ |
| 直接绑定       | 将辅助媒体归到目标视频                           |
| 虚拟复制后绑定 | 保留原条目，另建项目条目用于绑定，不复制磁盘文件 |

名称相近的多机位或多语言素材可能需要人工核对。未自动匹配时仍可完成导入，再按[管理音频与字幕轨](/media/tracks-binding)手动绑定。

## 完成导入并核对

1. 确认文件夹扫描结束，待导入数量正确。
2. 检查复制目标、可用空间、媒体箱名称和自动绑定选项。
3. 单击**导入**，等待登记完成。
4. 切换到**编辑**工作区，在媒体箱中检查条目和预览。
5. 打开代表性视频，核对画面、声音和辅助媒体。

后续媒体分析可能继续进行，部分缩略图和轨道信息稍后出现。失败的项目保留在待导入栏，修正问题后可重试；已成功的项目会保留。

## 选择适合素材来源的方式

| 来源情况                     | 可采用方式                   | 导入后注意               |
| ---------------------------- | ---------------------------- | ------------------------ |
| 已在稳定的素材库中           | 关闭复制媒体，引用原位置     | 继续保持该目录可访问     |
| 临时目录或外接盘，需集中工作 | 开启复制并选择固定目录       | 检查项目使用的是正确副本 |
| 希望项目与素材放在一起       | 先保存项目，再选择与项目相同 | 项目本身仍不包含媒体     |
| 拍摄视频有独立录音或字幕     | 配置自动绑定                 | 抽查每个关系与同步       |

## 直接绑定与虚拟复制后绑定

直接绑定将已有辅助条目归到目标视频。虚拟复制后绑定保留原条目，新增项目引用用于绑定，适合同一来源还需要独立整理的情况。

两者都不会修正录音错位，也不会自动创建缺失字幕。名称接近的多机位素材应检查目标视频，不能只依据文件名判断。

## 同名文件与复制结果

复制目标已有同名文件时，新副本会区分名称。复制并进行 MD5 校验需要额外时间，用来检查复制内容的一致性；它不代表你已经拥有独立备份。

复制完成后先核对画面、声音和路径，再决定是否断开原素材盘。不要在复制或校验进行中移动源文件。

## 只完成了部分导入

1. 查看任务提示，确认成功项与失败项。
2. 检查媒体箱，避免重复处理已成功内容。
3. 检查待导入栏中的剩余项。
4. 修正空间、权限或连接问题后重试。
5. 对自动绑定结果抽查，并保存项目。

取消不是整批回滚，可能已留下成功的项目条目或磁盘副本。
