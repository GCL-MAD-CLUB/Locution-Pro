# 选择、预览和调整待导出片段

导出前先准备片段，再设置文件规格。来自媒体箱、分镜和字幕的片段都可在导出预览中调整范围，不必为一次交付改变项目原来的切分。

## 选择导出内容

1. 在分镜、媒体箱或字幕面板选择需要的条目。
2. 选择**文件 → 导出…**，或按 **Ctrl + Shift + E**。
3. 在左侧片段列表逐项勾选，或使用**全选**选择全部片段。
4. 核对**已选数量 / 总数量**和已选片段的**总时长**。
5. 单击片段查看右侧预览，单击缩略图可播放当前范围。

可以从多个视频集中选择片段。分镜和字幕面板的来源范围决定可供选择的内容；确认筛选结果后再进入导出。列表中的时间、时长和来源路径可帮助你区分相似片段。

## 调整导出范围

需要多留一点片头、缩短结尾或整体移动片段时：

1. 单击导出列表中的目标片段。
2. 放大预览时间线。
3. 拖动蓝色括号的左右边界调整入点、出点，或拖动中间手柄整体移动。
4. 核对列表中的时长并播放确认。

**Ctrl + Z** 撤销，**Ctrl + Shift + Z** 重做。所有来源均支持此操作，原字幕时间、项目分镜和源文件保持原样。

导出范围属于本次准备工作，不随项目文件保存。切换项目或更换来源后，请重新核对范围。范围撤销不撤销输出参数，也不能删除成品或恢复被覆盖文件。

## 选择逐项或合并输出

在**常规**中设置**合并为一个文件**：

- 关闭：每个勾选片段输出独立文件。
- 开启：按列表顺序将片段拼接为一个文件。

合并前逐段确认顺序，混合画幅或帧率时选择符合交付要求的统一规格。这里只拼接所选内容，不提供轨道编排、转场或完整时间线剪辑。

## 核对初始范围的来源

| 选择来源 | 初始范围依据       | 重点检查                 |
| -------- | ------------------ | ------------------------ |
| 媒体箱   | 所选媒体的可用范围 | 是否确实需要完整媒体     |
| 分镜     | 项目镜头边界       | 动作是否被边界截断       |
| 字幕     | 显示对白片段的时间 | 句子、提问和停顿是否完整 |

当前源监视器播放的内容不等于全部待导出项。进入导出后应以左侧勾选列表为准。

## 精确调整一段内容

1. 单击目标片段载入预览。
2. 放大时间线，检查片头与片尾。
3. 调整蓝色括号，并核对片段时长。
4. 正常速度播放声音，避免截断词语。
5. 检查前后片段的衔接，再继续下一项。

正向预览会停在右括号，适合核对结尾。需要试听更大上下文时先定位或调整查看范围。

## 导出范围与项目切点

导出中的 Ctrl + Z 只撤销本次范围调整，不改变项目历史，也不撤销编码参数。要永久修正镜头切分，应回到编辑工作区调整项目切点并保存。

临时范围不会随项目文件保管。切换项目、重新选择来源或下次交付时，都应再次确认。

## 合并前的最后检查

- 列表顺序是否符合叙述顺序，而非仅按匹配度排列。
- 是否混入同一句对白的多个近似候选。
- 画幅、帧率和音频是否需要统一。
- 每个接缝是否保留完整动作、语句和必要停顿。

合并只拼接内容，不提供转场、轨道编排或特效。
