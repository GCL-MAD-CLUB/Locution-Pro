# 选择和管理字幕来源

字幕来源决定本次查找使用哪些视频、哪种语言和哪条字幕轨。先核对来源，再输入查询，可以避免在错误场次或语言中反复搜索。

## 开始前：准备字幕来源

- 内嵌文字字幕可以直接从视频的字幕轨中选择。
- 外部 SRT、ASS、SSA、VTT 或 WebVTT 字幕需要先导入并绑定到视频，详见[管理音频与字幕轨](/media/tracks-binding)。
- 位图字幕和画面中的烧录字幕不能直接用于文字或语义检索。
- 语义搜索需要安装可选组件；它检索已有字幕的含义，不会听写音频或生成缺失字幕。

## 选择字幕来源

1. 打开**字幕**面板和来源菜单。
2. 展开目标视频，选择需要的字幕轨。轨道会显示可用的语言、标题和来源信息。
3. 需要跨视频查找时，继续勾选其他视频的字幕轨。
4. 单击条目预览，确认对白、画面和时间相符。

同一视频一次显示一条字幕轨；选择另一条会替换当前轨道。多来源时，列表提供**来源**列，可按来源分组或跨来源排序。取消全部来源后显示**未选择**。

需要固定当前检索范围时，单击来源菜单旁的**锁定作用域**。字幕与分镜面板可分别锁定，详见[来源工作区与导航历史](/workspace/source-workspaces)。

## 为访谈项目准备字幕

1. 将每个访谈视频和对应字幕加入项目。
2. 对外部字幕，先在媒体箱绑定到正确的视频；多语言文件分别保留。
3. 从字幕来源菜单为每个视频选择本轮需要的语言。
4. 播放开头、中间和结尾，核对字幕与对白是否同步。
5. 跨场次查找时勾选其他视频；只看某一位受访者时取消无关来源。

切换同一视频的轨道会改变列表内容。不同轨道应分别核对文字、时间和标注。

## 区分几种来源状态

| 面板状态           | 含义                           | 下一步                         |
| ------------------ | ------------------------------ | ------------------------------ |
| 未选择             | 没有勾选视频字幕轨             | 打开来源菜单重新勾选           |
| 视频无字幕         | 当前视频没有可用字幕轨         | 检查内嵌轨或绑定外部文字字幕   |
| 已选来源但没有条目 | 可能仍在载入，或条目被筛选隐藏 | 查看任务，再清除搜索和独立筛选 |
| 有文字但对白不对应 | 可能选错轨道或绑定错视频       | 核对语言、标题、时间和实际内容 |

## 固定范围并继续浏览

锁定作用域后可以继续搜索、选择和标注。其他面板打开新视频时，本字幕面板的来源保持固定。需要更换视频或轨道时先解锁；需要返回另一套已有范围时，可从面板菜单选择来源工作区。

来源记录在当前电脑恢复。重要候选对白应使用旗标或星级标注并保存项目，便于下次重新建立来源后查找。
