# 使用关键字

关键字是你分配给分镜的描述性标记，用来记录画面中的人物、地点、景别和动作，便于日后反复查找素材。应用关键字后，可以通过分镜搜索、关键字树和快捷过滤快速找到属于某个分类的镜头。

关键字由你创建和分配，不会因语义搜索自动生成。关键字属于整个项目并随项目保存：项目中的同一分类可用于多个视频，一个视频也可以使用其他视频建立的分类。

关键字与星级、留用旗标、色标配合使用：关键字描述画面内容，标记帮助决定是否采用。例如“人物 > 嘉宾”说明镜头里有什么，三星级和留用旗标说明这个镜头值不值得用。

关键字还有三个重要特性：

- **可以嵌套。** 例如“人物”下可以包含“主讲人”和“嘉宾”，“嘉宾”下还可以继续细分。为镜头添加子关键字后，它也同时属于父级分类。
- **可以带同义词。** 同义词是与关键字意思相同的其他叫法，便于按不同习惯搜索。
- **可以组成关键字集。** 关键字集把一组常用关键字放进九宫格，批量标注时不必反复输入。

## 了解关键字面板

分镜右侧的关键字区域由几部分组成，本页其余小节分别介绍它们的用法。

| 区域               | 用途                                                                     |
| ------------------ | ------------------------------------------------------------------------ |
| 当前关键字与添加框 | 查看和编辑所选镜头的关键字，输入新路径直接赋值                           |
| 关键字列表         | 以树形展示项目中的全部分类，显示勾选状态和使用情况，支持创建、编辑和删除 |
| 建议关键字         | 根据所选镜头推荐可能适用的已有分类                                       |
| 最近使用过的关键字 | 快速重复添加刚用过的分类                                                 |
| 关键字集           | 九宫格形式的常用关键字分组，附数字快捷键                                 |
| 底部喷涂工具       | 在多个镜头上连续喷洒关键字或标记                                         |

关键字列表按分类名称排序；每个节点显示使用该分类的镜头数量。展开和折叠节点只影响显示，不会改变任何已有赋值。

## 规划关键字分类

好的分类结构是日后能快速找到素材的前提。建议从少量稳定的分类开始，例如：

| 分类 | 示例               |
| ---- | ------------------ |
| 人物 | 主讲人、嘉宾、观众 |
| 地点 | 教室、室外、演播室 |
| 景别 | 特写、中景、全景   |
| 动作 | 讲话、行走、演示   |

规划时请遵循以下原则：

- **一个概念只保留一个常用名称。** 其他叫法放入同义词，例如把“演讲者”设为“主讲人”的同义词，而不是另建一个分类。
- **先试用，再批量应用。** 在少量镜头上验证分类是否够用，再推广到整个项目。
- **名称不得为空，也不能包含路径分隔符、逗号或星号。** 这些字符在输入语法中有特殊含义。

分类建立后会在项目中长期使用。重命名或删除分类会影响所有使用它的视频，批量调整前请先保存项目副本。

## 添加关键字

可以向一个或多个所选镜头添加关键字。有以下几种方式。

### 输入路径添加

1. 在分镜面板选择一个或多个镜头。
2. 在右侧关键字区域单击**单击此处添加关键字**。
3. 输入名称或路径，如“人物 > 嘉宾”；多个路径用逗号分隔。
4. 按 **Enter** 提交，然后核对镜头关键字和树中的勾选状态。

输入的路径中不存在相应分类时，会自动创建。支持三种父子路径写法：

- 使用 `>` 从父到子，如“人物 > 嘉宾”。
- 使用 `<` 从子到父，如“嘉宾 < 人物”。
- 使用竖线 `|` 从根到叶，如“人物|嘉宾”。

同一条路径不要混用分隔符。逗号用来分隔多条路径，星号保留给多选状态显示，因此名称本身不能包含这些字符。

### 勾选树节点添加

在关键字列表中勾选节点，即可为所选镜头赋予对应分类。多选镜头时，勾选会应用到所有所选镜头。

也可以右键单击节点，选择**将此关键字添加到选定分镜**。

### 拖动标记添加

把分镜上的关键字标记拖动到树中的目标节点，即可赋予该分类。适合在核对画面时顺手整理。

## 读取关键字状态

为镜头添加关键字后，可以从两处确认结果：

- 镜头上显示的关键字标记。在不同显示方式中，可查看直接关键字，或包含父级的完整分类路径。
- 关键字树中的勾选状态。子关键字也属于它的父级分类：为镜头添加“人物 > 嘉宾”后，“人物”节点同样视为已赋值，通过“人物”也能找到这个镜头。

多选镜头时，关键字旁的星号表示该关键字只出现在部分选择中，其余镜头并未赋值。

直接编辑当前关键字文本会替换相应集合，移除的文字可能同时移除已有赋值。只想追加时，请使用添加框或树节点，不要改动现有文字。多选编辑时保留星号，可保留部分赋值的原分布。

## 重复使用常用关键字

建议关键字和最近使用可快速复用分类；关键字集把常用路径放入九宫格。可编辑预设、保存自定义集或还原默认预设。

详细操作见[使用关键字集和喷涂工具](/storyboard/keyword-sets)。

## 使用喷涂工具批量标注

先设置快捷关键字，启用关键字喷涂，再在缩略图上单击或拖动。Alt 用于擦除，Shift 打开九宫格选择。完成后退出喷涂。

详细操作见[使用关键字集和喷涂工具](/storyboard/keyword-sets)。

## 搜索和过滤镜头

关键字只有在能筛出镜头时才发挥作用。请区分两种容易混淆的操作：

- **过滤关键字**输入框只缩小树中的节点显示，帮助在复杂分类中定位节点，不改变分镜结果。
- 要按内容筛选镜头，请使用下面的方法。

筛选方式：

1. 在分镜搜索栏将范围选择为**关键字**，输入名称、完整路径或同义词。
2. 或者单击树节点右侧的快捷过滤箭头，直接筛选属于该分类的镜头。
3. 同时启用多个节点的快捷过滤时，结果须满足全部分类（逻辑与）。
4. 再组合星级、旗标或色标，找到既符合内容又符合质量要求的候选镜头。

父级分类可以找到带有相应子关键字的镜头：快捷过滤“人物”会同时包含只标注了“人物 > 嘉宾”的镜头。高亮模式下，同义词命中不一定在可见文字中显示相同字符，应结合匹配计数核对结果。

展开或折叠树节点、使用过滤关键字都不会改变已有赋值，可放心调整显示方式。

## 创建和编辑分类

可以创建父子分类并填写同义词；同一父级下名称不能重复。名称与同义词可编辑，已有节点不能直接移动父级，应新建正确分类并转移赋值。

详细操作见[维护关键字层级和同义词](/storyboard/manage-keywords)。

## 移除赋值与删除分类

移除赋值只改变所选镜头；删除分类会移除项目节点及相关赋值，删除父级还会影响子分类。确认使用情况后再执行。

详细操作见[维护关键字层级和同义词](/storyboard/manage-keywords)。
