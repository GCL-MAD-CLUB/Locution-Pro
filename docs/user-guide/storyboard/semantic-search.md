# 按画面描述查找分镜

画面检索用自然语言描述寻找相关镜头，不需要视频字幕，也无需先标注标题和关键字。它帮助缩小审看范围，是否采用仍需核对完整画面。

## 用描述查找画面

安装语义检索组件后，可使用**语义**搜索。它按画面内容查找镜头，无需先填写标题或关键字。

1. 选择需要搜索的视频来源。
2. 将搜索模式设为**语义**，输入具体画面描述，例如“室外行走的人群”。
3. 首次使用时，等待语义检索初始化和分镜索引构建完成。
4. 查看匹配度靠前的结果，并在源监视器中核对。
5. 调整阈值缩小或扩大结果集合。

阈值默认是 0.001，越高越严格。可拖动滑块或直接输入数值；输入后按 **Enter** 或移开焦点确认，按 **Esc** 放弃草稿。分镜匹配度显示五位小数，阈值可调整到三位小数。

匹配度用于比较相关性，不代表识别正确的概率。结果过少时，降低阈值或使用更简洁的描述。

图标视图会显示镜头中最符合查询的画面，并以竖线提示其时间位置。列表缩略图区域会并列显示原画面与命中画面；命中画面用于查看，原缩略图保留预览操作。清空搜索或切换模式后，恢复普通缩略图。

准备过程可取消，之后可重新尝试。视频较长或素材较多时需要等待。相关示例见[按画面查找镜头](/workflows/find-visuals)。

### 使用高级语义搜索

搜索栏右侧的**高级**打开高级搜索弹窗。弹窗包含模式、字段范围和规则；单击**应用**生效，**取消**或 **Esc** 放弃修改。

在语义模式中，每行输入一条正向描述，匹配其中任意一条即可获得较高得分；反向描述用于降低不希望出现的画面的得分。分别取正向与反向的最高匹配度，按 `max(0, 正向最高分 − 反向最高分)` 计算最终得分，再按阈值筛选。反向描述留空时按 0 计算，分镜预览使用正向最高分对应的帧。

例如，正向填写“海边的日落”和“夕阳下的沙滩”，反向填写“拥挤的人群”。快捷搜索框用 `|` 分隔全部正向描述，例如 `海边的日落|夕阳下的沙滩`；打开高级搜索后每行一条，两处均可编辑完整内容。

描述中的空格保留，连续的 `|` 和空行不产生空描述；清空快捷搜索框会清空全部正向描述。切换模式保留搜索内容。

正向、反向描述各限 10 个非空项，每项最多 1000 字符（ASCII 字符计 1，中文等非 ASCII 字符计 2）。同侧相同描述只检索一次。高级搜索弹窗会校验输入，正反向描述重复等错误会在弹窗内提示并标红对应输入框，修正后可应用；搜索栏不显示错误提示或错误样式。

清空搜索框会同时清除查询和高级条件，包括反向描述、排除内容、区分大小写与时长范围。

## 准备画面检索

1. 确认分镜已经生成，原始视频在线。
2. 只保留本轮需要的视频来源，避免无关素材增加准备和审看范围。
3. 确认缓存位置可写、空间充足，保持素材盘连接。
4. 输入描述后等待首次准备完成，再判断结果是否符合需求。

首次准备耗时与素材规模有关。准备失败时先检查任务提示；改变查询无法修复离线素材或缺失组件。

## 将需求改写为可见画面

| 需求     | 可尝试的描述         | 审看重点                   |
| -------- | -------------------- | -------------------------- |
| 活动互动 | 观众坐在座位上举手   | 动作是否完整、主体是否清楚 |
| 产品展示 | 桌面上的红色水杯特写 | 产品外观、遮挡和可用时长   |
| 场景空镜 | 傍晚空旷的城市街道   | 人流、光线和镜头运动       |
| 讲解画面 | 主讲人站在白板前演示 | 人物位置、板书和手部动作   |

“讲得有道理”“精彩片段”等标准不能直接由画面确认。寻找说话内容时，应改到字幕面板检索对白。

## 理解命中帧与整个镜头

命中帧表示镜头中与正向描述最相关的位置，不表示整个镜头始终满足要求。图标视图的竖线提示它在镜头中的时间位置；列表可比较普通缩略图与命中画面。

用命中帧确认目标出现后，播放完整镜头，检查目标进入与离开画面的时间。只有几帧符合需求时，导出前要重新确定可用范围。

## 逐步缩小结果

1. 先用一条正向描述并采用较宽阈值，确认能找到目标类型。
2. 结果太多时，增加主体、动作或场景细节。
3. 用多条正向描述表达可接受的替代画面。
4. 只有某类无关画面反复出现时，再添加反向描述。
5. 最后组合旗标、星级、标签或时长条件。

反向条件降低得分，不保证画面绝不含该内容。关键项目应人工检查。不同查询的分数不适合直接作为统一的质量评价。

## 保存搜索后的判断

为命中镜头添加关键字和留用标记，保存项目，再清空查询按标注复核。最近搜索方便再次查找，但不替代项目中的分类，也不自动保存导出选择。
