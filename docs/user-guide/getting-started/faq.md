# 常见问题

首次使用时，可以先通过这些问题判断素材准备和学习路径。具体按钮、选项和操作步骤请进入各主题阅读。

## 可以用它完成哪些工作

可以导入和整理本地媒体、将视频检测为分镜、按画面描述寻找镜头、用关键字和标记分类，并将选中片段逐项或合并输出。有现成字幕时，还可按对白文字或含义寻找片段。

按[创建第一个项目](/getting-started/first-project)完成一次导入到导出，再选择需要深入的主题。

## 没有字幕的视频能否整理

可以。分镜检测、画面检索、标题、关键字、星级、旗标和视频片段导出都不要求字幕。字幕面板用于已有文字字幕的浏览与对白检索。

## 能否自动生成或编辑字幕

当前对白检索使用已有内嵌或外部文字字幕，不进行音频听写。字幕正文、原始时间和样式不在字幕面板中编辑；导出时可独立调整媒体片段范围。

准备方法见[选择和管理字幕来源](/subtitles/choose-sources)。

## 语义检索和关键字有什么区别

语义检索依据画面或字幕与描述的相关性寻找候选，需要可选组件。关键字是你明确赋予分镜的项目分类，可以在多个视频中稳定复用。

可以先用语义检索找出候选，再添加关键字和留用标记，将本轮判断保存下来。

## 不安装语义检索组件能否使用

可以继续导入、人工浏览分镜、按标题和关键字搜索、文字查找字幕、标注和导出。需要语义模式时，再运行安装程序调整组件。

## 保存项目是否包含全部素材

项目保存分类、关系、切分和标注，原始视频、音频、图片、外部字幕与代理仍是独立文件。复制项目文件不能代替复制素材。

备份和交接见[移交项目与素材](/projects/transfer-project)。

## 代理可以代替原始媒体吗

代理用于轻量预览和审核输出。镜头检测、画面检索准备、原始分辨率静帧导出以及通常的正式交付仍需要原始媒体。代理连接在线也不意味着原文件已经恢复。

## 能否把多个视频拼在一起

可以将选中片段按导出列表顺序合并成一个文件。应用不提供多轨编排、转场和特效制作。需要修改镜头切分时在项目中调整，需要本次输出范围时在导出预览调整。

## 切换来源或关闭面板会删除整理吗

关闭面板、来源工作区或源监视器播放项，只影响浏览安排。删除项目媒体或镜头才会改变相应项目内容；长期整理结果仍需保存项目。

## 应该从哪里解决使用问题

先查看屏幕提示和顶部任务，再按[故障排查](/troubleshooting/troubleshooting)选择对应现象。反馈时提供当前版本、时间、操作步骤和对应日志。
