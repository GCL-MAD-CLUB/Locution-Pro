# 管理离线媒体与代理

媒体脱机表示项目找不到原始文件。代理是用于预览的轻量视频副本。原始媒体离线而代理在线时，仍可继续审看，但镜头检测、画面检索准备和原始分辨率静帧导出需要原始文件。

## 判断当前媒体状态

| 状态                   | 可以做什么                     | 需要处理什么                 |
| ---------------------- | ------------------------------ | ---------------------------- |
| 原始媒体在线           | 预览、检测、检索准备和正式导出 | 无需重新链接                 |
| 原始媒体脱机、代理在线 | 使用代理继续预览和审看         | 需要原始媒体的操作前重新连接 |
| 两者均不可用           | 查看项目条目和已有整理信息     | 恢复文件连接后再预览或处理   |

处理期间保持素材盘和代理盘连接。不要只依据文件名判断对应关系，应以画面、声音、时长等信息核对。

## 重新链接媒体

在媒体箱选择脱机条目，使用链接媒体逐项附加。可在同一目录中自动匹配其他媒体，但不搜索子目录，完成后抽查实际内容。

详细操作见[重新链接、替换和断开媒体](/media/relink-media)。

## 替换或暂时断开素材

替换素材用于明确的新版本，完成后检查内容、时长和旧切点。设为脱机只断开项目引用，不删除文件。

详细操作见[重新链接、替换和断开媒体](/media/relink-media)。

## 创建代理

选择一个在线视频创建代理，设置帧大小、预设与位置。当前一次处理一个视频；生成后在源监视器切换代理预览。

详细操作见[创建、连接和管理代理](/media/create-proxies)。

## 连接、分离和定位已有代理

可用应用内浏览器或系统选择器附加已有代理。分离只取消关联，不删除文件；原视频脱机时可重新连接完整分辨率媒体。

详细操作见[创建、连接和管理代理](/media/create-proxies)。

## 使用代理导出

导出中的使用代理适合审核文件，启用不会自动创建代理。正式交付通常关闭，并恢复原始媒体。

详细操作见[创建、连接和管理代理](/media/create-proxies)。
