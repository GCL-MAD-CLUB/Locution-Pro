# 按标题和关键字查找分镜

已经填写标题或关键字时，文字搜索可以精确定位分类和镜头描述。它不需要语义检索组件，适合复用人工整理结果。

## 按文字查找和筛选

从搜索范围选择**任何可搜索的字段**、**标题**或**关键字**。关键字范围支持完整路径和同义词。

| 模式或规则          | 用途                                               |
| ------------------- | -------------------------------------------------- |
| 过滤                | 只保留匹配项                                       |
| 高亮                | 保留上下文，用上一个、下一个按钮或匹配序号浏览结果 |
| 包含                | 查找包含任一输入词的条目                           |
| 包含所有 / 包含单词 | 要求所有输入词满足对应匹配条件                     |
| 不含                | 排除包含输入词的条目                               |
| 开头为 / 结尾为     | 按输入的完整文字匹配字段首尾                       |
| 为空 / 不为空       | 查找未填写或已填写的字段                           |
| 完全相等            | 要求字段内容与输入完全一致                         |
| 正则表达式          | 使用不带两侧 `/` 和标志的正则匹配所选字段          |

高亮模式不会隐藏非匹配项；此时全选可能包含这些镜头。只需匹配结果时，请切换到过滤模式后选择。

### 使用高级文字条件

- **排除内容**每行一项，按字面匹配，命中任一项即不匹配。
- **区分大小写**用于需要区分字母大小写的查询。
- **最短、最长时长**以秒设置，包含边界，留空表示不限。
- 文字条件与已有星级、旗标和标签筛选共同生效。
- **重置**在应用后恢复搜索默认值，不改变来源、选择和其他筛选。

过滤和高亮模式中，搜索内容的换行与空格等效，应用时连续空白合并为一个空格；再次打开高级搜索时，搜索框里的空白分隔显示为换行。正则中的 `|` 仍按正则语法处理。

高级入口只在当前模式使用了快捷栏无法显示的条件时点亮：时长范围、文字模式的区分大小写或排除内容、语义模式的反向描述。条件随当前面板的来源工作区保留，未保存到项目文件。

### 使用最近搜索

搜索框获得焦点时会显示最近搜索，可用上下方向键选择并按 **Enter** 使用。结果随输入更新；离开搜索框后记录最终的非空查询，应用高级搜索或修改快捷设置会更新对应记录。

选择记录会恢复模式、范围、规则、匹配度和全部高级条件。最近搜索保存在当前电脑，字幕和分镜分别记录；每个面板又分为**语义**和**过滤／高亮**两个空间，各保留最近使用的 6 项。

记录文字按搜索栏规则生成，同样的文字只保留一项，重新使用或修改配置会更新并移到最前。含高级条件的记录在文字后显示蓝色 `*`，星号不进入搜索栏。

## 选择正确的字段范围

| 字段范围         | 适用情况               | 注意事项                             |
| ---------------- | ---------------------- | ------------------------------------ |
| 任何可搜索的字段 | 先广泛定位线索         | 一个词可能来自标题，也可能来自关键字 |
| 标题             | 查找人工写下的镜头描述 | 未填写标题的镜头不能依靠标题内容找到 |
| 关键字           | 按人物、地点或景别分类 | 支持完整路径和同义词，检查父子层级   |

例如“人物 > 嘉宾”属于关键字路径；需要精确复用分类时，先选关键字范围，或直接使用关键字树上的快捷过滤。

## 多词与完整字段的区别

输入“舞台 嘉宾”并选择包含时，任一词出现即可；包含所有要求两词都出现。开头为、结尾为和完全相等按完整输入比较字段。

包含单词适合按完整文字边界查找，例如区分英文单词与更长单词的一部分。它不会自动为连续中文分词；中文分类查找通常先使用包含。

## 高亮后批量选择

1. 用高亮查看前后镜头，确认分类命中是否符合预期。
2. 使用上一个、下一个匹配按钮，或输入匹配序号定位。
3. 需要只给结果批量加标记时，切到过滤模式。
4. 核对可见数量后全选，再应用标记。
5. 清除查询，按新标记检查是否包含误选项。

同义词可能使镜头命中，但可见关键字中没有相同字符。应结合匹配计数和分类关系核对，不能只看着色文字。

## 找到还没有整理的镜头

选择标题或关键字范围，使用为空规则寻找缺失字段；也可以用未编辑筛选进行初步检查。为空按所选字段判断，未编辑则综合镜头的整理状态，两者用途不同。

如果需要“没有关键字且至少 3 秒”的镜头，选择关键字范围和为空，再在高级条件中设置最短时长。
