# 使用分镜图谱

图谱把分镜作为节点，按画面关系连接并排列，适合从大量素材中发现相似场景、重复构图和可比较的镜头。可以跨视频查看，结合搜索与筛选缩小范围，再将选择用于标记和导出。

## 准备并打开图谱

1. 导入视频，在分镜面板选择需要比较的来源。跨视频整理可先建立[来源工作区](/workspace/source-workspaces)。
2. 完成[镜头检测](/storyboard/detect-shots)，核对镜头范围。
3. 确认已安装分镜语义检索组件。图谱与[画面描述检索](/storyboard/semantic-search)使用相同的组件，不需要字幕，也不必输入搜索词。
4. 点击分镜面板的“图谱视图”，等待索引准备和图谱生成。首次处理新素材需要等待，可在[任务面板](/workspace/tasks-history)查看任务。

未安装组件时，画布会提示需要安装分镜语义检索组件。调整安装组件后再尝试；人工浏览仍可使用标签或图标视图。

## 理解节点、连线和聚类

每个节点对应一个分镜。相近的节点和连线用于提示画面关联，但距离不是精确的相似度数值，连线也不表示镜头在时间上相邻。应结合实际画面判断，不能据此直接认定重复素材或相同人物。

“聚类优化”默认开启，将关系密切的镜头聚集并显示群组边界。可以关闭以比较普通布局。群组帮助发现候选，不会自动创建关键字或合并镜头。更换来源、筛选或重新生成后，分组与位置可能改变。

将指针移到节点附近可查看关联高亮和镜头预览。“显示缩略图”便于直接比较画面，关闭后可减少遮挡。代表画面不能代替完整镜头，决定采用前仍需预览片段。

## 导航画布

先点击画布使其获得焦点，再使用快捷键；输入搜索文字时先退出输入框。

| 操作         | 方法                                   |
| ------------ | -------------------------------------- |
| 选择镜头     | 点击指针工具，或按 V                   |
| 平移画布     | 点击手型工具，或按 H，然后拖动         |
| 临时平移     | 按住空格拖动，松开后恢复原工具         |
| 缩放         | 在画布滚动，或在画布获得焦点后按 + / - |
| 恢复初始视野 | 画布获得焦点后按 0                     |
| 键盘平移     | 手型工具下让画布获得焦点，使用方向键   |
| 快速定位     | 使用全景导航移动浏览区域               |

找不到节点时先恢复初始视野，再用全景导航定位。平移与缩放只改变浏览范围，不改变镜头时间或视频内容。

## 单选、框选与选择模式

在指针工具下，单击节点选择镜头；拖动空白区域可框选一片节点。手型工具用于平移，需要先切回指针工具才能框选。

| 模式         | 选择结果                       | 临时修饰键                             |
| ------------ | ------------------------------ | -------------------------------------- |
| 替换选择     | 用本次命中替换已有选择         | 无修饰键时使用工具栏当前模式           |
| 添加到选择   | 保留已有选择并加入本次命中     | Shift                                  |
| 从选择中减去 | 从已有选择移除本次命中         | Alt，macOS 使用 Option                 |
| 与选择交集   | 只保留已有选择中本次命中的部分 | Shift + Alt，macOS 使用 Shift + Option |

可点击工具栏选择模式，也可用修饰键临时覆盖，松开后恢复。框选过程中可以调整修饰键，确认模式后松开鼠标完成选择。

开启聚类优化后，在指针工具下双击群组边界可选择该组当前显示的镜头，同样可结合添加、减去和交集模式。选择后应核对镜头，避免将相似但不适用的画面一起纳入。

## 批量整理与导出

1. 在全景中找到相关画面集中的区域，放大并审看片段。
2. 框选或选择群组，用添加和减去模式修正候选。
3. 为选择添加[关键字](/storyboard/use-keywords)、[星级或旗标](/storyboard/rate-filter)。连续标注可使用[喷涂工具](/storyboard/keyword-sets)；喷涂状态下工具行为以喷涂为准，完成后切回指针工具。
4. 切回标签或图标视图核对标题、来源与时间。图谱空间位置不代表导出顺序。
5. 在[待导出片段](/export/prepare-clips)中确认范围与顺序，保存项目后导出。

搜索和标记筛选影响当前显示的镜头。数量不符时，先检查来源、搜索条件、旗标、星级和关键字筛选；图谱只能选择当前显示的候选。需要修改镜头时间时，在[源监视器](/source/edit-cuts)调整切点。

## 排查空白与生成失败

- 画布为空：确认选中来源已有分镜，且筛选后仍有结果。
- 提示缺少组件：检查分镜语义检索组件是否安装完整，再重新打开图谱。
- 索引取消或失败：确认素材在线且路径可读，处理任务面板的错误后点击“重新生成图谱”。
- 更换来源或修改镜头后：等待当前图谱更新完成，再继续选择；不要把旧布局当作固定分类。
- 结果与预期不同：预览实际镜头，再结合文字检索、画面描述检索和人工标记判断。

更多处理方法见[分镜检索问题排查](/troubleshooting/search-results)。
