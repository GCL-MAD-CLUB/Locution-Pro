# 设置字幕高级搜索条件

快捷搜索框不足以表达要求时，打开高级搜索，将文字、时长或语义条件放在同一次查询中核对。应用前可以修改多项，取消后返回原来的结果。

## 使用高级搜索

单击搜索栏右侧的**高级**打开弹窗。修改后单击**应用**；**取消**或 **Esc** 放弃本次修改。

- 在搜索内容之外设置**排除内容**，每行一个词语或短语，命中任一项即不匹配；可选择**区分大小写**。
- **完全相等**要求一个字段的内容完全一致。
- **正则表达式**接受不带两侧 `/` 和标志的 JavaScript 正则，例如 `第[0-9]+集`。无效表达式会显示提示。
- 按秒设置最短、最长时长，包含边界，留空表示不限。时长与星级、旗标等现有筛选共同生效。
- 在语义模式中分别设置正向描述和反向描述，见[按含义查找字幕](/subtitles/semantic-search#正向与反向语义描述)。

过滤和高亮模式中，搜索内容的连续空格、换行和制表符在应用后合并为一个空格；打开高级搜索时，搜索框里的空白分隔显示为换行。清空搜索框会同时清除查询和高级条件。切换模式保留搜索内容。

高级入口只在当前模式使用了快捷栏无法显示的条件时点亮：时长范围、文字模式的区分大小写或排除内容、语义模式的反向描述。

**重置**在应用后清除搜索条件，不改变来源、选择和星级等独立筛选。条件随当前面板的来源工作区保留，但不保存到项目文件。

## 复用最近搜索

离开搜索框后记录最终的非空查询；应用高级搜索或修改快捷设置会更新对应记录。最近搜索分为**语义**和**过滤／高亮**两个空间，各保留最近使用的 6 项。

选择记录会恢复模式、规则、匹配度和全部高级条件。同样的文字只保留一项，重新使用或修改配置会移到最前。含高级条件的记录在文字后显示蓝色 `*`，星号不进入搜索栏。

## 组合一个查找任务

例如查找包含“预算”、时长在 2–8 秒之间、且不出现“广告”的对白：

1. 选择过滤模式，搜索内容填入“预算”，规则选择包含。
2. 在排除内容中填入“广告”；排除其他短语时，每行增加一项。
3. 最短时长填 2，最长时长填 8。
4. 单击应用，在源监视器试听结果。
5. 只保留高优先级片段时，再叠加星级筛选。

排除内容按字面匹配，不按正则解释。时长单位为秒，两个边界均包含在范围中。

## 输入条件时的检查

| 输入           | 要求                                    | 修正方法                     |
| -------------- | --------------------------------------- | ---------------------------- |
| 时长           | 非负数字，最短不大于最长                | 留空取消一端限制，或修正数字 |
| 正则表达式     | 表达式有效，不加两侧斜线和标志          | 先简化括号和字符集，再应用   |
| 正向、反向描述 | 各最多 10 项，不能两侧重复              | 删除重复或不必要的描述       |
| 单条语义描述   | 最多 1000 字符，中文等非 ASCII 字符计 2 | 改写为简短具体的表达         |

反向描述降低语义相关度，文字排除按字面排除；应根据当前搜索模式设置。

## 清空、重置与独立筛选

清空快捷搜索框会一并清除高级查询条件。弹窗中的重置需要单击应用才生效；应用后仍保留来源、选择以及星级、旗标等独立筛选。

清空查询后仍只剩少量结果时，检查独立筛选和仅展示选中字幕。最近搜索保存在当前电脑，不能代替随项目保存的标注。
