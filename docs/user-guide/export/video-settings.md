# 设置视频格式、尺寸和质量

视频设置决定输出文件的兼容性、画面规格和处理时间。先确认接收方要求，再比较右侧的来源与输出摘要。

## 设置视频

| 选项               | 使用说明                             |
| ------------------ | ------------------------------------ |
| H.264 / MP4        | 常用的视频交付格式                   |
| HEVC / MP4         | 适合高效率压缩，接收设备需兼容       |
| Apple ProRes / MOV | 用于后期交换和高质量中间文件         |
| VP9 / WebM         | 用于 WebM 交付                       |
| 分辨率             | 选择匹配源，或填写自定义宽高         |
| 帧速率             | 匹配源，或选择所需固定帧率           |
| 质量与速度         | 按画质、文件大小与处理时间取舍       |
| 性能               | 可选硬件加速；遇到问题时尝试仅限软件 |

在右侧**来源**和**输出**信息中比较画面规格。预计文件大小仅供安排空间，最终以生成文件为准。

### 画面规格与质量

不需要转换规格时，分辨率和帧速率可选择**匹配源**。自定义尺寸时保持所需宽高比，确认画面没有意外拉伸；可选固定帧率包括 23.976、24、25、29.97、30、50、59.94 和 60 fps。

质量提供低、中、高和非常高，编码速度提供最快、均衡和高质量。根据接收方要求选择，并在输出摘要中核对。提高帧率不会增加原素材已有的运动细节。

选择 ProRes 时，低质量输出 ProRes 422 Proxy，中质量输出 ProRes 422，高和非常高输出 ProRes 422 HQ。需要特定后期规格时，以右侧输出摘要为准。

### 使用代理输出

**常规 → 使用代理**适合快速审核。正式画面交付通常应关闭，并确保原始素材在线；启用此项不会自动创建代理。

需要创建或连接代理时，请参阅[管理离线媒体与代理](/media/offline-proxies)。

## 按用途选择格式

| 用途                     | 可优先核对的格式   | 注意事项                     |
| ------------------------ | ------------------ | ---------------------------- |
| 常规播放和素材审核       | H.264 / MP4        | 仍需确认目标播放器与尺寸要求 |
| 接收方明确要求高效率压缩 | HEVC / MP4         | 确认接收设备支持             |
| 后期交换                 | Apple ProRes / MOV | 核对质量档位对应规格和空间   |
| WebM 交付                | VP9 / WebM         | 切换后重新核对音频选项       |

## 混合来源的尺寸和帧率

一批片段来自不同规格时，不要只检查第一个来源。需要合并输出时，根据交付目标明确统一尺寸与帧率，并逐段核对实际画面。

提高分辨率不会补出原来没有的细节，提高帧率不会增加原素材的运动信息。自定义宽高应保持预期构图和比例。

## 质量、速度与性能分别影响什么

- **质量**影响输出画质和文件大小；ProRes 会对应不同输出档位。
- **编码速度**影响处理时间与编码取舍。
- **性能**决定是否使用可用的硬件加速；失败时可改为仅限软件重试。
- **使用代理**决定是否用已连接代理输出，独立于当前播放器的预览来源。

右侧预计大小用于安排空间，不能当作最终文件大小保证。高质量输出或合并长片段时，提前检查目标盘可用空间。

## 提交前比较来源与输出

1. 确认视频输出已开启。
2. 比较宽高、帧率和格式。
3. 检查代理选项，正式交付前确认原始素材在线。
4. 重新检查音频格式和声道。
5. 核对文件名、扩展名与输出位置后再导出。

输出模糊时，先检查代理、尺寸和质量，不要仅靠提高质量档位反复尝试。
