# 按画面查找镜头

当你知道需要怎样的场景，却不知道它出现在哪段视频中时，可以用画面描述查找分镜。例如，从活动素材中寻找“观众举手”，或从旅行视频中寻找“海边日落”。视频无需字幕，也无需预先填写标题或关键字。

本流程使用语义检索比较画面与描述的相关程度。它负责缩小审看范围，最终是否采用仍需结合实际画面判断。

## 开始前

- 将需要查找的视频导入项目，并保持原始文件在线。
- 确认安装程序中已安装**语义检索**组件；没有该组件时，搜索菜单不会显示**语义**。
- 在分镜面板的来源菜单中选择目标视频，等待镜头识别完成。
- 如果只需在部分素材中查找，先取消无关视频，减少准备时间和无关结果。

尚未生成分镜时，选择来源后会自动开始识别。只有代理在线时可以预览，但画面检索准备仍需要原始视频。

## 写出清楚的画面描述

一次描述一个主要画面需求，优先写出可以直接看见的内容。

| 描述方式      | 示例                   | 说明                       |
| ------------- | ---------------------- | -------------------------- |
| 主体 + 动作   | 观众在座位上举手       | 比只输入“观众”更明确       |
| 主体 + 场景   | 主持人站在演播室舞台上 | 同时限定人物与环境         |
| 物体 + 外观   | 桌上的红色保温杯       | 用颜色、位置或外观区分目标 |
| 环境 + 时间感 | 夕阳下的空旷海滩       | 适合查找氛围或空镜         |

避免只使用“好看”“有用”“精彩”等无法直接从画面确认的标准。也不要把多个互不相关的需求挤在一句描述中；可以分别搜索，再把结果合并为候选集合。

## 搜索画面

1. 打开**窗口 → 分镜**，在来源菜单勾选需要查找的视频。
2. 将搜索模式设为**语义**。
3. 在搜索框输入视觉描述，例如“穿红色衣服的人站在舞台上”。
4. 首次使用时，等待初始化和分镜索引构建完成。顶部进度区会显示准备状态。
5. 从匹配度较高的结果开始检查。图标视图会显示命中画面，竖线提示它在镜头中的位置。
6. 单击缩略图预览完整镜头，核对主体、动作、前后画面和可用长度。
7. 提高匹配度阈值以缩小结果；结果过少时，降低阈值或改用更简洁的描述。

匹配度用于比较相关程度，不代表识别正确的概率。清空搜索后，普通缩略图和完整结果集合会恢复。

### 组合多个描述或排除内容

1. 单击搜索栏右侧的**高级**。
2. 将几种可接受的画面分别写成正向描述，每行一条；匹配其中任意一条即可获得较高得分。
3. 在反向描述中填写不希望出现的内容，例如“拥挤的人群”。
4. 单击**应用**，再检查匹配度和结果数量。

快捷搜索框可用 `|` 分隔多条正向描述。反向描述只用于降低相关结果的得分，不会替代正向需求。

## 核对并保存候选镜头

1. 对符合要求的镜头设置**留用**旗标；明显不合适的镜头可设为**排除**。
2. 用 0–5 星记录质量或优先级，并采用一致标准。
3. 添加人物、地点、动作等关键字，方便清空搜索后继续筛选。
4. 按 **Ctrl + S** 保存项目。
5. 清空语义查询，改用旗标、星级或关键字筛选，检查最终候选集合。

::: tip 保留筛选上下文
高亮模式会保留非匹配项。若要全选搜索结果并批量标注，请先切换到**过滤**模式，再确认当前可见项。
:::

## 没有语义检索组件时

仍可使用图标视图人工浏览分镜，并按标题、关键字、星级或旗标筛选。先建立稳定的分类，再通过关键字树快速过滤，也能形成可复用的素材集合。需要语义搜索时，可重新运行安装程序添加组件。

## 从一次查询扩展到完整候选集合

以活动素材为例，可依次查找“嘉宾在台上演讲”“观众举手”和“现场全景”。每次将符合要求的镜头写入关键字或旗标，清空查询后按这些标记统一复核。

同一镜头可能出现在多次查询中，复核时注意重复选择。语义得分只表示当前查询相关性，最终取舍可用[星级和旗标](/storyboard/rate-filter)统一记录。
