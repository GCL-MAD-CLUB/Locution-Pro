# 使用字幕

字幕面板将已有字幕转换为可浏览、可搜索的对白条目。你可以跨多个视频查找对白，核对对应画面，再用星级、旗标和标签整理候选片段。

没有字幕的视频可以直接使用[分镜与画面检索](/storyboard/storyboards)。字幕面板用于查找和整理，不提供字幕文字、原始时间或字幕样式的编辑功能。

## 选择一条学习路径

- **第一次使用字幕**：准备来源 → 浏览预览 → 文字查找 → 选择并导出。
- **跨访谈寻找主题**：勾选多视频轨道 → 语义搜索 → 高级条件 → 标注候选。
- **继续上次整理**：恢复来源 → 按旗标或星级筛选 → 试听上下文 → 重新核对导出范围。

## 开始前：准备字幕来源

先确认已有可读取的文字字幕。内嵌文字字幕可直接选择，外部字幕先导入并绑定；语义检索还需安装可选组件。

详细操作见[选择和管理字幕来源](/subtitles/choose-sources)。

## 选择字幕来源

打开来源菜单，为每个视频选择一条字幕轨。可以跨视频查找，同一视频切换轨道会替换当前显示。需要固定范围时开启锁定作用域。

详细操作见[选择和管理字幕来源](/subtitles/choose-sources)。

## 阅读、排列与预览

通过表头排序、列边界和缩略图大小安排列表。单击条目在源监视器预览；播放跟随帮助定位当前对白。连续相同且时间相接或重叠的字幕会合并显示，不改写字幕文件。

详细操作见[浏览、排序和预览字幕](/subtitles/browse-preview)。

## 按文字查找对白

输入原话或关键词，选择过滤或高亮，再设置包含、包含所有、首尾或其他规则。高亮用于上下文导航；批量选择结果前，切换到过滤模式。

详细操作见[按文字查找字幕](/subtitles/text-search)。

## 按含义查找对白

安装语义检索组件后，切换到语义模式，以主题或表达描述想找的对白。等待准备完成，再按匹配度试听；可用正向与反向描述进一步筛选。

详细操作见[按含义查找字幕](/subtitles/semantic-search)。

## 筛选字幕条目

文字或语义搜索可与星级、旗标、色标、自定义标签、编辑状态和仅展示选中共同使用。结果过少时检查所有条件。

详细操作见[标注和筛选字幕](/subtitles/rate-filter)。

## 选择与标注

使用单击、多选或框选建立候选集合，应用星级、留用或排除旗标以及标签。字幕喷涂支持标签、旗标和星级。完成后保存项目。

详细操作见[标注和筛选字幕](/subtitles/rate-filter)。

## 删除字幕条目

普通删除移除项目中的条目，其他条目时间保持不变；波纹删除还会扩展紧接其后的保留条目的开始范围。两者均不改写原字幕文件。误操作后立即撤销。

详细操作见[删除字幕条目](/subtitles/delete-cues)。

## 导出对白片段

选中对白后执行文件 → 导出，核对初始时间范围，再在预览中调整蓝色括号。可逐项输出或合并成一个媒体文件。

详细操作见[从字幕导出对白片段](/subtitles/export-clips)。
