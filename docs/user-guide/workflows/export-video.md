# 导出所选片段或成片

选择所需镜头、媒体或对白片段后，可以逐项交付，也可以按列表顺序输出为一个文件。导出会生成新的媒体文件，但不会替你保存项目；完成整理后仍应按 **Ctrl + S**。

## 开始前

- 保存项目，确认重要整理结果已经保留。
- 确保原始素材在线；仅制作审核文件时，也可明确选择使用代理。
- 确认输出磁盘可写并有足够空间。
- 了解接收方要求的格式、分辨率、帧率、声道和命名方式。

## 准备片段

1. 在分镜、媒体箱或字幕面板核对来源、搜索和筛选条件。
2. 选择所需条目，执行**文件 → 导出…**，或按 **Ctrl + Shift + E**。
3. 在左侧列表检查勾选项、数量、顺序和总时长。
4. 单击每段载入右侧预览，确认内容来自正确的视频和轨道。
5. 需要调整片头片尾时，拖动蓝色括号的左右边界；拖动中间手柄可整体移动范围。

不同来源提供的命名字段不同，但导出范围均可调整。此处的修改只影响本次输出，不改变项目切点、原字幕时间或源文件。

## 选择逐项或合并输出

- **逐项输出**：关闭**合并为一个文件**，每个勾选片段生成独立文件，适合交付素材片段。
- **合并输出**：开启**合并为一个文件**，按列表顺序拼接为一个文件，适合快速组成审看片或简单成片。

合并导出只拼接所选内容，不提供多轨编排、转场或特效。跨视频混合画幅或帧率时，应先确定统一输出规格，并逐段检查接缝。

## 设置输出

### 选择位置和命名

1. 选择目标文件夹；需要分批管理时，开启**存储到子文件夹**并填写名称。
2. 选择命名规则，填写所需的自定名称。
3. 查看**示例**，检查来源名称、镜头标题或字幕文字是否使名称过长。
4. 选择同名文件处理方式。正式交付建议使用独立目录，谨慎使用**无提示覆盖**。

同名冲突的覆盖无法通过导出范围撤销恢复。开始导出前应核对完整路径。

### 选择视频与音频规格

1. 常规视频交付可选择 **H.264 / MP4**；后期交换或 WebM 交付按接收方要求选择对应格式。
2. 不需要转换规格时，将分辨率和帧速率设为**匹配源**。
3. 根据画质、文件大小和处理时间选择质量与编码速度。
4. 来源有音频时，确认音频输出已开启，并核对采样率、声道和比特率。
5. 正式交付通常关闭**使用代理**；快速审核时可开启，并明确输出用途。
6. 在右侧比较**来源**与**输出**信息，确认没有意外改变规格。

只需声音时可选择 MP3 或 AAC 纯音频输出。没有音频的来源不能选择纯音频格式。

## 导出并核对

1. 最后检查片段范围、合并状态、输出目录和文件名。
2. 单击**导出**，按提示处理同名文件。
3. 在顶部进度区等待任务完成；取消后应检查是否已留下部分成品。
4. 打开输出文件夹，确认文件数量和命名正确。
5. 用目标播放器检查清晰度、声画同步、片头片尾和合并接缝。
6. 需要继续在项目中使用成品时，应在导出前开启**导入项目**；已完成的导出可另行导入。

**使用上次设置导出**适合重复同一交付要求。素材或用途变化后，建议先打开完整导出工作区核对参数。

## 重复交付同一批素材

交付要求保持一致时，可使用上次设置导出。开始前仍要确认当前选择、原始媒体与代理、输出位置和同名处理；换目录或改用途后，打开完整导出工作区复核。

上一批部分失败时，先核对成品数量，只重做需要的片段。检查方法见[提交导出与查看结果](/export/run-export)，文件冲突见[命名和位置](/export/naming-location)。
