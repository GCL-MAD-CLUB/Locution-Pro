# 从字幕导出对白片段

字幕选择提供对白的初始时间范围。导出得到对应的视频或音频片段；本流程不用于生成新的字幕文件或编辑字幕排版。

## 导出对白片段

1. 选择所需字幕。
2. 选择**文件 → 导出…**。
3. 核对按显示字幕片段生成的待导出范围。
4. 需要保留更多开头或结尾时，在导出预览中调整蓝色括号。
5. 设置格式、文件名和输出位置后导出。

导出范围调整不改变原字幕时间。完整设置见[导出媒体](/export/exporting)，任务示例见[通过字幕找到片段](/workflows/find-dialogue)。

## 准备可导出的选择

1. 核对视频、字幕语言和轨道。
2. 切到过滤模式选择匹配项，或按住 Ctrl 逐个挑选对白。
3. 列表按匹配度排序时，先确认导出后的叙述顺序。
4. 保存标记，再打开导出工作区。

重复字幕合并为一个显示片段时，初始导出范围包含完整显示时间。不要将列表行数直接当作原字幕文件的条数。

## 留出完整语句和停顿

拖动蓝色括号的两端，保留必要的句前吸气和句尾停顿；向两侧检查，避免只留下回答而丢失提问。拖动中间手柄可整体移动范围。

此处只调整本次导出，不改变原字幕时间。Ctrl + Z 和 Ctrl + Shift + Z 撤销或重做范围调整。临时范围不随项目保存。

## 选择交付方式

| 交付需求             | 设置与检查                             |
| -------------------- | -------------------------------------- |
| 每句对白独立交付     | 关闭合并为一个文件，核对数量和命名示例 |
| 将多句组成审看片     | 开启合并，逐段确认列表顺序和接缝       |
| 只交付声音           | 来源有音频时选择 MP3 或 AAC            |
| 用对白作为文件名线索 | 选择字幕相关命名规则，检查名称长度     |

## 导出后核对

等待完成提示，确认成功与失败数量。检查完整语句、前后画面、预期音轨和顺序。失败片段重试前核对已有文件，避免无意覆盖成功项。
