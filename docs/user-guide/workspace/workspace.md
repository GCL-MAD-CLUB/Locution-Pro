# 工作区、面板与任务

使用顶部**导入、编辑、导出**切换任务界面。切换工作区后，项目素材和整理结果会保留。面板布局、来源范围和后台进度共同影响当前操作，但它们与项目内容分别管理。

## 安排面板布局

从**窗口**菜单打开源监视器、项目媒体箱、分镜、字幕、[素材库](#使用素材库整理字幕和镜头)和历史记录。

1. 按住面板标签拖动。
2. 拖到另一标签栏，可组合为标签页。
3. 拖到边缘停靠指示区，可拆为左右或上下排列。
4. 拖动区域分隔线调整大小。
5. 标签过多时，通过**显示全部标题**选择面板。

应用会在下次启动时恢复布局。当前不支持将面板移为独立浮动窗口。

### 关闭和重新打开面板

关闭当前面板可按 **Ctrl + W**，也可在面板菜单选择**关闭面板**。同一标签组有多个面板时，选择**关闭组中的其他面板**可只保留当前面板。从窗口菜单重新打开即可继续工作。

关闭面板不会删除项目媒体、分镜或字幕。**关闭面板**与来源菜单中的**关闭来源工作区**是不同操作。

面板菜单中的**浮动面板**和**面板组设置**当前为禁用状态，不能用于独立窗口或额外组设置。

## 管理来源工作区与导航历史

在来源菜单建立视频或轨道集合，使用导航按钮回退或前进。锁定作用域固定当前来源，关闭来源不会删除项目媒体。

详细操作见[管理来源工作区和导航历史](/workspace/source-workspaces)。

## 理解当前焦点

菜单、快捷键和标注通常作用于最后单击的活动面板。操作前先确认焦点：

| 操作     | 当前焦点的影响                                   |
| -------- | ------------------------------------------------ |
| 全选     | 只选择当前面板筛选后可见项                       |
| 删除     | 按当前面板的对象执行，例如分镜或字幕             |
| 标注     | 应用于当前面板中的选择                           |
| 撤销     | 编辑工作区撤销项目操作；导出工作区撤销待导出范围 |
| 文字输入 | 输入框获得焦点时，按键优先用于文字编辑           |
| 来源导航 | 改变浏览范围，不撤销标记或删除                   |

执行批量删除或导出前，同时核对**来源、筛选、选择和焦点**，不要只依据当前播放内容判断。

## 使用素材库整理字幕和镜头

素材库把来自不同视频的字幕和镜头集中整理。它有**字幕**和**分镜**两个固定的顶层文件夹，内容随项目保存。

1. 在字幕或分镜面板选中条目，右键选择**添加到素材库**。
2. 在**窗口 → 素材库**中整理：新建文件夹（**Ctrl + Shift + N**）、重命名（**F2**）、拖动移动、按住 **Ctrl** 拖动复制，或用剪切、复制、粘贴和**创建副本**。这些操作也在搜索框下方的命令栏中；命令栏的**排序**和**查看**菜单可切换排序方式、视图大小，以及是否显示属性窗格和项目复选框，**更多选项**菜单提供全选、全部取消和反向选择。命令栏最右侧的**属性**按钮显示或隐藏右侧属性窗格（**Alt + Shift + P**）；左侧文件夹窗格始终显示。
3. 单击左下角的**列表视图**或**图标视图**按钮切换视图，或拖动旁边的显示大小滑块、按住 **Ctrl** 滚动滚轮。较小时显示为列表，列表行高到可显示两行文字时，图标位置改为显示素材缩略图；继续放大后自动变为缩略图图标；**查看**菜单中的预设也只是设置这个大小。列表中单击列标题可排序，拖动列标题左侧边缘可调整列宽，右键列标题可选择显示文字、关键字、入点、出点和添加时间等列。拖动窗格之间的分隔线可调整左侧文件夹窗格和右侧属性窗格的宽度，双击分隔线恢复默认宽度。
4. 使用顶部地址栏定位：单击路径中的箭头可列出下一级文件夹，最左侧箭头可在**字幕**和**分镜**之间切换；单击地址栏空白处可输入路径，例如 `字幕\访谈`，按 **Enter** 前往。右键后退或前进按钮可跳转到最近访问的位置。拖动素材到路径中的文件夹名称上，可直接移入该文件夹。
5. 在右侧属性窗格修改名称、文字、旗标、星级、色标、标签和关键字；输入时间码或逐帧调整**入点**与**出点**。双击素材可在源监视器中预览范围。

::: tip 素材是独立副本
添加时会复制当时的范围、文字和全部标注。之后在字幕或分镜面板修改、删除原条目，或重新识别分镜，都不会改变素材库；在素材库中的修改也不会写回原面板。来源视频离线或被移除时，素材及其标注仍保留，只是暂时无法预览。
:::

字幕素材只能放在**字幕**文件夹下，镜头素材只能放在**分镜**文件夹下。素材库的修改记录在历史记录中，可撤销。

## 查看任务进度与取消

顶部显示任务与进度。只有一个可取消任务时可取消，等待取消结束后检查部分结果；多个任务汇总不提供逐项取消。

详细操作见[使用历史记录和后台任务](/workspace/tasks-history)。

## 获取帮助与日志

- **帮助 → Locution Pro 帮助**在默认浏览器打开用户指南，需要网络连接。
- **帮助 → 显示日志文件**打开日志所在文件夹。

反馈问题时，选择发生问题时段的日志，并检查其中是否含有需要遮去的路径和项目名称。完整说明见[查看与提供日志文件](/troubleshooting/troubleshooting#查看与提供日志文件)。
