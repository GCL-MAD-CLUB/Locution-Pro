# 管理音频与字幕轨

独立录音和外部字幕可绑定到视频，便于在预览与检索时一起使用。视频本身已有的音轨和字幕，也可以在项目中分别整理。画面浏览和分镜整理无需先绑定字幕。

## 开始前

- 将需要绑定的音频或字幕导入同一个项目。
- 确认目标视频和辅助媒体确实对应，尤其是多机位、多语言或名称相近的素材。
- 保持相关原始文件在线。
- 对白检索需要文字字幕；位图字幕和画面中的烧录字幕不能转换为可搜索文字。

## 绑定辅助媒体

1. 在媒体箱中选择一个或多个音频或字幕条目。
2. 使用工具栏或右键菜单中的**绑定媒体**。
3. 在**目标视频**中选择对应视频；选择中已包含一个视频时，先核对默认目标。
4. 检查已选媒体摘要，确认没有混入其他场次或语言。
5. 单击**绑定**。
6. 打开目标视频，试听音频或选择字幕轨，核对是否对应。

也可将音频或字幕拖到视频标题上绑定。视频不能绑定到另一个视频；当前选择不适用时，绑定命令会显示为灰色。

::: tip 导入时自动匹配后仍需检查
自动绑定依据名称或推断结果建立关系。多机位、多语言或相似文件名可能匹配错误，应抽查开头、中间和结尾。
:::

## 展开和折叠绑定媒体

媒体箱列表视图中，单击视频名称左侧的箭头，可展开或折叠其绑定的音频和字幕。

- 折叠只收起子条目，不改变绑定或启用状态。
- 按名称搜索时会展开绑定组，便于查看匹配项。
- 图标视图始终显示绑定的子条目。

## 解除绑定

1. 展开目标视频的绑定媒体。
2. 选择已绑定的音频或字幕。
3. 执行**解除绑定**。
4. 核对辅助媒体是否恢复为独立条目。

原文件和视频均保留。多选时，请核对所选条目是否均已绑定；不确定时分批处理。

## 整理内嵌音轨和字幕

1. 选择一个原始文件在线的视频。
2. 单击**分解音轨和字幕**，或使用同名右键命令。
3. 等待完成，查看新增音轨与字幕条目的语言、来源和启用状态。
4. 打开视频，逐轨检查实际内容。

分解用于项目内管理，不会在磁盘上生成独立音频或字幕文件。没有对应内嵌内容时，不会出现该类条目。

## 选择字幕轨

1. 打开字幕面板的来源菜单。
2. 展开视频并勾选需要的轨道。
3. 跨视频检索时，为其他视频各选择一条轨道。
4. 单击字幕条目，核对文字、声音与画面。

同一视频一次选择一条；多个视频可各选一条集中检索。需要另一条轨道时，在同一菜单切换。

字幕为空时，检查外部文件是否绑定正确、轨道是否启用以及素材是否在线。更多说明见[使用字幕](/subtitles/subtitles)。

## 核对声音与同步

绑定后应试听开头、中间和结尾，确认录音属于当前视频且时间一致。

- 检查对白是否与人物和场景对应。
- 检查长素材尾部是否出现逐渐扩大的偏移。
- 检查多声道或独立录音是否选用了预期来源。
- 预览或导出无声时，检查音频是否启用及导出音频开关。

绑定并不自动修复录制时的错位或变速。如果内容本身不同步，需要先准备正确的音频或处理来源，而不是反复解除和重新绑定。

## 多语言和多机位素材的核对

| 情况                   | 核对方法                           |
| ---------------------- | ---------------------------------- |
| 同一视频有多种语言字幕 | 分别查看轨道语言、标题和实际对白   |
| 不同机位使用相似名称   | 按画面与录音内容核对目标视频       |
| 一段录音被多处引用     | 检查直接绑定或虚拟复制后的项目关系 |
| 字幕有文字但时间偏移   | 试听开头、中间和结尾，先修正来源   |

绑定完成后保存项目；外部录音和字幕仍需单独保管。对白面板的来源选择、浏览和搜索分别见[字幕来源](/subtitles/choose-sources)、[列表预览](/subtitles/browse-preview)和[文字查找](/subtitles/text-search)。
