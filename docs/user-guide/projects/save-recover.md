# 保存、自动保存和恢复项目

项目保存整理结果，自动保存为变化中的工作提供恢复文件。两者都不包含原始媒体，应与素材备份配合使用。

## 保存工作

| 命令     | 快捷键           | 结果                             |
| -------- | ---------------- | -------------------------------- |
| 保存     | Ctrl + S         | 保存当前项目；首次保存需选择位置 |
| 另存为   | Ctrl + Shift + S | 保存为新文件，并继续编辑新文件   |
| 保存副本 | Ctrl + Alt + S   | 另存独立副本，继续编辑当前文件   |

建议在大批量删除、覆盖分镜、修改关键字层级或重新分类前保存副本。日常编辑使用**保存**，开始另一套方案时使用**另存为**，只想留下阶段快照而不切换当前文件时使用**保存副本**。

项目保存不会复制原始素材，也不会把临时导出范围变成长期记录。

### 还原到最近保存状态

**文件 → 还原**返回当前项目最近一次成功保存的状态，包含已启用的自动写回保存。执行后，之后的未保存更改会丢弃。

仅需回退个别操作时，应使用撤销；需要比较两个方案时，先保存项目副本再还原。

## 自动保存与恢复

默认每 5 分钟检查项目变化，每个项目最多保留 20 个自动保存文件。设置位于**编辑 → 首选项 → 自动保存**。

自动保存文件位于独立配置的位置，默认是缓存目录下的 **Locution Pro Auto-Save**。开启**自动保存也会保存当前项目**后，也会写回当前项目；未命名项目仍需先手动保存一次，才有正式路径可供写回。

### 选择合适的恢复文件

1. 如当前项目仍可打开，先保存副本，避免覆盖现状。
2. 在首选项中确认自动保存位置。
3. 找到所需时间附近的 `.lcp` 文件；可同时比较相邻时间的版本。
4. 使用**文件 → 打开项目…**打开恢复文件。
5. 核对媒体连接、镜头划分、标记和关键字。
6. 使用**另存为**保存到正式项目位置，避免继续把恢复文件当作正式项目编辑。

达到版本上限后，该项目最旧的自动保存文件会被移除。更改位置不会迁移旧文件；自动保存也不会备份原始素材。重要节点请保留独立副本。

## 选择保存方式

| 场景               | 命令     | 结果                         |
| ------------------ | -------- | ---------------------------- |
| 日常继续整理       | 保存     | 更新当前文件                 |
| 从此开始另一套方案 | 另存为   | 新文件成为当前工作项目       |
| 做破坏性调整前留底 | 保存副本 | 备份当前状态，仍编辑当前项目 |

首次手动保存后，项目有正式路径；导入复制可使用与项目相同的位置，自动写回也有目标文件。

## 自动写回与恢复版本

自动保存位置与正式项目路径是两个位置。开启自动保存也会保存当前项目后，定时保存可同时写回正式文件，因此还原可能包含最近自动写回的内容。

要长期保留一个里程碑，应使用独立副本。自动保存达到上限会删除最旧版本，不适合长期归档。

## 恢复后的检查顺序

1. 确认恢复文件的时间与项目内容。
2. 检查媒体箱层级、原始媒体连接和绑定轨道。
3. 检查分镜边界、标题、关键字和字幕标记。
4. 在几处关键位置预览画面与声音。
5. 另存到正式工作目录，重新核对来源、筛选与导出范围。

恢复项目不会恢复已覆盖成品，也不会自动找回磁盘上删除的素材。

## 保存失败时保留当前工作

检查磁盘在线、可写和剩余空间。先尝试另存到稳定的可写位置，再排查原目录。不要继续反复覆盖唯一文件；应用还能编辑时优先保住一份可打开的副本。
