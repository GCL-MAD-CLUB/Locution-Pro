# 删除字幕条目

需要从项目列表移除对白条目时，可以使用删除。若只是当前方案不采用，排除旗标更适合保留原条目供以后比较。

## 删除字幕条目

删除会改变项目中显示的字幕条目，不会修改原始字幕文件。

- **删除**保留其他条目的时间范围。
- **波纹删除**还会扩展下一条保留字幕的开始范围，具体变化见下文示例。

需要回退时立即撤销。若只是不想使用某段，优先设置排除旗标或取消选择；执行波纹删除前先保存副本并核对影响范围。

## 删除前确认范围

1. 保存项目；跨视频批量处理前可保存副本。
2. 区分当前可见项与已选择项。
3. 核对来源列，确认没有选中其他视频的相似对白。
4. 对合并显示的连续相同字幕，确认要处理整个显示片段。
5. 决定只移除条目，还是同时改变下一条的开始范围。

## 执行普通删除

选择目标条目，按 Delete 或 Backspace，或使用右键菜单的删除。其余条目的开始和结束位置保持原有值；原视频和字幕文件中的内容仍然存在。

## 执行波纹删除

选择目标条目后，使用波纹删除或 Shift + Delete。连续删除一组条目时，紧接其后的保留条目会向前扩展开始位置到该组删除区间，结束位置保持不变。

例如删除 10–12 秒的条目，下一条原为 12–15 秒，波纹删除后下一条可从 10 秒开始，覆盖更长的媒体范围。它不会把原视频剪短，也不会使所有后续对白整体平移。

删除发生在轨道末尾时，没有下一条可扩展。完成后应试听发生变化的条目，尤其是重新导出前。

## 撤销和继续工作

误删后立即按 Ctrl + Z，或在历史记录中回退。继续编辑前确认条目和标注已恢复。跨多个来源执行删除时，逐个来源检查。

只需多留片头时，可直接调整临时导出范围，无需通过删除其他字幕改变对白条目。
