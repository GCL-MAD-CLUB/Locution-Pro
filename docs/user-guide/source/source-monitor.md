# 使用源监视器

源监视器用于审看当前媒体、核对检索结果和检查镜头边界。在媒体箱双击视频，将媒体箱视频拖到源监视器，或单击分镜、字幕条目，即可打开对应内容。编辑工作区中的分镜切点与导出工作区中的临时导出范围是两套不同操作。

## 切换播放历史

从面板菜单返回会话中打开过的视频。关闭和关闭全部只管理播放历史，不删除媒体。

详细操作见[播放和精确定位媒体](/source/playback-navigation)。

## 播放与定位

使用播放按钮、Space、J/K/L、逐帧按键和时间码定位。概览条用于平移和改变可见时间跨度。

详细操作见[播放和精确定位媒体](/source/playback-navigation)。

## 调整画面显示

使用适合、固定比例或滚轮缩放查看细节，不改变源文件和输出尺寸。

详细操作见[播放和精确定位媒体](/source/playback-navigation)。

## 切换完整媒体与代理

从预览来源菜单选择完整或代理；代理需先创建或连接。静帧导出仍需要原始视频。

详细操作见[播放和精确定位媒体](/source/playback-navigation)。

## 检查片段范围

单击分镜缩略图或双击镜头可打开完整范围；选择字幕可预览对白范围。字幕模式中的原始范围只供查看，不能拖动修改。

### 编辑工作区中的分镜范围

拖动左右边界改变入点、出点，拖动中间手柄移动范围。分镜边界与相邻镜头相连，调整后请检查相邻镜头时长。使用 **Ctrl + Z** 可撤销。

### 导出工作区中的待导出范围

所有来源均可独立调整，只改变待导出片段，不改变项目切点、原字幕时间或原始素材。详见[在导出预览中调整范围](#在导出预览中调整范围)。

## 调整分镜切点

显示切点后，可添加、拖动、精确编辑或清除切点。边界调整影响相邻镜头，大批量操作前保存副本。

详细操作见[添加、移动和清除切点](/source/edit-cuts)。

## 恢复普通删除的分镜

选择属于普通删除区间的切点，右键从选中的切点恢复。波纹删除使用撤销恢复。

详细操作见[添加、移动和清除切点](/source/edit-cuts)。

## 导出当前帧

在编辑工作区的分镜模式中定位画面，单击摄像机图标，设置名称、格式和位置后导出。原始媒体必须在线。

详细操作见[从视频导出静帧](/source/export-still)。

## 在导出预览中调整范围

1. 在导出列表单击片段，载入右侧预览。
2. 放大时间线以便精确定位。
3. 拖动蓝色括号左端或右端，修改待导出入点或出点。
4. 拖动中间手柄整体移动范围。
5. 核对时长，并从范围内播放检查；正向播放会停在右括号。
6. 使用 **Ctrl + Z / Ctrl + Shift + Z** 撤销或重做范围调整。

分镜、字幕和媒体箱来源均可调整。此处只改变待导出片段，不改变项目切点、原字幕时间或原始素材；撤销不会恢复已输出或覆盖的文件。
