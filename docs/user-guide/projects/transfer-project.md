# 备份和移交项目与素材

项目文件保留分类和标记，素材文件提供实际画面与声音。移交时将两者一起准备，接收方才能继续预览、检索准备和导出。

## 移交项目

### 准备需要复制的文件

1. 保存项目，必要时另存一个交付副本。
2. 复制 `.lcp` 项目文件。
3. 复制原始视频、音频和外部字幕。
4. 如接收方需要继续预览，复制并保留需要使用的代理。
5. 不要只复制最近项目列表或自动保存目录来代替正式交付。

### 在接收电脑恢复

1. 打开项目，对脱机条目重新链接。
2. 核对音频、字幕、代理、分镜和关键字。
3. 检查素材是否完整，预览几处画面和声音。
4. 保存项目到接收电脑的正式工作位置。
5. 重新确认输出位置、筛选条件和待导出选择。

面板布局、来源浏览记录和最近导出设置属于当前电脑的使用环境。复制项目后，请重新核对这些设置。

## 决定需要交付的文件

| 内容               | 是否准备               | 用途                   |
| ------------------ | ---------------------- | ---------------------- |
| 正式项目文件       | 需要                   | 延续媒体箱、分镜和标注 |
| 原始视频与音频     | 需要继续处理时必须提供 | 检测、预览与正式输出   |
| 外部字幕           | 项目使用时提供         | 延续对白查找           |
| 已使用的静帧或图像 | 项目引用时提供         | 保持项目媒体完整       |
| 代理文件           | 需要继续轻量预览时提供 | 减少重新生成           |
| 已导出的成品       | 按交付要求准备         | 与可编辑项目分别管理   |

最近项目列表、搜索历史和自动保存目录不能代替正式交付包。

## 在复制前整理连接

1. 先确认项目在当前电脑能正常打开。
2. 记录素材所在磁盘和文件夹，避免遗漏分散存储的字幕或录音。
3. 保存项目副本，复制相关文件并保持清晰层级。
4. 将成品与原始素材放在可区分的位置。
5. 检查副本大小和可读性，再断开磁盘。

项目内的移动或复制不等于磁盘文件复制。虚拟复制或重复条目仍可能引用同一个文件。

## 接收方继续工作的顺序

先恢复原始媒体，再检查代理、音频和字幕。路径变化较大时按目录分组重新链接，并抽查同名文件。随后核对分镜和分类，最后重新选择来源和输出位置。

面板布局、来源浏览记录、最近查询和导出习惯属于当前电脑环境。接收后应重新确认，不以原电脑的临时选择作为交付依据。

## 完成移交的判断

接收方可打开项目、看到正确素材、预览关键位置并找到预期分类，才表示可继续工作。仅能打开项目名称还不足以证明素材已完整移交。
