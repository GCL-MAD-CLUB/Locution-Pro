# 系统维护契约

本文面向 Locution Pro 维护者。产品介绍位于根 README，使用说明位于用户指南。

## 产品与数据边界

应用支持独立的媒体管理、画面检索、分镜整理和导出。字幕是可选来源，不应成为视频导入、检测、分镜检索或导出的前置条件。

应用标识为 `com.locutionpro.desktop`，项目扩展名为 `.lcp`，默认 Windows 数据目录为 `%LOCALAPPDATA%\Locution Pro`，浏览器键使用 `locution-pro:` 前缀。与 LineCut 的安装、卸载、快捷方式和可写数据隔离，项目读取兼容由项目文件层维护。

## 前端目录与依赖

先确定代码的功能所有者。面板内的视图、交互、状态、样式和 Worker 随面板放置，并按职责使用子目录，例如 `AssetLibrary/{actions,model,state,views}`。跨面板复用的 UI 或交互放入 `components/common/<Owner>/`。需要被 UI 下层使用的规则、任务或适配器放入对应的功能目录。目录名描述实际职责，例如 `assetLibrary`、`frameTrace`、`semanticSearch`。避免用通用工具目录收纳多个功能。

| 目录                                             | 职责                                                     |
| ------------------------------------------------ | -------------------------------------------------------- |
| `src/app`                                        | 应用外壳、工作区装配和面板注册                           |
| `src/components/panels`、`src/components/common` | 面板私有实现、跨面板共享的 UI 与交互                     |
| `src/application/<feature>`                      | 跨系统流程和共享媒体服务                                 |
| `src/systems`                                    | 项目、首选项、任务、导入、导出和转码等系统               |
| `src/platform`                                   | Tauri 及其他宿主接口适配                                 |
| `src/runtime`                                    | 生命周期、事件、投影、调度和错误运行时                   |
| `src/core`                                       | 底层契约与纯业务规则，编辑功能按 `editor/<feature>` 归类 |
| `src/assets`                                     | 图标、字体、版本和随包声明的资源入口                     |

表中各层可引用自身及下方的层。启动入口、共享 DTO、Vite 声明和全局样式保留在 `src/` 根目录。组件和系统目录使用 PascalCase 命名，目录内部直接引用实现，外部通过 `index.ts` 使用公开接口。面板通过应用装配、类型化端口、EventHub 或 StateHub 协作。Worker 和 AudioWorklet 与使用它们的功能放在一起，通过显式相对路径加载。

第三方库按职责接入。Tauri SDK 由适配器和命令网关接入，RxJS 由调度模块持有，虚拟列表通过行虚拟化模块复用，d3-force 留在分镜图引擎。新增生产包须直接声明在 `package.json` 并通过依赖检查。官网脚本和用户指南主题各自独立。官网浏览器与边缘 Worker 通过发布契约共享逻辑。

`npm run lint` 检查单文件归属和依赖边界。`npm run check:architecture` 在构建和 CI 中检查文件与组件／系统循环、从入口不可达的模块和未使用的生产依赖。分析覆盖类型导入、静态导入、重新导出、字面量动态导入和通过 `import.meta.url` 加载的模块资源。运行 `npm run --silent deps:frontend` 可输出 JSON，其中 `modules` 给出文件及连边，`groups` 按功能汇总依赖，`packages` 列出第三方包的引用文件。

## 组件通信

组件拥有本地交互状态；项目文档与历史由 `ProjectSystem` 聚合，首选项由 `PreferencesSystem` 持有，任务排队由 `TaskSystem` 管理。视觉组件直接使用类型化端口、私有状态与运行时能力，不增加 `use...System` 组合层。

| 边界         | 契约                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------- |
| EventHub     | 广播请求与事实，不指定接收实例，不消费事件                                                    |
| StateHub     | 发布最小只读投影，以 key 与 owner 标识，revision 单调递增                                     |
| 项目端口     | 外部按需声明查询与命令，不直接导入 ProjectState                                               |
| 首选项端口   | 外部按需声明查询与命令，不直接导入 PreferencesState；更改不写入项目历史，也不把项目标为已修改 |
| 面板私有状态 | 不跨面板导入，不把完整 store 发布为共享状态                                                   |

事件信封与投影不可变。发布方不持有接收者引用；某订阅失败不阻断其他订阅，错误进入统一诊断。编辑与播放仲裁由各接收方根据活动页签、焦点和稳定身份执行，不能用目标面板字段取代广播。

运行时契约位于 `src/runtime/events`、`src/runtime/state` 与 `src/runtime/systems`。公共组件位于 `src/components/common`，业务面板位于 `src/components/panels`。

## React 渲染与资源所有权

渲染保持纯粹：从当前输入计算显示值，事件处理器提交编辑；禁止镜像 props 或其他 state 的派生状态，以及任何有条件或无条件的渲染期状态更新。草稿通过 `useScopedState` 保存当前上下文的用户编辑，切换上下文立即回到派生默认值，迟到回调只影响原编辑会话。

禁止导入、调用、别名或包装 React 的 `useEffect`、`useLayoutEffect`、`useInsertionEffect`，浏览器 harness 同样遵守。外部资源显式接收 `RenderLifetime`，无条件按稳定顺序调用 `useBeforePaint` / `useAfterCommit` 登记获取和释放；激活条件放在获取回调内部。每条返回路径都渲染该 lifetime 的边界，未提交的渲染不获取资源。方法名中的 `use` 让 Hooks 和 Compiler 分析识别提交阶段的回调边界。

可变外部对象不能直接成为渲染数据。虚拟列表由 lifetime 在提交时配置和释放，`useSyncExternalStore` 发布独立快照；滚动、测量等控制仅从事件或提交回调执行。

`npm run lint` 对应用、官网、测试和工具执行 ESLint，所有 React Hooks / Compiler 推荐规则均为 error，包括纯度、不可变性、refs、错误边界和手工记忆化保持规则。项目规则补充禁止条件性渲染更新和派生状态初始化。`npm run lint:fix` 仅执行 ESLint 提供的自动修复，余下诊断必须按所有权和数据流修正，不通过关闭规则规避。

## 多来源与派生读取

来源上下文只组织视图和编辑分发，不将多个视频变为共享媒体。显示行可以包装来源身份，但持久化条目保留原身份。合并镜头、删除与堆叠在各视频内执行；关键字目录按项目协调。

字幕自动整理集中在 `core/editor/subtitles/subtitlePreprocessing.ts`。同轨、纯文本完全相同且相接或重叠的连续 cue 可合并为缓存读取视图，原始 cue 不变。所有显示、计数、搜索、预览和导出使用该视图；删除等显式编辑通过来源 cue 映射作用于原数据。位图轨不参与文本预处理。

素材库是项目内容 `asset_library`，纯规则位于 `core/editor/assetLibrary/assetLibrary.ts`，面板只通过 `assetLibraryUpdated` 提交整库替换，形成一条 `library` 历史。条目在加入时复制媒体身份、入出点、文本与标注（关键字按名称），此后不读取也不写回字幕、分镜状态；字幕与分镜面板只负责构造快照。播放时按视频 id、再按指纹解析项目媒体，解析不到即离线，条目保留。素材库的“主文件夹”（快速访问固定的文件夹、收藏夹、最近使用的素材）属于用户而非项目内容：它按项目 id 存在 WorkspaceConfig.xml 的面板状态中（`core/editor/assetLibrary/assetLibraryHome.ts`），不进入项目文件和撤销历史，只列出仍存在的 id。导出时，所选文件夹与素材库展开为其中的素材（隐藏内容遵循“查看隐藏内容”），按素材自身的名称、入出点和关键字生成片段；同时含字幕与分镜素材时使用“素材”命名规则，媒体离线的素材跳过。

## 面板来源与播放

`components/common/PanelMediaSources/panelMediaSources.ts` 组织来源，`panelMediaPersistence.ts` 与 `projectPanelPersistence.ts` 负责本机恢复和顺序写入。

来源工作区保存来源集合、活动源、字幕轨、播放位置和有界来源历史。相同媒体与轨道集合只保留一个工作区；项目与面板实例共同限定本机配置。来源锁分别属于字幕与分镜面板，阻止手动及自动来源变化，仍允许切换既有工作区。

播放模式通过最小投影共享，源监视器不得导入媒体面板私有状态。只有可见且满足活动规则的面板可接管播放。恢复配置完成前不启用目标配置写入，避免跨项目污染。

## 搜索与大列表

共享搜索控件位于 `components/common/PanelSearch`，纯文本规则位于 `core/editor/search/textSearch.ts`。查询实时更新，最近搜索在退出输入时记录最终非空查询，并在应用高级搜索或修改快捷设置后更新。字幕与分镜各自维护语义、过滤／高亮两个历史空间，每个空间最多 6 项 LRU；以 `searchQueryToSingleLine` 生成的文本判重，保存并恢复完整搜索配置。同名配置覆盖旧项，高级条件的蓝色星号仅用于历史列表展示。

分镜语义结果携带最高得分帧位置；列表补充只读预览，图标视图使用命中帧并保留缩略图操作。排序和过滤使用原始分数，显示精度不能改变结果。

图标网格按可见行渲染，键盘导航按网格坐标处理未挂载项。隐藏面板暂停缩略图与观察工作，不能因标签保留而持续处理大列表。

## 任务与导出

任务提交时登记 queued，获得执行资格后才启动底层工作。最多三项分镜检测并行，其余任务独占，后续检测不越过队列中的普通任务。尚未启动的任务只在前端取消。运行中任务的取消是向后端的一次请求：后端设置取消标志、结束 FFmpeg 并删除清理路径，请求在这些步骤完成后才返回；所有者等到该请求结束再释放槽位。取消全部时暂停补位。关闭窗口走这条前端请求。窗口销毁时，后端只补做尚未认领的清理，避免与前端重复结束进程或删除文件。

导出来源与参数在提交时捕获。分镜、字幕和媒体箱的临时范围由 `ExportSystem/exportWorkspaceState.ts` 管理，独立撤销，不修改原项目切点和字幕时间。刷新来源按仍有效的片段与路径保留范围，切换项目清空。任务期间的新编辑不改变已提交输出。

导出先完成冲突处理与准备检查，再登记任务进度。只有派发 `export_clips` 后，`started` 才解析为 true，界面报告开始并返回编辑工作区；取消或准备失败时解析为 false。完成消息按项目身份隔离，并显示成功与失败数量。

## 帮助与发布信息

“关于”从应用清单读取版本，提供署名与随包第三方声明；仅 Escape 关闭，焦点与应用快捷键必须隔离。检查更新由 `application/update/update.ts` 协调，后端 `backend/update.rs` 只读取 CDN 的 `latest.json`，接受 SemVer 高于当前构建的正式版本；预发布构建同样检查，但预发布结果不参与提示或下载。关闭对话框后忽略迟到结果。发布说明中的链接只允许 HTTP(S)，由系统浏览器打开，不导航应用 WebView。

自动更新仅使用更新专用安装包，地址须位于固定 CDN 目录，安装前重新读取 CDN 清单并复验版本、摘要和本地文件。缓存元数据、忽略版本及已展示说明在本机持久化，重启后复验缓存；更新失败通知先于其他更新通知。CDN 请求失败时，手动检查报告错误，后台检查保持静默；有版本信息但不能自动安装时保留发布页入口。

安装交接等待已有项目写入，按需要保存并检查工作区是否变化或仍有任务运行。交接进程必须确认身份和接管状态；取消或超时撤销交接，保留当前应用。安装器完成后按结果重新启动并打开已保存项目，失败保留恢复信息。更新来源、校验与安装恢复见[发布流程](releasing.md#桌面自动更新)。

## 首次安装迁移

迁移由当前用户安装器执行，正常运行不扫描或复制 LineCut 数据。既有 Locution Pro 安装记录、用户数据或浏览器配置阻止重新迁移；机器级安装不迁移用户数据。中断的首次迁移只在归属可验证时继续。

复制使用暂存、同步、完整性校验和提交，源数据保留。缓存与自动保存位置改为自身副本，浏览器配置整体提交，不合并既有数据库。安装器媒体工具选择优先于导入的旧设置，正常保存后的用户设置继续优先。

取消后等待有限清理，失败不自动跳过。图形界面允许重试或显式跳过；跳过保留原数据与已复制副本，并阻止后续自动续传。卸载与清理只操作自身记录和已确认归属路径。
