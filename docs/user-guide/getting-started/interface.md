# 认识工作界面

Locution Pro 将常用操作安排在**导入、编辑、导出**三个工作区中。它们使用同一个项目，可按工作需要随时切换；切换工作区不会清除素材、分镜或标注。

## 选择工作区

| 工作区 | 适合完成的任务                                     | 常用入口                         |
| ------ | -------------------------------------------------- | -------------------------------- |
| 导入   | 浏览本地文件，选择素材，设置复制与媒体箱组织       | 文件浏览器、待导入栏、组织媒体   |
| 编辑   | 预览画面、检测与整理镜头、添加关键字、筛选候选素材 | 项目媒体箱、源监视器、分镜、字幕 |
| 导出   | 核对片段范围，配置文件格式、画面、音频和输出位置   | 片段列表、导出预览、输出设置     |

右上角主页按钮打开项目首页，用于新建、打开和查找最近项目。首页关闭后可继续当前工作。

## 使用编辑面板

| 面板       | 用途                                             | 常见操作                                 |
| ---------- | ------------------------------------------------ | ---------------------------------------- |
| 项目媒体箱 | 管理视频、音频、图像和字幕，建立文件夹与媒体关系 | 导入后检查、绑定媒体、创建代理、重新链接 |
| 源监视器   | 播放媒体，逐帧检查，调整分镜切点，导出当前帧     | 播放定位、查看完整媒体或代理、调整范围   |
| 分镜       | 按镜头浏览与检索画面，设置标题、关键字和标记     | 语义搜索、文字筛选、喷涂、堆叠           |
| 字幕       | 已有字幕时，查找、标注并选择对白片段             | 文字或语义搜索、核对上下文               |
| 素材库     | 集中整理收藏的字幕和镜头，独立编辑标注与切点     | 分文件夹整理、搜索、调整入出点           |
| 历史记录   | 查看项目操作，撤销、重做或返回先前状态           | 回退操作、比较先前状态                   |

从**窗口**菜单可打开面板。拖动面板标签可调整停靠位置，拖动分隔线可改变大小；详见[工作区、面板与任务](/workspace/workspace)。

## 从素材到片段的基本路径

1. 在**导入**工作区把媒体加入项目。
2. 在**编辑**工作区的媒体箱中打开视频。
3. 在分镜或字幕面板中选择来源，浏览并查找所需内容。
4. 用源监视器核对画面、声音和范围。
5. 保存项目，再进入**导出**工作区输出选择。

## 确认当前操作对象

执行全选、删除、标注或导出前，先单击目标面板。命令通常作用于当前聚焦面板中的选择；焦点在文字输入框时，快捷键用于文字编辑。

操作时注意以下区别：

- **当前来源**决定分镜或字幕面板显示哪些视频和轨道。
- **当前筛选**决定哪些条目可见，高亮模式不会隐藏非匹配项。
- **当前选择**决定批量标注和导出处理哪些条目。
- **当前焦点**决定快捷键和菜单命令作用于哪个面板。

分镜和字幕面板各自提供来源菜单，可同时查看多个视频。单击条目会在源监视器中打开对应媒体。需要固定面板内容时，使用来源菜单旁的**锁定作用域**。

## 查看处理进度和提示

顶部进度区显示导入、分析、分镜识别、检索准备、代理生成和导出等任务。任务可能先排队，处理期间可继续执行允许的操作。

只有一个可取消任务时，顶部提供取消按钮。取消可能保留已导入的素材或已生成的文件，完成后应核对项目和输出位置。处理期间不要断开素材盘、代理盘或输出盘。

灰色命令通常表示当前选择、媒体连接或工作区不符合条件。遇到问题时，先查看屏幕提示，再参阅[故障排查](/troubleshooting/troubleshooting)。

## 调整外观和保存布局

在**编辑 → 首选项 → 外观**中选择最暗、深色或浅色主题。布局会在下次启动时恢复；当前不支持将面板移为独立浮动窗口。

如果误关面板，从**窗口**菜单重新打开即可。关闭面板不会删除项目媒体或分镜。

## 按当前任务安排面板

| 当前任务         | 建议保留的面板     | 先确认什么                     |
| ---------------- | ------------------ | ------------------------------ |
| 核对导入与绑定   | 媒体箱、源监视器   | 文件在线、辅助媒体正确         |
| 分镜审看和分类   | 分镜、源监视器     | 来源、切点、选择与标记         |
| 对白查找         | 字幕、源监视器     | 字幕轨、查询与上下文           |
| 回退一次项目修改 | 当前面板、历史记录 | 要回退的是项目编辑还是来源导航 |

先关闭暂时不用的面板，为当前任务留出可读空间。需要重新打开时从窗口菜单选择，布局操作不会删除媒体内容。
