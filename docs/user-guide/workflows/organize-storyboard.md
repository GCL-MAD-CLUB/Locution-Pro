# 整理分镜并建立关键字

适合审片、素材筛选和建立可复用的项目素材分类。你可以先把长视频切分为镜头，再用旗标和星级记录取舍，用关键字描述内容，最后按分类找到候选素材。整个过程无需字幕。

建议先用一小段素材确定分类和标记标准，再处理整个项目，避免中途反复改名或批量返工。

## 开始前

- 导入视频，并保持原始文件在线。
- 打开**分镜**面板，在来源菜单中选择需要整理的视频。
- 等待镜头识别完成；多视频集中审看时，可继续勾选其他来源。
- 大批量覆盖分镜、删除分类或调整结构前，使用**保存副本**保留一个阶段版本。

## 浏览并校正镜头

1. 切换到**图标**视图快速浏览，并调整缩略图大小。
2. 单击缩略图预览完整镜头，检查是否包含所需动作和足够时长。
3. 对明显的误切或漏切，在源监视器中显示切点，再添加、移动或清除切点。
4. 修正后回到分镜面板，检查相邻镜头的标题、关键字和标记。
5. 多来源整理时，确认当前操作的视频；需要固定范围时开启**锁定作用域**。

自动识别容易受淡入淡出、叠化、闪光和快速运动影响。切点调整会改变镜头集合，因此宜在大批量标注前完成主要修正。

## 建立统一的筛选标准

用旗标区分留用和排除，以星级记录质量或优先级。以下是一套可调整的示例：

| 标记   | 示例约定                         |
| ------ | -------------------------------- |
| 留用   | 内容符合主题，可以进入候选集合   |
| 排除   | 内容不符合要求，不再进入本轮筛选 |
| 1–2 星 | 可用性较低，仅作为备用           |
| 3 星   | 内容合格，仍需比较               |
| 4–5 星 | 质量或优先级较高，优先审看       |

先审核少量镜头并统一标准，再使用多选、数字键或喷涂工具批量标注。只想暂时隐藏不采用的镜头时，优先使用排除旗标，不要直接删除分镜。

## 规划并添加关键字

### 建立少量稳定分类

从人物、地点、景别或动作等维度开始。例如：

- **人物 > 主讲人**、**人物 > 嘉宾**。
- **地点 > 教室**、**地点 > 室外**。
- **动作 > 讲话**、**动作 > 演示**。

同一概念只保留一个常用名称，其他叫法放入同义词。关键字属于整个项目，同一分类可以应用到多个视频。

### 为镜头赋值

1. 选择一个或多个镜头。
2. 在添加框输入名称或路径，或在关键字树中勾选已有节点。
3. 对连续镜头使用底部**喷涂工具**，加快重复标注。
4. 多选后检查星号状态，确认某个关键字是应用于全部还是部分镜头。
5. 使用**过滤关键字**定位树节点，使用节点右侧的快捷过滤箭头筛选镜头；两者作用不同。

重命名或删除分类会影响项目中的所有相关镜头。只需取消个别镜头的分类时，应移除赋值，而不是删除整个分类。

## 组合相关镜头

将同一场次或段落的多个镜头组成**堆叠**，保持浏览整洁：

1. 选择相关镜头，右键选择**组成堆叠**。
2. 折叠堆叠以查看代表项，展开后核对各成员。
3. 对折叠堆叠批量标注后，再次展开检查标记是否适用于全部成员。
4. 只需调整浏览分组时使用堆叠；确实要改变基础切分时，才使用合并或清除切点。

跨视频拼接不属于合并镜头，应在导出时开启**合并为一个文件**。

## 检查并保存整理结果

1. 清除临时文字搜索，分别按旗标、星级和关键字筛选。
2. 检查候选镜头是否完整，排除项是否仍混在结果中。
3. 如使用高亮模式，改用过滤模式后再全选，避免包含非匹配项。
4. 按 **Ctrl + S** 保存项目。
5. 进入导出前，再次核对来源、筛选条件和实际选择。

## 项目规模增加后如何继续

一套分类稳定后，可保存为[关键字集](/storyboard/keyword-sets)，按场次逐批标注。需要更改名字或父级时，先按旧分类筛选并保存副本，再按[维护层级和同义词](/storyboard/manage-keywords)迁移赋值。

分镜越多，越需要将内容分类与采用判断分开记录：关键字回答画面是什么，旗标和星级回答本轮是否采用。返回项目时，先恢复来源，再通过这些已保存标记继续工作。
