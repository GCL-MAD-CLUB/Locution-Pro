# 创建和管理项目

项目保存媒体箱组织、轨道关系、镜头划分和标注。原始媒体仍位于自己的文件夹中，因此保存项目不等于备份素材；保管、恢复或移交工作时，需要同时考虑两类文件。

## 了解项目保存的内容

| 内容                           | 是否随项目保管 | 说明                       |
| ------------------------------ | -------------- | -------------------------- |
| 媒体箱组织与显示名称           | 是             | 不同于磁盘文件夹和原文件名 |
| 分镜、标记和关键字             | 是             | 保存后可继续筛选和整理     |
| 音频、字幕与代理关系           | 是             | 对应文件仍需可访问         |
| 原始视频、音频、图像和外部字幕 | 否             | 必须分别备份或复制         |
| 临时搜索、选择和导出范围       | 否             | 导出前重新核对             |
| 面板布局与来源浏览记录         | 当前电脑恢复   | 换电脑后重新安排           |

## 使用项目首页

启动时默认显示项目首页。单击**新建项目**、**打开项目**或最近项目名称即可开始；右上角主页按钮可再次打开首页。

- 在**筛选最近的文件**中输入名称，快速缩小列表。
- 单击列标题排序，按名称或时间寻找入口。
- 拖动首页边缘调整大小，双击标题栏恢复铺满。
- 按 **Esc** 或单击**返回工作区**继续编辑。

最近项目只是访问入口，原文件移动或删除后需要重新选择。是否在启动时显示首页，可在[首选项](/projects/preferences)中设置。

## 新建和打开项目

| 操作         | 入口                      | 快捷键     |
| ------------ | ------------------------- | ---------- |
| 新建项目     | 文件 → 新建项目           | Ctrl + N   |
| 打开项目     | 文件 → 打开项目…          | Ctrl + O   |
| 返回最近项目 | 文件 → 打开最近使用的内容 | 从列表选择 |

顶部项目名称旁的圆点表示存在未保存更改。当前项目有未保存更改时，先选择存储、不保存或取消；在确认对话框中也可按 **S** 选择存储，或按 **D** 选择不保存。不确定是否还需要当前工作时，选择**取消**或先保存副本。

打开后若提示媒体脱机，按[重新链接媒体](/media/offline-proxies#重新链接媒体)恢复。打开旧项目后首次保存前，保留原文件副本；由当前应用重新保存的项目可能无法在较早应用中打开。

## 保存工作

保存写回当前项目；另存为切换到新文件继续编辑；保存副本留下独立快照并继续当前文件。还原返回最近一次成功保存。

详细操作见[保存、自动保存和恢复项目](/projects/save-recover)。

## 自动保存与恢复

在首选项设置自动保存。默认每 5 分钟检查变化、每个项目最多保留 20 个版本；恢复后另存为正式项目。

详细操作见[保存、自动保存和恢复项目](/projects/save-recover)。

## 使用历史记录

按 Ctrl + Z 撤销，Ctrl + Shift + Z 重做；也可从窗口 → 历史记录返回对应状态。返回旧状态再继续编辑会替换后续历史，比较方案前先保存副本。

项目历史、来源导航和导出范围撤销的区别见[使用历史记录和后台任务](/workspace/tasks-history)。

## 移交项目

保存正式项目或副本，复制原始媒体、外部字幕和需要的代理。接收电脑打开后重新链接并核对整理结果，再保存。

详细操作见[备份和移交项目与素材](/projects/transfer-project)。

## 关闭项目或应用

- **文件 → 关闭项目**关闭当前项目并保留应用。
- **文件 → 退出**关闭应用。
- **文件 → 关闭**或 **Ctrl + W**关闭当前面板，不关闭整个项目。

有未保存更改时，按提示选择存储、不保存或取消。误关面板时，可从**窗口**菜单重新打开。
