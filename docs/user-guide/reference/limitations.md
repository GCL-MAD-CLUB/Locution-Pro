# 当前限制与使用边界

安排正式工作前，请确认以下条件。这里说明功能边界和需要人工核对的部分；具体操作可通过各节链接进入相应主题。

## 系统、媒体与项目

- 桌面应用面向 64 位 Windows 10 / 11。
- 项目文件不包含原始媒体。交接时同时提供素材，路径变化后重新链接。
- 项目可以另存副本，但副本不会自动复制其引用的素材。
- 代理可用于预览和审核输出，但不能替代原始素材归档。
- 镜头检测、画面检索准备和原始分辨率静帧导出需要原始视频在线。
- 更改缓存或自动保存位置，不会迁移旧文件。
- 图像导入支持不代表具有与视频相同的分镜、播放和检索能力。

保管与恢复方式见[创建和管理项目](/projects/projects)，格式条件见[支持的格式与兼容性](/reference/supported-formats)。

## 搜索、字幕与镜头整理

- 语义检索需要安装可选组件。它用于寻找相关内容，不能保证每个结果都符合意图。
- 分镜语义检索依据画面，字幕语义检索依据已有字幕；均不提供音频听写。
- 字幕面板中的文字与原始时间只读。导出预览可单独调整输出范围。
- 位图字幕和烧录字幕不能直接用于文字检索。
- 同一视频在一个字幕面板中一次显示一条轨道。
- 高亮搜索保留非匹配项，全选前应确认是否需要切换过滤模式。
- 临时搜索和筛选条件不属于项目中的长期整理记录。
- 自动镜头识别需要人工检查，尤其是转场、闪光和快速运动处。
- 不同视频可以集中检索和标注；合并镜头与堆叠分别在各视频内进行。
- 色标与自定义标签互斥。
- 关键字层级不支持直接移动，调整父级需新建正确分类并重新赋值。
- 字幕喷涂支持标签、旗标和星级，不支持关键字。

## 导出与剪辑范围

- 跨视频拼接使用合并导出；不提供多轨时间线编排、转场和特效制作。
- 导出只处理勾选的片段，不自动包含当前来源中的全部内容。
- 临时导出范围不随项目保存，撤销范围也不能恢复已覆盖的成品。
- 提交导出后返回编辑工作区，完成提示中的成功与失败数量才是批次结果。
- 取消导入、分析、代理或导出可能保留已完成的部分结果，不等同于撤销。
- 提高输出帧率不会增加原素材已有的运动细节。
- 预计文件大小仅供参考，实际大小以生成文件为准。

详见[导出媒体](/export/exporting)。

## 面板与本机状态

- 当前不支持将面板移为独立浮动窗口；菜单中的**浮动面板**不可用。
- **面板组设置**当前不可用。
- **脱机编辑**等显示为禁用状态的命令不是当前可执行的工作流程。
- 面板布局、来源浏览记录和最近导出设置在当前电脑使用；复制项目到另一台电脑后需重新检查。
- 来源工作区与顶部导入、编辑、导出工作区是不同概念，关闭来源工作区不会删除媒体。
- 多个后台任务汇总显示时，不提供逐项取消。

## 数据保管建议

重要决定应写入标记并保存，临时搜索、过滤和勾选不宜作为交付记录。处理任务期间保持相关磁盘连接，不要移动正在使用的媒体。

自动保存不是完整备份，代理也不是原始素材的替代品。正式交接前，应分别核对项目文件、原始媒体、需要的辅助文件和输出成品。

## 根据当前条件选择下一步

| 当前条件             | 可以先做什么                   | 需要补齐什么                     |
| -------------------- | ------------------------------ | -------------------------------- |
| 无字幕但原视频在线   | 检测、浏览和分类分镜           | 仅对白检索需要文字字幕           |
| 无语义检索组件       | 人工浏览、文字搜索、标记与导出 | 按含义或画面描述搜索前安装组件   |
| 原视频脱机但代理在线 | 继续代理预览和审看             | 检测、检索准备与静帧前恢复原视频 |
| 在另一台电脑打开项目 | 查看并核对已有整理             | 恢复素材连接与本机设置           |
| 只需调整一次交付范围 | 在导出预览微调                 | 长期分镜修改应回编辑工作区       |

具体准备方法见[分镜检测](/storyboard/detect-shots)、[字幕来源](/subtitles/choose-sources)、[媒体重新链接](/media/relink-media)和[导出范围](/export/prepare-clips)。
