# 支持的格式与兼容性

导入前确认文件类型，交付前确认接收方的编码与规格要求。同一扩展名可能包含不同编码，能否正常使用还取决于文件内容、解码支持和媒体工具。

## 可导入的文件

| 类型 | 扩展名                                                  |
| ---- | ------------------------------------------------------- |
| 视频 | MKV、MP4、MOV、WebM、AVI、TS、M2TS、MTS、MPEG、MPG、M4V |
| 音频 | WAV、MP3、M4A、AAC、FLAC、OGG、Opus、WMA、AIFF          |
| 图像 | JPG、JPEG、PNG、WebP、BMP、TIF、TIFF、GIF               |
| 字幕 | SRT、ASS、SSA、VTT、WebVTT                              |

图像可作为项目媒体导入；导入支持不代表每类媒体都具备与视频相同的分镜、播放或检索能力。音频和字幕可作为独立媒体导入，并按工作流程绑定到视频。

首次处理一类素材时，先抽查导入、预览、定位、音轨和导出结果，不要只根据扩展名判断兼容性。

## 可用于检索的字幕

- 视频中的内嵌文字字幕可直接选择。
- 绑定的外部文字字幕可用于对白检索。
- 位图字幕不能直接用于文字或语义检索。
- 画面中的烧录字幕不会自动转为可搜索文字。
- 复杂字幕排版可转换为便于阅读的文字，但不作为字幕样式编辑功能提供。

字幕语义检索使用已有字幕，不会通过听写音频补齐缺失内容。详见[使用字幕](/subtitles/subtitles)。

## 视频与音频输出

| 编码 / 格式   | 扩展名 | 常见用途     |
| ------------- | ------ | ------------ |
| H.264         | .mp4   | 常规视频交付 |
| HEVC（H.265） | .mp4   | 高效率压缩   |
| Apple ProRes  | .mov   | 后期交换     |
| VP9           | .webm  | WebM 交付    |
| MP3           | .mp3   | 音频交付     |
| AAC           | .aac   | 音频交付     |

可用音频编码、采样率、声道和比特率随输出格式与来源变化，选择框中未提供的组合不可直接使用。没有音频的来源不能选择纯音频输出。

ProRes 的质量档位会对应不同 profile；需要精确后期规格时，在导出工作区的输出摘要中核对。完整设置见[导出媒体](/export/exporting)。

## 静帧输出

**导出帧**提供 BMP、DPX、GIF、JPEG、OpenEXR、PNG、Targa 和 TIFF，默认 PNG。通过源监视器的分镜模式导出，使用原始视频分辨率，因此需要原始媒体在线。

静帧导出与视频片段导出是不同功能，不能用来生成视频。完整步骤见[导出当前帧](/source/source-monitor#导出当前帧)。

## 代理格式

创建代理时可选 H.264 MP4、H.264 MP4 All-Intra、H.264 QuickTime、VP8 WebM 或 VP9 WebM 等预设。代理用于轻量预览和审核，不改变原始文件格式，也不代表所有播放器都能播放对应成品。

详见[管理离线媒体与代理](/media/offline-proxies)。

## 交付前兼容性核对

1. 确认接收方要求的容器、编码、分辨率、帧率和音频规格。
2. 在导出工作区比较来源与输出摘要。
3. 先导出短片段，用目标播放器或后期软件打开。
4. 核对画面、声道、同步、文件名和可播放性。
5. 再提交完整批次。

较通用的视频交付可优先测试 H.264 / MP4。HEVC、ProRes、WebM 和专业图像格式需确认接收软件支持；硬件加速可用性还取决于本机环境。

遇到问题时，记录媒体编码和报错，按[故障排查](/troubleshooting/troubleshooting)处理。

## 扩展名、编码和用途

| 名称                     | 表示什么               | 需要另外确认                       |
| ------------------------ | ---------------------- | ---------------------------------- |
| MP4、MOV、MKV、WebM      | 文件容器或扩展名       | 里面的视频和音频编码               |
| H.264、HEVC、ProRes、VP9 | 视频编码               | 输出容器、尺寸、帧率和播放兼容性   |
| SRT、ASS、VTT 等         | 外部字幕格式           | 是否为可读取文字，时间是否对应视频 |
| 代理                     | 文件在工作流程中的用途 | 编码、尺寸及与原视频的对应关系     |

仅改文件扩展名不会转换编码，也不能让不受支持的内容变为可读取媒体。导入图像格式与导出静帧格式分别列出，不表示所有格式都可双向使用。
