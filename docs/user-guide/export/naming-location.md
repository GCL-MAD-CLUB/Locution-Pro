# 设置导出位置、文件名和同名处理

输出位置与命名规则帮助你核对每一批交付。设置后先看路径和名称示例，尤其是复用上次设置、切换来源或改为合并输出时。

## 设置输出位置

选择**指定文件夹**并单击**选择**，或选择桌面、文档等常用位置。界面中的**原始照片所在的文件夹**对视频同样适用，使用第一个来源的原始媒体目录。

需要分批管理时，开启**存储到子文件夹**并输入名称。检查目标位置可写、磁盘空间充足；合并输出还应预留完整成品所需的空间。

### 处理同名文件

| 设置                       | 结果                         |
| -------------------------- | ---------------------------- |
| 询问要执行的操作           | 遇到冲突时显示列表，由你决定 |
| 为导出的文件选择一个新名称 | 为新文件生成不重复名称       |
| 无提示覆盖                 | 替换已有同名文件             |
| 跳过                       | 保留旧文件，不生成冲突项     |

选择询问时，**导出文件已存在**窗口列出全部冲突文件，并提供：

- **取消**：停止本次导出处理。
- **跳过**：保留已有文件，跳过冲突项。
- **使用唯一名称**：为冲突的新文件生成不同名称。
- **覆盖**：用新文件替换已有文件。

窗口中的选择会应用于列出的全部冲突文件。覆盖无法通过撤销恢复，确认前请核对文件名和完整路径。

## 设置文件名

先选择命名规则，再检查**示例**。规则随来源和合并方式变化：

| 来源     | 可用于命名的内容                               |
| -------- | ---------------------------------------------- |
| 分镜     | 镜头标题、关键字、时间范围、原文件名和自定名称 |
| 字幕     | 字幕文字、时间范围、原文件名和自定名称         |
| 媒体箱   | 原文件名、自定名称及其组合                     |
| 合并输出 | 文件名、自定名称或两者组合                     |

选择包含自定名称的规则后，填写自定义文本。长字幕或关键字可能使名称过长，应在示例中检查，并选择较简洁的规则。切换来源或合并方式后再次核对。

**起始编号**用于区分同一批次内的重复名称，不会给每个文件强制加号。第一个文件保留基础名称，后续同名项追加编号；例如起始编号设为 3，后两个同名项分别追加“-3”“-4”。扩展名大小写只改变名称显示，不改变编码。

## 为一批交付安排目录

1. 选择可写、空间充足的输出位置。
2. 按批次设置子文件夹，区分审核文件和正式交付。
3. 检查不是唯一原素材或唯一旧成品所在位置。
4. 看完整路径，确认外接磁盘仍连接。
5. 再选择同名处理方式。

原始照片所在的文件夹也适用于视频，并使用第一个来源的原始目录。多来源交付时，指定明确目录通常更便于核对。

## 根据来源选择可追溯的名称

| 来源     | 可采用的命名线索                     | 避免的问题             |
| -------- | ------------------------------------ | ---------------------- |
| 分镜     | 原文件名、镜头标题、关键字、时间范围 | 多个镜头同名、路径太长 |
| 字幕     | 对白文字、时间范围、原文件名         | 整句字幕使名称过长     |
| 媒体箱   | 原文件名与自定文本                   | 相似文件无法区分       |
| 合并输出 | 项目用途或批次自定名称               | 沿用单片段的旧命名方式 |

起始编号只处理同一批基础名称的重复，不会为每个文件统一添加序号。需要交付顺序线索时，应结合可用命名字段和实际列表核对。

## 选择同名处理策略

- 初次整理目录或无法确认旧文件用途时，使用询问。
- 希望保留旧成品时，使用唯一名称或独立批次目录。
- 明确只重做缺失结果时，可按需要使用跳过，并核对数量。
- 明确替换旧结果后才使用覆盖，先保留必要备份。

冲突对话框的选择作用于列出的全部冲突文件。取消会停止本次处理，跳过不表示这些文件已被新批次更新。

## 导出后核对文件名

比较已选片段、成功数量与输出目录。部分文件被跳过时，注意目录中看到的可能是旧成品；核对文件时间、内容和规格后再交付。
